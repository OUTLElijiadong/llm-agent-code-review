# 真实 Agent 发布与生产闭环共识

## 可测试验收标准

1. 审查员用真实职责创建 `auth_boundary_reviewer` v1，核对保存、静态校验、审批提交与刷新后的状态。
2. 管理员核对审批单对应 Agent、版本、提示词、审查重点、Skill、能力申请与调用成本，批准后核对发布记录及全站目录。
3. 用运行提交 `7e7559a` 中真实源码调用新 Agent；结果能指出有证据的问题或明确返回无问题，并保留实际模型用量与版本信息。
4. 小菱在真实对话中按精确编码调度已发布 Agent，并创建含现有 Agent 与新 Agent 的团队；团队成员确实运行，事件、最终摘要与会话记录一致。
5. 三账号正向功能和反向权限逐项记录：审查员不能审批，普通用户不能创建/审批；各自会话、团队和报告不得跨账号泄露。
6. 刷新、重开和异常恢复后，聊天内容及顺序正确；所走正常页面无意外 404；可见控件与布局在所测视口无错位。
7. 每项记录账号、对象 ID、时间、操作、预期、实际、证据与“通过/失败/阻断/未测”，不得把静态测试或配置表述为生产功能通过。

## 技术与数据约束

复用现有 Agent 工坊、发布审批、Agent 目录与小菱工具；不创建重复接口。真实源码只取已核实的运行提交，不上传凭据或私有环境文件。发现错误先复现，最小修复后运行定向回归和适当的全量检查；发布状态单独核验。
