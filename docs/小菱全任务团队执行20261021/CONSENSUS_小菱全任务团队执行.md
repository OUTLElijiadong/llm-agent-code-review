# 小菱全任务团队执行共识

## 已确认目标

小菱仅担任协调者。每条新的、可执行的人类请求必须由小菱创建可追踪团队并派给至少一个匹配 worker；普通问答也包含在内。AgentMesh 的自动结果回执、用户澄清/审批/停止控制不算新的业务请求，不能因此递归创建团队。

团队成员不匹配时，小菱可以建立当前任务专属临时成员，临时成员只能使用已登记执行合同。仍没有安全合同的任务必须形成明确阻塞记录与缺口，禁止小菱直接回答或执行业务部分。普通文字问答使用无业务工具、无网络、无写权限的通用 worker；实时页面数据必须使用固定能力目录中的 GET/read worker；其他领域使用专用 worker。

小菱只能在任务终态后核验完整覆盖、权限和证据并汇总。任务运行中只允许报告已派发/运行状态。团队失败、阻塞、取消或证据不足时不得声称完成，亦不得改由小菱补做。

临时 Agent 默认随团队留存审计快照；小菱可以依据已记录的复用次数、成功率、合同稳定性及用户价值判断是否值得保留。自动“常用”判定仅生成带证据的保留候选；永久加入 Agent 库必须走现有 Agent 发布/治理流程，未经该流程不得静默扩大能力或发布。

## 生产与历史验收

先对账并确认 4.1.15 已完整部署，且生产代码、镜像、迁移、发布台账和健康端点一致。已通过 `root@81.70.251.90` 只读核对生产源码、镜像、容器、迁移和发布容量；未读取或修改生产密钥。此前已记录可复现的旧版行为：普通问答没有可见团队卡、报告默认混入失败/无评分记录、圆桌历史回放 JSON 解析失败。当前浏览器仍停在登录页，因此需要登录态的评分、账号权限、强停/恢复和逐页布局行为只能标注未核验。基线确认后在 4.1.15 SHA 的隔离分支修复，候选为三段语义版本 4.1.16。

历史验收包括：普通/安全审查评分和报告的账号归属；失败、未评分、部分覆盖记录的默认展示；圆桌启动、手动强停、意外断线同运行恢复；页面文字布局和 OWASP 热点说明删除。仅在生产回归中证实通过后才关闭对应条目。

## 验收标准

1. 普通问答、页面查询、领域操作均有真实团队卡；卡片与成员/派发 instructions 对应持久记录。
2. 根会话的业务工具执行能力由服务端关闭；非团队最终回答不能被标记成功。
3. 团队成员未开始或仍运行时，只出现准确的派发/进度状态；仅在所有必要任务和核验完成后允许汇总。
4. 缺失适配合同、无权限、无可用执行成员或审计证据时，形成清晰 blocked 状态与缺口，不回退直做。
5. 临时成员无额外权限；保留决定有明确证据，并通过现有 Agent 治理发布链。
6. 生产各账号的评分、报告、圆桌停止/恢复及历史筛选经过真实浏览器复核。
7. 生产代码、发布版本、镜像、迁移、健康检查、备份回滚记录与浏览器验收相互吻合。

## 边界与阻塞

服务器只读 SSH 和正式部署入口已可用，用户已授权继续生产发布；候选发布必须通过正式 `deploy/deploy.sh all --revision <SHA>`，保留脚本生成的回滚点并检查发布回执。Safari 当前为登录页，所有依赖用户登录态的真实页面验收仍待用户登录后完成；部署和匿名健康检查不能替代该验收。
