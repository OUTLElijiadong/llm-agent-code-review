## 小菱编排新能力

- 创建团队或临时成员不再询问。只有远程目标、改动服务器的运维或应急成员需要审批；只读运维直接执行。
- 成员卡片显示“完成 x/y”、未完成任务的状态，以及可以展开的“小菱的派发内容”；卡片上可以单独停止某个任务。
- 新增 `POST /api/agent-teams/{team_id}/tasks/cancel` 和小菱工具 `cancel_agent_team_task`：运行中可以停掉某个成员并改派。生产探测不存在的团队返回 400，说明路由已生效。
- 人为停止立即收敛为已取消。非人为异常最多从检查点自动恢复 2 次，并有每 120 秒一次的僵尸运行清扫。
- 上下文超预算时先做应急压缩再继续：用户原话保持原文，助手和工具输出缩短。
- 前端 chunk 加载失败时自动刷新一次，用来避免发版后出现“页面不存在”；小菱站内导航允许 `/remote-pentests`。
- JARVIS 主动派发的代码默认开启，30 分钟节流，新的高危告警不受节流限制。
- 生产 Agent 知识库：编排手册更新为 chat_assistant doc#65、manager doc#66。“停掉子 Agent 改派”“创建团队前是否询问”“人为停止与自动恢复”三类检索，两端前两条都命中新手册。

## 上线后发现

- 热修复 `4d6db063`：一个长期挂起后取消的渗透任务耗时超过 INT 上限，MySQL 拒绝写入 `review_tasks.duration_ms`。这导致启动时的远程评估孤儿清扫和每轮的渗透保留清扫都失败。现在耗时截断到 INT 上限，并加了回归测试。热修复上线后，后端日志 ERROR 为 0。
- 第一次种入手册时嵌入接口超时，脚本静默降级为本地哈希向量，导致 Agent 知识库检索命不中新手册。TEI 恢复后重新种入即可正常。种入脚本本身仍会静默降级，属于待修项。
