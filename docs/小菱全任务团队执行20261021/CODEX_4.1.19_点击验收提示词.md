## A. 4.1.16 的 8 个问题

1. 失败报告不再写“未发现问题”
   - 管理员登录，打开 `/reports/217`（或任意状态为失败且不出分的报告）→ 点“预览 HTML”，再分别导出 PDF、Word。
   - 预期：问题区不出现“本次审查未发现问题”，而是“审查未完成或覆盖范围未知，没有可用结论，不能据此判定无问题”。部分覆盖的报告显示“已审范围内未发现问题；审查覆盖不完整…”。
2. 小菱面板默认不遮挡
   - 退出登录后重新登录，进入 `/dashboard`。
   - 预期：小菱对话面板默认收起，只显示右下角入口；手动打开后刷新页面仍保持打开；新开标签页默认收起。
3. 0 文件项目不能调用测试 Agent
   - 打开 `/sandboxes`，在“项目源码”选择 `QA-20261021-Prism-Acceptance`（0 文件）。
   - 预期：出现提示“该项目还没有代码文件，请先上传源码或从 GitHub 导入后再调用 Agent”，“调用测试 Agent”按钮置灰不可点。
4. 项目表格不再逐字竖排
   - 打开 `/projects`，切到表格视图，把浏览器窗口宽度缩到约 1100px。
   - 预期：表头和状态、评分、文件列都是单行横排；表格可以横向滚动；最右侧“操作”列固定可见，“详情/编辑/删除”可直接点击。
5. 审查员导航一致
   - 用审查员账号登录，点顶部“功能导航”（搜索框）。
   - 预期：能搜到“渗透测试”和“操作审计”，与左侧边栏一致，点击可打开。
6. 权限页说明真实授权
   - 管理员打开 `/admin/access?section=roles`，对“审查员”点“数据范围”。
   - 预期：弹窗顶部有说明“数据范围当前仅作记录，尚未参与鉴权…实际以项目成员关系为准”；若当前值是“参与的项目”，对应单选项已选中（不再全部空白）。
   - 额外核验（可选）：审查员尝试删除非本人项目应被拒绝。
7. 调度列表显示最近执行
   - 管理员打开 `/admin/operations?section=jobs`（运行与审计 → 任务调度），对任一任务点“运行”。
   - 预期：表格新增“最近执行”列，显示“成功/失败/运行中”标签与时间，失败时显示错误摘要；刚运行的任务刷新后更新。
8. 知识库检索不再返回无关结果
   - 打开 `/knowledge`，上传两篇文本：一篇关于“SQL 注入防护：参数化查询”，一篇关于“周末菜谱：红烧肉”。
   - 检索“如何防止 SQL 注入”。预期：只命中 SQL 那篇，菜谱不出现。
   - 检索“Kubernetes 滚动发布”。预期：无结果，而不是返回约 60% 的无关文档。
   - 验收完成后删除这两篇测试文档（这是你自己创建的测试数据，允许删除）。

## B. 小菱编排新能力

9. 创建团队不再询问
   - 普通用户登录，打开小菱，发送：“帮我对项目 <选一个有代码的项目名> 做一次代码质量和安全并行检查，再汇总”。
   - 预期：小菱直接组队执行，不弹“是否创建团队/临时 Agent”的确认卡片。
10. 子 Agent 任务可视化
    - 在团队卡片里点开团队悬浮窗或团队详情。
    - 预期：每个成员卡片显示“完成 x/y”进度、未完成任务的状态（排队/进行中/等待前置），以及可展开的“小菱的派发内容”（原文任务说明）。
11. 运行中改派
    - 团队运行中，在小菱里发送：“停掉安全检查那个成员，改成只检查 SQL 注入”。
    - 预期：小菱回复停了哪个成员、新任务交给谁、做什么；原安全检查任务显示“已停止”，其余成员继续；出现新的团队/任务专门检查 SQL 注入。
    - 另测：成员卡片上的“停止”按钮，确认弹窗后只停该任务，其他成员继续。
12. 人为停止立即停止
    - 新发一个任务后点击小菱的停止按钮。
    - 预期：立即显示已取消，之后不会自己恢复执行。
13. GitHub 导入
    - 在小菱发送：“把 https://github.com/<一个小型公开仓库> 导入成新项目并做源码审计”。
    - 预期：小菱组队导入（无确认弹窗），项目出现在 `/projects` 且文件数大于 0，随后派发审计成员。
14. 页面不再出现“页面不存在”
    - 在上述所有小菱执行过程中留意页面标题与内容。
    - 预期：不出现“页面不存在”页；小菱给出的站内链接都能打开。
15. 管理小菱主动运维（管理员）
    - 管理员保持管理端小菱会话在线 10 分钟以上。若期间有新的高危告警或失败运行，管理小菱应主动发来“JARVIS 运维简报”并自行组建只读巡检团队核验。
    - 预期：只读巡检直接执行；任何服务器改动只给方案并等待批准（请点拒绝）。若 10 分钟内没有新异常，记为“无法验证（无触发条件）”。
