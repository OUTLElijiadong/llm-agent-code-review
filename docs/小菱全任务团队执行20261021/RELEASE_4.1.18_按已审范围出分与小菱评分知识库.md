## 本版改动

- 评分范围 `score_scope`：完整覆盖 / 仅覆盖已审范围 / 历史任务按已保存问题集复算；只有没有任何已审内容时不出分并给出原因，不再用 0 占位。
- 代码审查：失败文件自动重试一次；仍失败但已有文件完成时按已审文件出分，失败文件写入 `coverage.partial_failures`。
- 圆桌：已有有效发言并完成问题抽取时按已完成发言出分。
- 渗透：`pentest-confirmed-deduction-v1`，检测阶段完成即出已测范围分。远程网站评估：`remote-config-observation-v1`。
- 小菱终审：旧失败任务无评分版本的 0 视为占位，不参与比对；仪表盘均分与趋势只用完整覆盖分。
