# 小菱全任务团队执行最终记录

## 交付结论

4.1.16 已按正式生产发布流程部署成功。生产代码、前后端镜像、发布台账、Alembic 版本、公网健康/就绪端点一致；发布备份在独立 MySQL 容器恢复验证通过（109 张表）。

小菱现按“协调器”边界运行：所有用户任务（包含普通问答）必须先读取当前账号可用 Agent，再创建团队、派发 worker 工作并由 verifier/summarizer 独立核验；团队未完成时只报告真实进度。小菱直接调用业务工具会被服务端拒绝。缺少适配执行合同会生成明确阻塞任务，不回退为小菱直接回答。常用临时成员只形成有历史数据依据的保留候选，不自动发布到永久库。

异步团队结果通过服务端可信终态快照绑定到原团队；状态与总结不一致时不能报成功。团队编号要求完整 token，避免 52 误绑定到 152、520、52abc 或 team_id:52_extra。人工停止走强制取消且不自动重启；系统中断由同一 run 检查点恢复。

评分/报告默认隐藏失败、无评分和不属于当前账号权限范围的记录，并保留历史筛选入口；圆桌结构化回放解析和缺失覆盖失败关闭已修复；OWASP 热点中指定的免责声明文案已移除。团队执行轨迹默认展开，可查看成员、任务依赖和持久化派发指令。
