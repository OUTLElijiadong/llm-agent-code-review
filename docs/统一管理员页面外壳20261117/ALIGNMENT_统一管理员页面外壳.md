# 统一管理员页面外壳：对齐说明

## 原始需求

管理员在 `/admin/operations?section=overview` 与 `/forum` 之间切换时，不应看到两套前端外壳。只保留管理员使用的一套页面外壳，并完整保留现有能力；完成后发布到当前线上生产环境。

## 项目与任务特性

- 项目为 Vue 3、Vite、TypeScript 与 Vue Router 构成的单一 SPA。
- 管理页路由由 `AdminLayout` 渲染；论坛路由 `/forum*` 由 `AppLayout` 渲染。
- 当前代码已有 `isAdminSharedRoute` 机制，管理员访问 `/billing`、`/support` 时复用 `AdminLayout`；`AdminLayout` 已提供论坛导航项。
- 论坛能力由原有路由和页面提供：列表、搜索、分类、排序、发帖、帖子详情、编辑及回复。不得删除或改写这些业务能力。
- 线上健康端点于 2026-11-17 核验为版本 `4.1.55`、提交 `34f9fb71f9aa0c0d56f4fdbc805471b98959b3d3`；本次干净工作分支以该精确提交为基线。

## 范围

1. 管理员访问 `/forum` 及论坛帖子子路由时继续使用 `AdminLayout`，与 `/admin/operations` 的导航和框架保持一致。
2. 普通用户与审查员继续使用现有 `AppLayout`。
3. 不改论坛 API、数据、权限守卫、企业账号限制、管理员控制台内容或其他页面的路由。
4. 在干净生产基线上实现、验证，并按项目正式流程发布全栈同 SHA 制品；部署脚本不支持只发布前端。

## 需求理解确认

- 用户已确认目标页面为 `https://www.lijiadong.cn/admin/operations?section=overview` 和 `https://www.lijiadong.cn/forum`。
- 用户已确认发布目标为当前线上生产环境。
- “只保留一个前端”在本任务中落实为：管理员在管理页与论坛间使用同一套管理员页面外壳；论坛路由及普通用户现有外壳继续保留。
- 根工作区有 725 条既有 Git 状态记录和约 519 MB 未跟踪材料。本次不清理或覆盖该旧工作区；以线上精确 SHA 建立独立干净分支用于发布。

## 疑问澄清

关键页面和目标环境已由用户确认，无待澄清项。路由及账号限制沿用项目现有规则。
