# 验收：远程渗透链路与沙箱失败诊断

## 验收范围

本次在隔离 worktree 中完成代码修复、独立远程任务链路、本地自动化回归和迁移 smoke test。没有部署生产，也没有对 `lijiadong.cn` 或其他真实公网目标发起请求。

## 结果

| 验收项 | 结果 | 证据 |
|---|---|---|
| 项目授权审批与执行权限分离 | 通过 | 全局 `pentest:authorize` 审批不再额外要求审批人是项目成员；项目启动仍独立校验发起人权限。服务/API 回归包含有权、无权和重复审批场景。 |
| 项目黑盒/白盒失败与覆盖状态 | 通过本地回归 | 根路径 404/非 2xx 不再被描述成完整覆盖；执行失败和报告保存失败保留结构化原因。详情页按报告 ACL 显示证据；无权账号不获得评分、问题统计或正文。 |
| 远程任务无需项目 | 通过 | 独立创建 API 不接受 `project_id` 作为依赖；前端创建表单不显示项目选择，审批、七阶段记录和独立报告使用自己的数据链路。 |
| 远程授权与账号边界 | 通过本地 API 回归 | 授权人必须是不同账号且具有全局授权权限；审批范围摘要绑定目标、声明、范围、规则及时间窗。审批人仅看申请范围与任务状态，不能读取阶段证据或报告。 |
| 远程请求边界 | 通过 mock 回归 | HTTPS/443、公网 DNS、固定根路径、无重定向、最多两次 GET、不读写响应正文；复核解析 IP 与首次不一致时在 HTTP 连接前失败关闭。测试没有公网流量。 |
| 前端权限展示与流程 | 通过组件回归 | 远程申请没有项目选择；审批人与报告所有者看到不同授权内容；审批账号不会看到虚假的 `0/7` 阶段进度，也不会发起报告请求。 |
| 数据库迁移 | 通过隔离 SQLite smoke test | 预置迁移版本 `063_agent_browser_actions` 后升级到 `064_remote_pentest_chain`，确认迁移版本与四张远程任务相关表。未连接生产数据库。 |

## 证据边界与未验收项

1. 未执行生产发布、生产 Safari 真实点击、真实生产账号闭环，也没有对外部网站进行主动探测；因此生产行为仍待部署后验收。
2. 远程“七阶段”表示七个阶段都有独立状态、摘要和报告链路；当前公网探测被限制为最多两次只读根路径 GET 和安全响应头观察。受控验证不发送漏洞载荷，后渗透仅为离线推演，不能称为全面主动渗透。
3. 截图中的报告受限提示与“当前账号不是报告所有者/管理员”一致。该限制是账号隔离，不代表报告不存在。应使用原任务发起账号或管理员身份查看；不应通过放宽 ACL 解决。
4. 迁移为前向迁移，downgrade 有意拒绝删除审计数据。部署前需备份并按发布流程应用迁移；本地 smoke test 不等于生产迁移验收。
5. 未做真实手机设备验收、真实公网 DNS 切换或公网浏览器 UI 验收；对应逻辑由本地组件/API/mock 测试覆盖。
