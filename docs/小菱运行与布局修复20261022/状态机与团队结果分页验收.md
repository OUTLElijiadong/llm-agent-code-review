## 团队完整分页契约

复用现有 `get_agent_team` 工具和 `get_team_result_page` 服务，不新增路由。

| 参数 | 行为 |
| --- | --- |
| `result_scope=task`（默认） | 携带 `task_id` 时分页读取原任务结果；原有调用兼容 |
| `result_scope=team_summary` | 不携带 `task_id`，读取团队 `summary_json` 原值 |
| `result_scope=team_error` | 不携带 `task_id`，读取团队 `error_json` 原值 |
| 未指定作用域且未指定任务 | 保持团队详情查询 |

引用携带明确作用域，并保留路径或索引、偏移及分页参数。长字段名的 `key_reference` 同样保留作用域。服务仍先检查账号归属与入口权限，再完整脱敏、定位和分页；团队作用域与 `task_id` 混用会拒绝。

真实引用回归从详情或终态通知返回的引用开始，经过固定工具参数校验、Orchestrator 和实际数据库服务，逐页重组中文、换行、emoji 与超长摘要末尾；同时覆盖团队错误长字段名、完整错误尾部、秘密字段脱敏、跨账号/入口拒绝及默认任务兼容。
