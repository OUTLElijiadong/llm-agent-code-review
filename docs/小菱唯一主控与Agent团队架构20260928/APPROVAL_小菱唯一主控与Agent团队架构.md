# 小菱唯一主控与 Agent 团队方案执行批准

## 已确认范围

- 用户确认可由审查员创建项目固定审查 Agent，再由管理员审批发布。
- 用户确认唯一主控为小菱；小菱可复用已有 Agent，也可创建一个或多个当前账号、当前任务有效的临时 Agent。
- 临时 Agent 完成后保留审计记录，不进入永久 Agent 库。
- 生产真实数据可保留，采用真实使用流程而非演示数据。

## 发布前门禁

本地代码和测试完成后，可先由审查员真实点击创建并提交审批草稿。最终管理员发布会扩大已发布 Agent 对全站审查代码的处理范围，且每个代码分片至少增加一次模型调用。按浏览器执行确认规则，需在最终发布按钮前展示全部准确 Agent 名称、职责、提示词/权限边界与预计调用成本，再取得当时确认后发布。

本文件记录执行范围，不替代上述操作时确认，也不代表任何 Agent 已在生产创建、审批或发布。
