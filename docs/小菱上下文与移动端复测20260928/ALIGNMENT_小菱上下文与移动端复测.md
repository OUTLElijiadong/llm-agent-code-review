# 小菱上下文与移动端复测：需求对齐

## 原始需求

继续完成生产发布后的测试与修复，特别验证移动端布局，以及超过 100 万 token 的上下文压缩；不能静默截断，压缩后应尽量完整保留用户目标、权限边界、纠正和历史事实。

## 已核实范围

- 生产健康接口在本次复测开始时报告 v4.0.22，release SHA 为 `2fa4dbae0f7c7de3620c4f40330c0f67616bf2aa`。
- Safari 响应式模式 `390×844`、管理员运行与审计中心中，小菱悬浮按钮覆盖“安全态势”卡片最右数值和标签；这是实际截图可见的布局缺陷。
- C13 严格预期失败测试表明，沙箱源码压缩只核对来源 ID 和非空摘要，遗漏中段账号隔离权限事实仍可能通过。
- Responses 运行时只核对来源片段和压缩块标记，存在同类语义遗漏缺口。现有百万级测试使用应用估算与模拟模型，不等于真实供应商 tokenizer 或真实模型理解证明。

## 边界

本次只修复能在候选代码中复现并可增加明确回归的移动端遮挡和上下文关键事实遗漏；同时盘点 AI/Agent 输入路径，补齐 1M+ 测试证据边界。生产发布仅在候选回归、独立复核和发布前检查通过后执行。真实模型 1M+ 结论必须以有效供应商响应、真实 usage 与完整答案为证；无效凭据、费用或窗口限制均记为阻塞，不以模拟结果替代。

## 非目标

不声称语义压缩在数学意义上零损失；不将一条入口的测试外推到全体 Agent；不把日志关键词零命中写成系统绝无错误；不更改权限业务规则或账号隔离策略。
