# 小菱上下文与移动端复测：实现共识

## 验收标准

1. 管理后台手机视口中，小菱入口不得覆盖可见业务卡片、文字或操作；入口保持可发现且可点击。
2. 上下文压缩保留原始账本和来源标识；必须对确定性识别到的用户约束、否定语句、权限边界、数量限制和后续更正保留可核对原文。预算容纳不下完整原文时，显式失败，不静默删除。
3. 来源片段 ID 齐全但关键事实丢失时，不得标记压缩完整或继续执行审查/审计。
4. 百万级本地测试明确标为应用估算与模拟传输。真实 1M+ 模型测试只有在供应商实际接受输入、返回完整终态并提供有效 usage、且首中尾校验问答正确时通过。
5. 候选代码、文档和测试经独立只读复核后方可部署；部署后重复原生产浏览器视口和同一语义回归路径。

## 技术约束

- 生产状态从当前健康接口、镜像、发布账本和运维检查重新核对。
- 实现和验证在从生产 SHA 创建的干净托管工作树中完成，保留用户主工作树的未提交内容。
- 超出上游真实模型能力或配额时如实标记未验证，不用估算值冒充供应商 tokenizer。
