# 任务：审查与黑白盒报告可信度

| 子任务 | 内容 | 验收 |
|---|---|---|
| T1 | 复现并修复报告 H2、围栏、编号、重复及混合发现统计 | 原场景复测，候选与确认数一致 |
| T2 | 校验黑白盒 AI 报告章节/角色清单，失败使用确定性报告 | 模型异常不冒称 AI 审查完成 |
| T3 | 保存并读取 AI 报告状态与原因 | API/列表/详情显示一致，权限范围不变 |
| T4 | 回归标准代码审查证据与覆盖门禁 | 普通审查相关测试通过 |
| T5 | 构建、静态检查与发布验证 | 精确 SHA、备份恢复、生产健康/报告只读验收 |

依赖：T1/T2 → T3；T1–T4 → T5。任何外部服务不可用的历史都应通过确定性兜底或可观测失败表达，不承诺外部模型永久可用。
