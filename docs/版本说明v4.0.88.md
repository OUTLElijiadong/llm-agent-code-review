# Prism v4.0.88

修复大文件源码压缩把合法分片误判为截断的问题。沙箱为源码分片保留路径、偏移和原文件长度；压缩提示要求只总结当前片段可见内容，不因 JSON 或代码语法在分片边界处未闭合而误报失败。哈希、来源覆盖、逐字引文和受保护事实校验保持不变；确实缺失或无效的来源仍然 fail-closed。

同步五种语言 Worker 镜像构建的 runner 默认 SHA-256，使其与仓库内 runner 源码一致，避免镜像来源校验因默认摘要陈旧而拒绝构建。

该修复针对 v4.0.87 生产 bWAPP 黑盒任务 `sbx_324746c18daf43ae80e82013` 暴露的上下文压缩失败。发布后以真实生产黑盒及白盒任务复测，结果和边界记录在本次验收文档中；不能据单个项目推断所有 PHP 项目均通过。
