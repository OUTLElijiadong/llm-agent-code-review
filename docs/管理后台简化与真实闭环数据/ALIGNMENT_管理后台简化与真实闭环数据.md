# ALIGNMENT 管理后台简化与真实闭环数据

## 目标

将 Prism 管理后台从面向内部实现的配置表单，调整为面向管理员日常决策的中文治理台；同时使用真实导入源码、真实审查任务和真实治理服务，补齐全部管理菜单的数据闭环。

## 已确认边界

- 目标服务器：`81.70.251.90`，用户授权数据库备份、部署、迁移、重启和回滚。
- 数据规模：至少 50 个可登录账号、30 个治理 Agent；其余规模由验收结果决定。
- 可使用已配置的大模型额度，审查结果必须来自真实模型调用。
- 管理后台所有菜单均须有可追溯数据；演示/验收产生的数据必须可辨识，不能伪装为自然历史数据。
- 生产工作区已有未提交改动，本轮不得覆盖或回退它们。

## 基线事实

生产库已有 16 用户、23 Agent、29 项目、49 审查任务、1620 条模型调用日志；但策略、工具调用、审批、告警、奖惩、治理知识、反思、指标快照和治理版本表均为空。这是管理后台空白的直接原因。
