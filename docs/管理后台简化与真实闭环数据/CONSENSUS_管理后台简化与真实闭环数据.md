# CONSENSUS 管理后台简化与真实闭环数据

## 数据真实性约定

本轮数据分为两类，均写入来源标识：

1. `live_acceptance`：通过平台服务创建账号、项目、文件、审查任务、策略决策、工具调用、审批、知识、奖惩和版本。
2. `imported_open_source`：从公开仓库导入的源代码或文档；保留仓库 URL、提交标识或文件路径。

不会用随机数、伪造 AI 回答或直接 SQL 拼装审查结论填充界面。

## 管理端简化原则

- 首屏先显示正在运行的业务指标、待处理事项和风险，不显示 JSON。
- 中文名称、状态和风险标签优先；内部编码仅在高级信息中展示。
- 所有输入框具有可见字段标签和示例，不再依赖 placeholder 猜测含义。
- 高风险操作仍保留审批、审计和回滚，不因界面简化而取消控制。
