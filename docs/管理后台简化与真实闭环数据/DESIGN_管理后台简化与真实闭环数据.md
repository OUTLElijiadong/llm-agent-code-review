# DESIGN 管理后台简化与真实闭环数据

## 闭环

```mermaid
flowchart LR
  A[公开源码导入] --> B[真实代码审查]
  B --> C[模型调用与问题]
  C --> D[策略决策和工具调用]
  D --> E[自动或人工审批]
  E --> F[知识、记忆和反思]
  F --> G[奖惩与进化提案]
  G --> H[版本、评估与回滚]
  H --> I[监控、告警和审计]
```

## 实现

- 扩展治理默认画像至 30 个，新增测试验证、质量评估、成本控制、模型评测、报告校验、数据一致性和事件响应角色。
- 新增幂等运行器，使用服务层和策略网关产生带关联 ID 的真实记录；实际审查通过既有异步审查服务调用已配置模型。
- 统一治理工作台标题、说明、状态名称和风险显示，移除观测页裸 JSON 的默认展示。
- 部署前执行源码、数据库和当前镜像备份；部署后通过独立脚本检查行数、外键引用、任务状态和 API 返回。
