# 圆桌讨论持续会话与压缩：交付说明

圆桌会话、发言和进度持久化并按账号隔离；桌面和手机可从全局入口重新打开后台讨论。长源码和发言按来源分片压缩，结构化问题抽取支持分批与长度重试；无法完整抽取时显示失败，而非生成貌似完整的报告。

用户确认的时间规则已实现：正常报告封存后固定五分钟继续追问，截止后禁言，不因追问续时。总结、抽取和写报告期间发送的消息先保存在原始账本，报告成功后由主持人按序回答。进程重启后自动扫描未答但已接受的问题；旧问题跨过五分钟仍需答复。

v4.0.7 真实生产验收中，普通账号小菱发起了圆桌 `disc_13ecdb6fd0`，五位专家完成 13/13 步并生成报告 #184；桌面和手机 390×844 视口均能从全局入口关闭后重开。该圆桌绑定项目 14 的 `agent_service.py`，主题未自动进入专家发言。验收发现报告生成后浮窗仍显示“正在生成报告 13/13”，五分钟倒计时内输入一直禁用；到期后禁言正确。这一缺陷不能用 13/13 进度或报告已生成来掩盖。
