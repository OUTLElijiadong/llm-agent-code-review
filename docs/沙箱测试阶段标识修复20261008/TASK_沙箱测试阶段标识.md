# 沙箱测试阶段标识任务

| 子任务 | 输入 | 输出与验收 |
|---|---|---|
| 后端事件 | `test_mode` 与现有 executor submit 流程 | 活动状态保持兼容；三种模式写入各自阶段；参数化单测通过 |
| 前端标签 | 阶段码和环境 `test_mode` | 新旧阶段均显示正确；前端单测、Lint、类型检查和生产构建通过 |
| janitor 并发 | 状态文件 + 进程内待提交/进行中集合 | 对 validating/preparing 中的活跃提交不执行重启恢复；真实重启后仍安全失败关闭；参数化测试通过 |
| 生产复测 | 精确发布 SHA 与固定安全样本 | 记录部署账本、健康、黑盒/白盒异常与正常回执、资源清理和 Safari 实点；测试状态清理并留审计事件 |

本任务不触碰公网目标，不创建持久业务项目，不调整生产数据或历史审计记录。
