## 停止与 Token 计费边界

父 Responses、圆桌编排与派生团队的应用态取消已实现。Native Responses 的在途异步 HTTP stream 现在会以 250ms 间隔检查持久取消状态，并在停止后取消请求协程、清理 HTTPX 响应流上下文；MockTransport 回归测试确认上下文被清理，但没有观测真实 TCP 或 provider 端取消。completed/cancelled 的先提交终态会被保留，迟到取消不会改写 completed。圆桌旧同步 LLM HTTP 请求若已在线程池或独立 Worker 启动，仍不能强杀在途网络请求；其资源与计费可能持续到超时。

若要求“点停止即停止计费”，仍需逐个确认 provider 端取消契约、流式连接关闭语义、后台 Worker 中断协议及账单归属，并增加可复现的真实 provider 测试。在这之前不能宣称 provider 端计算或费用即时停止。
