# 棱镜第四版更新说明

小菱可编组平台已有 Agent，并行执行正式代码审查和完整白盒安全审计，再汇总终态、发现来源、覆盖指标与正式任务引用。本次流程不动态创建 Agent 定义。

## 审查与审计

- 项目审查复用正式任务、输入快照与报告链路，默认排除不可审二进制和空文本，并记录原因。
- 并行请求使用独立提示词；取消、权限变化、超时和租约接管均校验提交归属，避免过期 Worker 覆盖结果。
- 部分失败保留证据并明确失败。公开团队摘要保留问题来源及文件、分片、字符覆盖标量，未知覆盖不推断为完成。
- 汇总按项目、文件、行号、标题和严重度进行精确去重；不同措辞的同根因发现由小菱进一步核对，不把静态发现写成动态验证成功。
- 报告读取同时检查报告访问合同与当前项目权限；历史文件名称和语言取审查时的冻结快照。
- 上传限制中间件正确透传非 HTTP 消息；生产 Uvicorn 强制执行生命周期，防止生命周期被静默跳过、团队一直排队。

## 界面与交互

- 侧栏折叠按钮保持完整可见；代码中心移除重复留白，页头按底边对齐。
- 问题卡片使用独立操作列，对齐参照一致；中文标题、标签与操作文本按底边排列，窄屏可换行。
- 项目和问题分别加载，失败原因及重试入口清楚可见。
- 团队计时、操作时钟及问题/任务/报告的服务端时间正确处理 UTC；日期筛选器维持原有语义。
- 报告页脚使用全站版本常量。

## 适用边界

正式审查单任务支持 1–500 个文件，默认等待上限为 600 秒。摘要为有界预览，截断时提示读取原任务或报告。真实模型验收使用合成样本；通过不代表全部历史项目、超大输入或所有模型均已验收，也不代表静态发现已被动态复现。

生产发布按精确提交同步构建前后端，执行备份、独立数据库恢复验证、迁移、健康及公网检查。测试覆盖正式任务/团队集成、并发与租约、权限、公开摘要、真实 ASGI 生命周期、响应式布局、加载恢复和非 UTC 时区。
