# 宿主机服务收敛最终共识

## 要求与验收标准

1. 关闭独立的 `auto-surface-mm-local`、`lijiadong-portfolio`、`momentum-radar`、`site_total` 与本机 `postfix` 服务，并禁止它们开机启动。
2. 关闭宝塔面板及其开机启动；云安全组保持现状，SSH 仍可用于主机管理。
3. 保留 Prism 前后端、生产数据库、缓存、ClamAV、嵌入服务、隔离测试数据库、运维/沙箱执行器、备份/证书续期/自动防御定时器，以及 Docker、网络、日志和 TAT 云端管理等系统服务。
4. 不删除其他项目文件、数据库或密钥。
5. 停服后检查目标端口无监听、所有 Prism 容器健康、HTTPS 健康检查成功且关键 Prism 定时器仍启用。
6. 发布 `audit_log.action` 长度修复，使用原操作编号幂等补齐生产执行历史，并核对数据库审计和 root 执行器账本。

## 明确边界

本次停服不等于销毁其他项目，也不会撤销报告中已经暴露的密钥。云安全组与服务器历史配置不在本次修改范围内。
