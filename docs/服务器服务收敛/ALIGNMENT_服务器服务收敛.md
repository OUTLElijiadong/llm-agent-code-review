# 宿主机服务收敛需求对齐

## 原始需求

“他们说服务器还有别的服务运行，请让其下线，只保留本项目完整运行。”

## 当前项目理解

生产主机同时运行 Prism 与若干独立应用。Prism 使用 Docker 前端、后端、MySQL、Redis、ClamAV、嵌入服务、运维/沙箱执行器及发布定时器。服务器还运行个人站、势头雷达、Auto Surface、宝塔面板和若干系统服务。

## 范围

- 停止并关闭独立于 Prism 的业务应用和管理面板自启动。
- 保留 Prism 的生产及发布验证依赖、系统基础服务、SSH 和云端 TAT 管理代理。
- 不删除其他应用的数据目录，不修改云安全组，不清理密钥或环境文件。
- 同一生产修复中完成 `audit_log.action` 字段溢出的热修和原请求幂等恢复。

## 决策

用户明确要求只保留 Prism 项目完整运行；生产确认没有客户端连接，Prism 的备份、证书续期与自动防御由项目自身 Docker/systemd 单元运行，不依赖宝塔。无需进一步改变业务范围。
