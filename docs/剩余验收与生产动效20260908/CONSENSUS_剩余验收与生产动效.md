# 剩余验收与生产动效：验收约定

1. 新旧FastAPI下自动生成同一真实路由范围，继承父级依赖及完整路径；漏路由/伪造小计划必须明确失败，不能输出全量通过。
2. 88角色格各有源码合同与允许的安全验证方式；公开/自有数据入口不硬套403，缺真实夹具/身份的项目保留阻断。
3. 原始控件清单与历史观察不覆盖；每个状态变化有本轮源码、真实UI或明确范围证据。API测试不替代点击，批量复制状态不算实测。
4. 动效复用已有能力，辅助真实执行步骤/结果理解，失败与失权内容立即生效；键盘焦点、取消/返回不被过渡阻挡；reduced-motion静态可用。
5. 动效单独提交与验收，再按已授权正式Git bundle发布流程验证运行版本、资源、备份、数据与失败恢复。
6. 最后使用固定107–110收尾脚本验证身份、0模型/0审查、停用后status0/token_version+1、旧会话40301；历史状态和项目/文件保留。
