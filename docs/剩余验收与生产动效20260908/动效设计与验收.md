# 小菱生产动效设计与验收

本轮范围以 `CONSENSUS_剩余验收与生产动效.md` 为准。主任务知识库准入收据为 `20260908-074247-6a8730208b`，已 ready。实施前已完整阅读实际成员端 `AgentChatDrawer`、管理端 `AdminCopilot`、共享 `ResponseToolTimeline`、审批/追问卡、`CodeViewer`、`MonacoEditor`，以及两端现有流事件与交互测试。仓库没有独立 `AgentCopilot` 组件；实际成员入口为 `AgentChatDrawer`。

## 选型与位置

复用 Vue 的 Transition、TransitionGroup 和 CSS；系统动态偏好复用已安装的 VueUse `usePreferredReducedMotion`。不增加依赖。消息、面板、运行图标已有动效，不再叠加整块入场；本轮只为真实状态变化增加短提示。

|实际位置|触发与信息目的|时长与退出|减少动态效果|
|---|---|---|---|
|两端共享工具时间线的新步骤|收到真实工具事件后提示新增位置；不预演工具或补假步骤|160 毫秒、4 像素位移；无错峰；删除立即生效|不位移、不淡入|
|真实审计阶段|收到 `response.audit.progress` 后绑定当前助手时间线；仅当前 run 活动时标记“进行中”|同一次入场；无常驻呼吸；终止/等待立即取消活动标记|静态状态文字|
|工具结果展开|已有成功事件的 `resultPreview`，复用既有脱敏函数、纯文本呈现，默认折叠|160 毫秒展开；收起立即移除，不保留离场副本|即时展开/收起|
|错误与权限变化|错误原因独立常显，不放入可折叠结果、不等待任何入场/离场；被父组件清除的数据立即删除|0 毫秒；失效展开状态及时清理|相同行为|
|代码定位|复用 `CodeViewer → MonacoEditor.revealLine`，有效目标的行号提示与一次高亮帮助找到位置|行号提示立即显示；定位高亮一次 600 毫秒后回到既有行样式；焦点立即定位|Monaco 使用 Immediate 滚动，定位提示静态，无高亮动画|

工具结果只使用现有 Responses 成功结果，不新增网络请求、参数暴露、原始 payload 或一次性秘密的展示入口。仍使用已有脱敏规则，不宣称其能识别任意业务敏感文本。完成状态只由原始事件决定；取消单列，不计作失败或进行中。恢复历史不播放逐步入场。

## 交互与实现边界

- 展开按钮使用原生 button、`aria-expanded` 和 `aria-controls`；Enter/Space 按原生行为触发，不用重复键盘监听；展开不转移焦点。错误无需先点击。
- 仅新增入场过渡，离场 hook 立即完成；列表清空、运行失败和父组件撤销内容时不可保留可交互旧节点。
- 系统动态偏好在页面打开期间变化也生效。新过渡关闭，同时修复共享时间线 RAG 双点漏关的问题；现有两端错误/时间线父气泡跳过重复动画。
- 不修改鉴权、会话缓存、模型调用、审批执行、数据库或历史状态。不把运行阶段文案当执行完成证据。不改变代码定位原有即时 focus 契约。

## 验证计划

先用真实 Vue 组件红测：运行中转失败立即露原因；等待/取消计数；阶段绑定当前助手 run 并随终态停止；结果按真实成功事件展开、脱敏、焦点与立即删除；减少动态偏好切换。两端走既有真实组件的模拟 SSE 边界，不触发生产模型。

代码定位测试挂载真实 `CodeViewer` 和 `MonacoEditor`，只替换 Monaco 浏览器运行时，验证滚动参数、定位焦点、有效行/无效行、文件更换与卸载清理。测试检查用户可见行为及真实调用，不镜像 CSS 常量。随后执行相关组件回归、类型与 lint；主线程安排浏览器视觉和生产发布验证。本地 jsdom 不作为真实视觉验收。
