# 多模态与头像真实验收准备

日期：2026年9月12日。核验源码：`d000ebe`。这是执行方案，尚未执行生产请求，不能当作生产通过证据。执行者为主代理；本次准备没有登录生产、读取共享浏览器或写业务数据。

## 最小真实界面顺序

1. 主代理先核最终发布版本、当前本人账号数值编号；记录管理员界面已有的小菱默认模型和视觉模型分配。不要改模型配置来制造结果，不记录密钥。使用全新验收会话，只上传本地合成的色块／几何图片，记录文件字节数及 SHA256；不使用个人头像、历史项目或知识库内容作图片问答材料。
2. 图片轮：同一会话发送“这是合成验收图片，请只描述图中颜色和形状，不读取任何项目、知识库或个人资料”。记录会话编号、运行编号、界面输出和结束状态。要求输出与合成图片相符；视觉模型真实调用、输入资产完整及文本输出保存同时成立。
3. 默认恢复轮：保持相同会话，发一条无图片的简单文本请求，例如“只回复验收完成”。必须产生不同运行编号；新运行没有图片资产或图片占位符，检查点和实际调用日志符合当前默认配置。旧轮图片仍按原运行保留。若默认模型与视觉分配本来相同，模型名相等不能证明切换；需如实记载配置边界，不能臆造不同模型或偷偷改配置。
4. 续跑分支：另起一个合成图片任务，要求先使用追问确认要数哪种形状。只有界面真实出现 `waiting_input` 才计入此分支；记录追问调用编号，刷新后回答。相同运行编号、原视觉模型、原图片 SHA256 保留，续跑没有新增重复资产，最终输出可读。模型未产生追问则该分支未验收，不能用自然语言“请确认”冒充工具暂停。
5. 取消分支：在明确等待输入或仍运行的另一合成任务点击取消，记录取消前后状态。要求数据库及刷新界面均为 `cancelled`，后续旧执行者不能覆盖；新文本任务仍可启动。**取消不可在原运行恢复**；恢复仅指 `waiting_input` 的回答，或 `failed/incomplete/max_rounds_exceeded` 的重试。若模型已经完成再点击取消，返回 completed 是合法幂等行为，不能算真实取消通过。
6. 失败分支不破坏生产资产或配置。通过 UI 超过数量／体积的合成附件检查明确反馈与可删除重选；后端伪图片、图片缺失、损坏与上游异常由已完成的本地回归证明。真实发生失败时保存界面和数据库事实，不改历史状态。不为制造错误删除生产图片、改密钥或停服务。

## 请求合同（供对应真实 UI 请求，不能盲目重放）

统一前缀 `/api`，使用当前本人登录态；证据不能包含 Authorization、Cookie、图片 base64 或用户私有上下文。

- POST `/api/agent-responses/stream`，图片启动示意：`{"action":"start","surface":"user","session_id":"实际会话编号","messages":[{"role":"user","content":"合成图片验收提示","images":["data:image/png;base64,合成图片"]}]}`。会话编号 8—128 字符；图片只允许最后一条用户消息，每条最多 4 张、单张不超过 1500000 字节。
- 同会话新文本轮仍为 `action:start`，不传旧 `run_id`，新消息无 images；UI 历史只给最后一条用户消息携图。开始响应中记录真实 run_id。
- 追问恢复：`{"action":"answer","surface":"user","session_id":"原会话","run_id":"原运行","call_id":"真实待回答调用","answer":"统计红色方形","messages":[]}`。不重传图片；后端按本人／surface／session 验证并恢复原图。
- 失败重试：`{"action":"retry","surface":"user","session_id":"原会话","run_id":"原运行","messages":[]}`，仅可恢复状态允许。
- 取消：`{"action":"cancel","surface":"user","session_id":"原会话","run_id":"原运行","cancel_reason":"合成验收取消","messages":[]}`。前端取消请求只检查 HTTP 成功，必须后续核最终状态。
- GET `/api/agent-responses/session?surface=user&session_id=原会话` 是 UI 恢复入口。**该 GET 可能收敛过期活动运行，不作为严格只读数据库采集方法。**
- GET `/api/agent-responses/runs/{run_id}/assets` 返回本人资产 metadata；他人运行返回 200 空数组。GET `/api/agent-responses/assets/{asset_id}/image` 非本人 404，包括管理员；本人返回二进制。

## 数据来源与通过条件

| 来源 | 实际字段与检查 |
| --- | --- |
| agent_response_run | `id` 是数值主键，`run_id` 是字符串唯一编号，`user_id/surface/session_key` 是隔离维度；数据库字段名不是 session_id。检查点 `model/status/rounds/output_text/last_response/transcript/pending`；仅输出长度、散列、状态及图片引用，不复制 instructions 或私有上下文。 |
| agent_multimodal_asset | `run_id/user_id/surface/role/mime/sha256/data/create_time`；binary 的 SHA256 应等于保存值和本地合成文件，输入 role=input；检查点为 `prism-asset://SHA256`，不应含 base64。`run_id/user_id` 是应用关联字段，**没有声明数据库外键**。 |
| ai_call_log | 当前 Responses 写 `model_name/status/*tokens/user_id/root_agent_run_id/agent_run_id`；root/run 是指向 agent_response_run.id 的真实数值外键，不能拿字符串 run_id 直接 join。普通独立根任务自身 root 字段可空，而该根任务调用日志应 root_agent_run_id=agent_run_id=根任务.id。调用次数可能多轮／重试多条，不能强定只有一条。 |
| 输出留存边界 | 当前图片输入、文本输出。完整输出在检查点 output_text/last_response；当前 Responses 的 ai_call_log.prompt/response 默认为空，不能宣称在日志表留了完整输入输出，更不能宣称已有输出图片资产。 |

比较模型名时区分 UI 配置名、检查点计划模型和上游响应模型名。上游别名可能正规化；保存实际值并核官方别名关系，不靠 UI 徽标单独证明。失败或取消在上游已经开始的请求仍可能产生一条真实用量日志，取消不能抹掉已经发生的成本。

## 头像闭环

先通过当前本人资料确认 `user.avatar` 原值。父代理提供的先前状态为空，需要现场重核；本人 GET `/api/users/{本人编号}/avatar/image` 应 404，确认不存在隐藏旧上传行。若已有原图，先保全原图及 MIME 的受控备份再确定恢复方式，不能上传覆盖后删除并声称恢复了原始数据库。

在个人中心真实点击：默认 → 任选内置头像 → 合成图片 A 上传 → 同名但不同像素的合成图片 B 再上传 → 再次选择相同 B → 恢复默认。每一步刷新核显示；B 用来证明缓存更新，相同 B 用来证明文件输入重选有效。失败上传应保留原头像且常驻说明，不能变成空白。

- PUT `/api/me/avatar`：`{"avatar":"builtin:cat"}`；现有 12 内置 key 为 cat/fox/panda/bunny/shiba/penguin/owl/dino/chick/jelly/robot/astro。
- POST `/api/me/avatar/image`：multipart 字段 `file`，PNG/JPEG/WebP/GIF 真解码，≤524288 字节、最大维 4096；upsert 本人唯一 user_avatar 行，user.avatar 设为 upload。
- DELETE `/api/me/avatar`：UI“恢复默认”调用，删除本人上传行，user.avatar=null。不是 PUT 空字符串。
- GET `/api/users/{id}/avatar/image`：本人或管理员可读；普通用户读别人 403、匿名 401、授权但无图片 404。与小菱图片资产的“仅本人”权限合同不同。
- 最终原状态为空时必须恢复 user.avatar=null、user_avatar 行不存在、GET 404，刷新显示默认；不改密码、token_version 或用户偏好。记录每步照片散列与页面结果，不把图片内容写入知识库。

## 只读采集交接

由主代理在真实 UI 操作后提供专用验收账号数值编号及最多 10 个精确 run_id。对应采集器 `证据/collect_multimodal_avatar_readonly.py` 仅 SELECT，MySQL 事务声明 READ ONLY，结束 rollback；不调用 session GET，不遍历其他账号运行，不输出原始图片、prompt、response、transcript、instructions。输出建议命名 `多模态头像-生产只读-阶段名.json`。头像在默认、内置、A、B、恢复默认各阶段采一次；多模态运行结束后按同会话关联核模型、资产、输出与外键。
