## 5. 封禁链路自检（唯一一次真实内核写操作，目标为回环地址）

目的：验证 v4.0.51 依赖的既有内核链路在生产仍然有效（新增动作只读，不改链路）。

```
ipset add prism-sec-v4 127.0.0.9 timeout 120
ipset save prism-sec-v4
    create prism-sec-v4 hash:ip family inet ... timeout 900 maxelem 64
    add prism-sec-v4 127.0.0.9 timeout 119        ← 内核 TTL 生效
iptables -S PRISM-SEC-IN
    -A PRISM-SEC-IN -m set --match-set prism-sec-v4 src -j DROP
iptables -S PRISM-SEC-DK
    -A PRISM-SEC-DK -p tcp -m conntrack --ctorigdstport 80  --ctdir ORIGINAL -m set --match-set prism-sec-v4 src -j DROP
    -A PRISM-SEC-DK -p tcp -m conntrack --ctorigdstport 443 --ctdir ORIGINAL -m set --match-set prism-sec-v4 src -j DROP
ipset del prism-sec-v4 127.0.0.9
ipset_remaining=0                                 ← 解封后集合清空
```

选 127.0.0.9 的理由：回环地址不会命中任何真实业务来源，也不影响 SSH 会话；
本次自检**没有**对任何第三方地址下发封禁。
