## 一句话结论

安全中心新增「溯源与响应」分区：**溯源单个攻击来源、审计本机防御面、读取流量元数据**，
全部只读、只由唯一超级管理员发起、不进任何模型工具目录；真正的处置仍只有既有的
**限时单 IP 封禁租约**（内核 ipset + TTL，自动到期）。没有抓包，没有对第三方的主动探测，
也没有"反击"开关——本轮把那个从不开启的假开关旁边补上了如实反映只读取证是否可用的状态位。
