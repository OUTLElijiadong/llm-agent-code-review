# FINAL 前端 UX 审计修复

## 交付结论

v4.0.28 UX 审计清单的大部分内容随 v4.0.29 发布；普通 Safari 发布后真实点击又复现 `/reviews` 首载同时显示空态和 0 条、随后加载出 50 条。v4.0.30 候选增加任务列表首轮请求门控，定向 18/18、全量 1404 项、ESLint 和 Vite 生产构建通过，生产复验待做。

v4.0.29 已部署且 ops-check 通过；普通 Safari v4.0.29 `/reviews` 任务首载误空已复现，候选修复尚未发布。普通账号精确搜索一个审查员会话标记无匹配，但既有 `session_id` 元数据重合异常仍未全局关联并核清，不宣称完整隔离通过。无痕/私密浏览未使用，未创建/删除/修改生产业务数据。

## 改动

- 将发布审批、执行审批、规则提案收拢进审批中心；将 AI 调用日志与操作审计收拢进日志与审计。保留原数据 API、筛选和分页，兼容历史入口参数。
- 代码中心项目卡明确“浏览代码文件”；发起审查模式补充说明，移除与标准流程完全相同的 quick 新建选项，保留历史兼容。
- 统一一批用户侧/管理侧术语；对系统 Agent 展示名做映射，不动数据库 Agent。
- 说明仪表盘各统计的来源、时间范围和处理状态：总问题数包含已排除发现，严重度分布排除它们，问题追踪默认只展示未修复/待复查；另区分加载错误与真实空权限目录，避免将无开放告警说成系统全绿。
- 调整管理员身份呈现、引导关闭记忆、移动抽屉遮罩、任务卡操作列、仪表盘骨架屏和支持工单用词。

逐项修改和边界见 [验收记录](./ACCEPTANCE_前端UX审计修复.md)。

## 验证

- `npm test`：v4.0.29 基线为 124 files / 1402 passed；v4.0.30 候选为 124 files / 1404 passed。
- `npm run lint`：通过。
- `npm run build`：通过，生成候选 dist。
- Playwright：51 项通过、9 项跳过。全量覆盖多分辨率布局/交互；9 项跳过的是必须在显式配置本机隔离环境运行的登录型用例。
- `git diff --check`：通过。
- Playwright 在本地候选浏览器测试环境运行；Safari 另在普通标签中做了旧生产版本的局部真实点击，不将自动化结果替代生产真实点击。
