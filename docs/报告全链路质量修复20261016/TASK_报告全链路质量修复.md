graph TD

## 执行约束

- 先增加或调整回归断言并运行失败复现，再修复实现。
- 不生成真实生产测试任务；使用隔离 SQLite/测试用户和临时导出文件。
- 导出格式修复不得绕过 HTML 消毒或领域报告限制。
- 独立复核本轮变更文件、测试结果、发布证据和任务范围。
