# Prism v4.0.96

## 沙箱 AI 失败快速停止与导入校验

- 将模型服务 HTTP 402 识别为计费或额度拒绝，返回安全、非敏感的明确错误，不再按普通模型故障重复请求。
- 源码上下文压缩遇到 402 后立即停止重试，并通知排队中的并发批次取消尚未开始的调用；已在途请求最多受现有并发上限约束。
- 动态用例生成遇到 402 时不再进行 Agent 内部或沙箱外层重复生成；事件记录保留 `billing_error`，不把确定性测试结果包装为 AI 动态测试成功。
- 用量审计事务提交失败时保留 `usage_accounting_error`，阻断压缩、部署规划和动态用例阶段的重发；同一沙箱任务不再启动后续 PHP 模型修复或多 Agent 模型报告，仍继续确定性沙箱执行并生成确定性报告。
- PHP 并行语法修复在 `billing_error` 或 `usage_accounting_error` 时停止继续派发文件，保留失败类型给沙箱任务级 fuse；已开始的并发调用收敛后不写入部分修复结果。
- Agent Mesh 将 `billing_error` 和 `usage_accounting_error` 直接写入失败回执并终止重排；普通瞬时异常仍保留原退避重试。多 Agent 报告阶段发生用量审计失败时，仍保存并发布确定性报告。
- Python 生成测试对 `from 标准库模块 import 成员` 执行真实导入成员检查，拒绝错误模块和不存在的符号，保留合法导入。
- 增加重复调用、并发中止、审计异常跨阶段传播、任务级停止、错误正文不泄露和标准库导入正反样本回归。
