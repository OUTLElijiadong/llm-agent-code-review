## 沙箱 AI 失败快速停止与导入校验

- 将模型服务 HTTP 402 识别为计费或额度拒绝，返回安全、非敏感的明确错误，不再按普通模型故障重复请求。
- 源码上下文压缩遇到 402 后立即停止重试，并通知排队中的并发批次取消尚未开始的调用；已在途请求最多受现有并发上限约束。
- 动态用例生成遇到 402 时不再进行 Agent 内部或沙箱外层重复生成；事件记录保留 `billing_error`，不把确定性测试结果包装为 AI 动态测试成功。
- Python 生成测试对 `from 标准库模块 import 成员` 执行真实导入成员检查，拒绝错误模块和不存在的符号，保留合法导入。
- 增加重复调用、并发中止、错误正文不泄露和标准库导入正反样本回归。
