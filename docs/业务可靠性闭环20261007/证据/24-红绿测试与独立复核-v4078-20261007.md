## 修复前复现

对模块属性伪导出、预览端口环境映射变更与 route-only 回执依据错标添加复现用例。修复前运行结果为 7 failed、22 passed；原始输出见 [`修复前红测日志`](20-独立复核问题修复前红测-v4078-20261007.txt)。失败项确认了同名跨模块符号、环境删除回退和无动态断言回执文案不准确等具体问题。

## 修复后复测

- 将 Python 模块属性展开到具体源码模块导出，覆盖 `import ... as ...`、全限定模块引用、`from package import submodule` 以及跨文件同名伪导出。
- 扩展动态端口门禁，覆盖 `operator.delitem`、导入别名、`methodcaller` 及其导入别名；逐项测试保留安全来源作为对照。
- Runner 仅在动态断言实际执行后报告 `route_and_agent_assertions`；路由探活使用 `route_smoke`。解析器遇到 basis 与断言字段不匹配时拒绝回执。
- 沙箱相关五个测试文件共 200 项通过，3 warnings；见 [`修复后定向日志`](21-独立复核缺陷修复后定向回归-v4078-20261007.txt)。独立复核者对上述反例另外做了隔离执行，结果一致。
- 最终全后端回归 6,334 passed、6 skipped、6 warnings，83% 覆盖率；见 [`最终全量日志`](22-最终后端全量回归-v4078-20261007.txt)。
