# v4.0.80 Safari 复测中断与待验收范围（2026-10-07）

## 本轮实际完成

- 使用现有普通 Safari 窗口查看了先前的棱镜生产代码沙箱标签。页面仍显示旧页脚版本 v4.0.78，选中的任务为既有黑盒失败记录；这只是旧标签/旧任务观察，不代表 v4.0.80 页面状态。
- 尝试刷新现有沙箱页面时，Safari 前台页面发生变化。重新读取后发现用户已切换到另一个页面；为避免打断当前浏览，停止了后续 Safari 操作。没有打开无痕窗口。
- CUA 状态采集与浏览器发现多次超时；未用其它自动化通道绕过这一用户界面状态变化。
- 发布后通过公网健康、就绪、构建资源、备份/账本和运维巡检做了只读核验，证据见 68；这些检查不等于生产 Worker 的黑白盒任务执行。
- 本轮没有新建、重试、取消或删除生产沙箱任务。已有测试任务仍由产品 72 小时 TTL 保留；没有终态任务删除入口，不能说它们已即时删除。

## 恢复条件
