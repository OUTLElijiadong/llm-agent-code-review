# Prism v4.0.77 候选发布说明

## 沙箱与黑盒可靠性

- 修复 Backend 将内部来源修订/修复轮审计字段发送给严格 Worker 导致 HTTP 400 的契约冲突。
- 总结果不再由 Worker 成功状态或 exit code 单独决定；缺失、无效或失败的必需子步骤回执不能被汇总为通过。
- 黑盒重定向与鉴权响应不再冒充完整路由通过；根路径 `/` 回执作为合法路径解析。
- 失败、部分、未知覆盖范围在报告页分别标示；项目成员未获报告权限时不返回 coverage 细节。
- 源码上下文完整性校验、有限纠错重试和生成用例截断处理增加回归约束，预算不足时明确失败。
- 黑盒应用入口退出、启动崩溃和 HTTP 就绪超时现在产生结构化失败回执，并保留最多 4KB 启动日志用于定位。

## 验证

发布 SHA、后端/前端全量测试、构建、静态检查、发布故障注入以及生产复测证据在 `ACCEPTANCE_黑白盒可靠性.md` 更新。真实模型超过 1,000,000 token 的语义理解不纳入本版已验证结论。
