# 黑白盒可靠性原子任务

1. 将 v4.0.76 生产真实任务失败固化为证据，明确本地候选与生产状态边界。
2. 为 Worker 白名单、首轮/PHP 修复轮投影、成功状态聚合和缺失/错误/重复子步骤回执添加红测；修复后通过。
3. 为源代码分片、压缩、事实/引用、动态测试截断、调用/时间预算、执行清理添加正常、边界和异常回归。
4. 为本机和远程黑盒覆盖 2xx、3xx、401、403、404、5xx、根路径、断言失败、缺失/重复/伪造回执；先红后绿。
5. 覆盖黑盒启动异常：入口正常退出、启动崩溃和就绪超时均应返回结构化失败回执及受限启动日志。
6. 对项目列表/详情、报告 API 与普通成员角色核实覆盖信息权限；前端状态标签覆盖 complete/partial/unknown/failed。
7. 完整运行后端与前端全套测试、Ruff、compileall、Vue 类型检查、ESLint、Vite build、Shell 语法及发布脚本故障注入。
8. 检查精确候选版本、代码树洁净、依赖/迁移/Compose/备份隔离恢复与生产发布容量；按官方脚本发布。
9. 发布后先重跑真实项目 Python 白盒，确认请求字段和任务完整结果；获得结束与 Worker 清理确认后再运行不访问公网的 loopback 黑盒。
10. 将生产浏览器证据、发布 SHA、测试统计、遗留风险与本地知识库收据同步归档。
11. 对生产观察到的三轮 grounding 拒绝、白盒 `lower/status` 与黑盒无动态断言情形建立回归；补测 OS/getenv/environ 别名、固定端口、非回环 host 和未编码 payload。
12. 将生成失败归类为源码上下文、输入预算、超时、截断、模型调用、schema、配置、grounding 或真实执行契约拒绝；确认失败事件不再把模型问题统一误报为“结构无效/契约失败”。
13. 复测 AI 生成通过与拒绝/回退两条路径：AI 未执行不得显示为 AI 已通过；可确定性 runner 单独通过时报告需同时标示动态用例状态。

14. 增加动态端口来源改写红测：环境字典整体替换、字典别名赋值、`update`、`setattr(os, 'getenv', ...)`、环境映射增强赋值均需被拒绝；安全导入别名仍需通过。
15. 候选 v4.0.78 运行全后端/前端回归、静态检查和构建；重新核对生产 SHA 与 Safari 记录，恢复部署 SSH 公钥访问后才进行生产复测。
16. 复现并封堵 Python 模块属性跨文件同名 grounding、`operator.delitem`/`methodcaller` 修改动态端口、route-only 回执依据错标；分别执行修复前红测和修复后多变体回归。
17. 明示五种语言的源码 grounding 覆盖差异；未实现等价语言分析之前，不把运行时语法或进程通过写成应用行为覆盖通过。
18. 复现大源码引文校验失败后直接终止的场景；在不放宽来源和逐字引文校验的前提下实现无损递归拆分，并测小输入不可拆分时仍 fail-closed。
19. 复现 Node `type:module`/CommonJS 下测试扩展名和 `blackbox.mjs` 未执行问题；新 harness 固定 `.mjs`/ESM，旧 CommonJS `.js` 白盒用例兼容，黑盒成功/失败回执都必须真实来自脚本执行。
20. 复现 Java 动态白盒编译/执行 classpath 缺失项目类；两阶段加入可用项目输出目录，测试验证 classpath；真实 JDK/第三方依赖 Worker 环境列为未覆盖，不能扩大结论。
21. 复现离线依赖准备晚于应用启动以及普通白盒从未准备依赖的问题；在测试前准备缓存依赖，分别验证准备成功和缺失时的失败结果，不得假通过。
22. 复核超百万级源码与聊天压缩用例的完整覆盖、前中后锚点、原始会话不变及输入输出 Token 预算；合成模拟结果不得表述成供应商实测或真实语义理解证明。
