# 生产修复与交互闭环：实施共识

## 验收契约

| 需求 | 验收方法 |
| --- | --- |
| 输入非空 | 空串、Unicode 空白、二进制、空集合服务端拒绝，前端排除并说明原因 |
| 原子创建和稳定输入 | 任务与版本快照一次提交；失败无孤立任务；更新源文件不改变任务输入 |
| 真实结果 | 顺序、并行模型失败及部分失败不成功；合法零发现仍成功 |
| 状态闭环 | 分片边界及写入前核查状态/租约，删除和取消不会被旧执行者覆盖 |
| 同源统计 | 普通审查、沙箱、渗透报告使用各自实际结果，列表详情和仪表盘口径一致 |
| 操作反馈 | 异步选择不串项目、不静默截断、明确单文件圆桌、批量逐项结果、防重复提交、轮询错误可恢复 |
| 数据隔离 | 明确测试来源、隔离前后计数及权限、恢复清单可验证 |
| 工程交付 | 后端/前端回归、类型检查、lint、构建、迁移测试及独立复核 |
| 总览真实性 | 未知、失败、空数据、成功分别显示；权限拒绝暂停轮询；重试保留可追溯的旧结果 |
| 同版发布与恢复 | 精确 SHA 与语义版本一致；恢复前确定镜像；版本漂移不可被健康检查掩盖 |

用户已允许任务实施。生产发布本地提交和认证浏览器会话为单独门禁；未通过不得表述已发布或全部按钮已验收。
