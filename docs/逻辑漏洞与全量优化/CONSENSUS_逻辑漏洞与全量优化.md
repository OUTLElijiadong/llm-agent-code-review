# CONSENSUS_逻辑漏洞与全量优化

## 需求共识

本次任务按高风险优先修复平台逻辑漏洞，并同步完成测试与文档。交付后应满足：

- 普通用户不能通过猜测 ID 读取、启动、控制或修改他人资源。
- 讨论审与普通审查在项目/文件权限上保持一致。
- WebSocket 讨论会话绑定创建者，非创建者不能订阅或控制。
- 审查规则修改必须校验所有者或管理员权限。
- 用户自定义 AI API 地址不能让后端访问本机、内网、链路本地、组播或保留地址。
- 生产 Caddy 配置恢复 HTTPS-only，不提供 HTTP 明文应用回退。
- 前端重定向和外链符合基本安全交互要求。

## 验收标准

- 新增或更新后端单元测试覆盖：
  - 讨论审项目越权被拒绝。
  - 讨论 WebSocket 会话 owner 校验逻辑。
  - 任务问题列表越权被拒绝。
  - 问题详情越权被拒绝。
  - 规则启停/更新/删除越权被拒绝。
  - 自定义 API `base_url` 阻止 localhost/private/link-local 等地址，允许正常 HTTPS 公网域名。
- 后端 `pytest` 通过，至少新增测试所在模块通过。
- 后端 `ruff check app tests` 与 `compileall` 通过。
- 前端 `npm run build` 通过。
- Caddy 配置中 HTTP 入口只做 301 到 `https://lijiadong.cn{uri}`，HTTPS 入口保留 HSTS。
- `说明文档.md` 和本目录 ACCEPTANCE/FINAL/TODO 同步记录执行结果。

## 技术约束

- 遵循当前 FastAPI 依赖注入和服务层模式，不重写项目架构。
- 保留现有 `Resp` 响应结构和异常体系。
- API Key 只存储在 `.env` 或加密数据库字段中，不写入文档或测试输出。
- URL 安全校验应在保存配置、测试连接和解析运行时配置时统一生效，避免只修一个入口。
- 默认兼容公网 OpenAI-compatible 服务；内网模型服务放行必须显式配置。

## 任务边界

- 本次修复仓库内确定漏洞和可验证安全改进。
- 腾讯云域名备案、DNSPod webblock、控制台策略不在自动修复范围，只在 TODO 中保留操作指引。
