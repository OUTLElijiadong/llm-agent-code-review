# Prism 继续优化机会审计对齐

## 一、任务解释

本轮不是重复实现已经在 3.9.9 发布记录中标记为完成的功能，而是对当前代码和生产验收边界做一次结构性复核，找出会造成重复页面、历史不一致、账号隔离风险、输入校验遗漏、发布漂移或模型结果不完整的后续优化项，并按影响、证据强度和依赖排序。

## 二、已核对的范围

- 生产基线：3.9.9，生产验收记录声明前后端绑定同一提交、迁移、备份、health/ready 和自动化测试已通过。
- 会话：`backend/app/services/agent_mesh_service.py`、`backend/app/services/admin_chat_history_service.py`、`backend/app/api/v1/admin_copilot.py`、Responses/Mesh 相关模型与接口。
- 导航与权限：`user_capability_registry.py`、`page_guide_service.py`、维护/反馈路由及已合并的 `/support` 页面。
- 输入与数据：Agent Mesh、Agent Responses、维修工单 Schema、用户 ORM、MySQL 初始化 SQL、DeepSeek 配置与预算校验。

## 三、边界

实施范围已经扩展到业务代码、前端、合同测试和发布前验证；不物理删除历史消息、项目或审计记录。“存在 1m 配置”仍不等于“供应商真实支持 1m”；平台上传项目的 CodeQL 执行器也仍需外部 CLI/许可与隔离 worker 证据。

## 四、关键未决语义

1. 同账号跨 user/admin surface 活动会话硬上限为 10；先归档最旧空闲会话，10 条均运行/待操作时第 11 条返回 409。
2. 归档会话必须按当前 `user_id` 分页检索并显式恢复，不物理删除消息或审计账本。
3. 已发布自定义 Agent 是管理员审批后的平台级目录；普通目录不返回 `owner_id`，草稿和停用版本不可调用。
4. `/support` 是唯一前端、导航、能力注册和页面指南事实源；维修/反馈 API 保留为同一页面下的类型接口。

## 五、完成定义

每一项只能标记为“已修复并验证、阻塞或未通过”。本地测试不冒充生产发布；生产只在精确 SHA、备份/恢复验证、迁移、health/ready 和 HTTPS 冒烟都存在后标记完成。
