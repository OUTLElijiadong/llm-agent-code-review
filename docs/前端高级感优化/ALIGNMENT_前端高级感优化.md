# 前端高级感优化 · Align

## 原始需求

用户要求“马上修改”，基于上一轮前端方案审查结论，直接提升现有前端的美观度和高级感。

## 项目上下文

- 前端技术栈：Vue3、TypeScript、Element Plus、Pinia、ECharts、Monaco Editor、Sass。
- 现有设计基础：`frontend/src/assets/styles/variables.scss` 已有 Prism 品牌色、8 维度光谱、严重度色、中性色、阴影、布局变量。
- 现有问题：登录页品牌感较强，后台主界面仍偏传统管理台；页面级标题、卡片、按钮区、渐变、图标符号在多个页面内重复定义，视觉一致性不足。

## 任务边界

- 本次优先改造第一批高影响区域：全局布局、顶部栏、登录页移动端、仪表盘统计卡、安全态势卡、Agent 态势面板。
- 不调整后端接口、不更改业务数据结构、不引入新的 UI 组件库。
- 不做全站逐页重构，避免扩大风险。

## 关键决策

- 保留 Prism 棱镜视觉语言，但在后台页面中降低大面积光效，转为克制的产品工作台风格。
- 用 Element Plus 图标替代字符和 emoji，提升专业度。
- 通过全局 design token 和基础 utility class 承接页面高级感，而不是继续在单页硬编码。

## 验收标准

- `npm run build` 通过。
- 登录页桌面和移动端首屏无横向溢出，移动端保留轻量品牌识别。
- 仪表盘统计卡不再使用字符符号作为主要图标。
- 后台主布局、Header、关键卡片视觉更统一，且不破坏现有交互。
