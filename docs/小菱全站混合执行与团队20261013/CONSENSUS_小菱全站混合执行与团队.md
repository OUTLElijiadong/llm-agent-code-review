# 小菱全站混合执行与团队执行共识

复用两套页面能力白名单、OpenAPI 参数契约、真实 FastAPI 路由授权、现有 AgentTeam 持久任务/租约和监督器。小菱是唯一主控，页面执行子 Agent 是受限工作节点。

主控提交普通页面能力时自动创建执行+独立核验团队；按任务也能混用既有专职成员与临时成员。临时定义只保存职责，不扩大权限；执行仅由显式受控任务输入决定。低/中风险按现有策略自动执行，高/危急风险通过当前账号确认。未知能力、过期租约、身份变化和不明确执行结果均停止。

业务返回仅代表接受时不能报告完成。需要后台排队的能力回报真实状态；写入不自动盲重试。敏感一次性结果沿用主会话安全链，不进入团队持久结果。

缺口按页面实际 API 核实并登记；对凭据、多段上传、二进制导出使用专用流程，保持明确覆盖边界。
