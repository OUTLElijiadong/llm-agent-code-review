# 共识：小菱后台任务持久化与 3.6 侧边栏升级

## 行为契约

1. 浏览器关闭悬浮窗、切换会话、刷新页面或退出账号，仅断开客户端订阅，不向服务端发送取消指令。
2. 服务端任务不依赖浏览器连接存活；恢复页面后从数据库会话状态和事件账本重建 UI。
3. 后端启动时识别上个进程遗留的执行态：Responses 运行从检查点自动 retry；常规审查清除该任务的部分结果并从已选文件重新执行。
4. 等待审批、等待用户输入和用户主动取消的任务不自动恢复执行。
5. 同一运行通过检查点 claim 和工具执行账本防止重复副作用；同一审查任务通过进程内恢复集合防止重复派发。

## 版本契约

- 根目录 `VERSION` 是语义版本唯一来源，本次为 `3.6.0`，界面展示 `v3.6`。
- Git 完整 SHA 继续作为不可变部署 release；语义版本与 SHA 同时进入后端健康接口和前端构建。
- 发布脚本必须校验 `VERSION`，并将 `APP_VERSION`、`VITE_APP_VERSION` 传给镜像。

## 验收标准

- 关闭悬浮窗与退出登录后，任务在服务端进入完成/失败/取消/等待人工动作之一，不停留于前台假运行。
- 重启后 Responses 与常规审查可自动恢复；恢复失败会落真实 failed 和错误原因。
- 小菱历史会话重开仍能显示运行状态、团队卡片和最终结论。
- 桌面侧边栏具备悬浮岛、分组折叠和整体收起；角色可见项与原实现一致。
- `/healthz`、`/readyz` 同时返回 `version=3.6.0` 和精确 release SHA。
- 后端、前端、部署脚本测试及公网浏览器验收全部通过。
