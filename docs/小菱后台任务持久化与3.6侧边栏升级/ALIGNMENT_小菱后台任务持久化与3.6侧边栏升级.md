# 对齐：小菱后台任务持久化与 3.6 侧边栏升级

## 原始需求

- 关闭小菱悬浮窗、切换对话或退出账号后，已启动任务继续在服务端执行直至终态。
- 审计任务及小菱调用的其他长任务遵循相同后台语义。
- 服务或容器重启后，从持久化状态自动恢复可继续的任务；确需人工审批的任务继续等待审批。
- 本次版本升级为 3.6，并固化版本号发布流程。
- 侧边栏改为悬浮岛式、分组可折叠结构，不改变现有路由和角色权限。

## 已核实上下文

- 生产开发者论坛已有 2026-08-12 与 2026-08-15 的 v3.5 发布公告，因此本次版本为 v3.6。
- 当前生产侧边栏仍显示 v3.4，版本展示与论坛发布状态不一致。
- 小菱前端组件卸载时会主动中止 SSE；后端在客户端断开时会保护当前协程，但进程重启只会把遗留运行标记失败。
- 常规审查使用后台线程和独立数据库会话，关闭页面不影响执行；进程重启后当前实现会把任务标记失败而不重跑。

## 范围

- Responses 检查点运行的断线续跑和重启恢复。
- 常规代码审查任务的重启恢复与结果幂等清理。
- 小菱悬浮窗卸载、会话切换的本地订阅语义。
- 单一版本源、前后端健康接口和发布脚本传递。
- 桌面侧边栏悬浮、分组折叠、整体收起；移动端继续使用抽屉。

## 明确不改变

- 用户主动点击停止时仍取消服务端运行。
- 审批与补充信息是业务等待态，不得绕过或自动批准。
- 路由、后端 RBAC 和数据权限不变。
- 已有 Agent 团队、审计、沙箱和报告能力不删减。
