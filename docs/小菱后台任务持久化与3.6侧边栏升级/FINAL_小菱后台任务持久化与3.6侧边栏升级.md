# 最终报告：小菱后台任务持久化与 3.6 侧边栏升级

## 完成内容

- 小菱 SSE 执行改为独立数据库会话和进程级后台任务引用；关闭悬浮窗、切换会话、刷新或退出账号只断开订阅。
- Responses 启动清扫和恢复调度使用既有检查点、CAS claim 与工具账本；等待审批/等待输入不被误清理。
- 常规审查新增数据库 `execution_token`，重启恢复只允许一个 Worker 换发租约；旧 Worker 不能覆盖新结果。
- 沙箱保存原始源码、实际 Worker 执行归档、摘要、修复轮次和执行租约；启动时校验 SHA 后按相同 request_id 复用相同输入恢复白盒/黑盒/组合测试，无快照或校验失败会真实失败关闭。
- 版本唯一源为根目录 `VERSION=3.6.0`；健康接口、前端构建和发布脚本同时校验语义版本与 Git SHA。
- 侧边栏改为带分组、整体收起、tooltip 和移动端抽屉兼容的悬浮岛结构，未改路由与角色过滤。

## 验证结论

代码静态检查、Python 编译、前端 lint/类型检查/生产构建、部署 Shell 契约、后端相关 146 项回归及侧边栏 2 项组件回归均通过。当前尚未执行本次代码的公网部署，因此生产版本仍不能宣称已切换为 3.6。

## 生产边界

Responses 工具在“副作用已发生但结果提交前进程崩溃”窗口只能安全收敛为失败，不能凭空证明外部写操作已经完成；需要具体工具提供幂等键和结果查询才能进一步提升恢复语义。该边界已写入设计和验收，不伪装为 exactly-once。
