## 本次候选修改

- 小菱圆桌经已鉴权 REST 停止路径持久取消，防止迟到进度或重连把终态任务恢复为运行中；应用不会继续启动后续 Agent 阶段。已经发到供应商的在途请求是否停止计费取决于供应商能力，不能由应用状态推断。
- 报告列表、详情与导出按对象归属、全局权限及来源权限一致过滤；缺少访问权限或来源快照/关联不完整的报告不形成卡片，详情/导出拒绝不完整数据。
- 沙箱与渗透报告只展示有明确来源凭证的成绩。无有效评分依据时展示未评估，不把占位 0 或任务状态推成真实分数。
- 管理员助手入口调整为页头入口，避免覆盖管理列表操作区。
- 漏洞来源展示优先级按用户决定标注 CNVD、CNNVD；只有官方精确记录凭证才标为官方匹配，否则 OWASP 仅作兜底。当前未接入官方授权数据。
