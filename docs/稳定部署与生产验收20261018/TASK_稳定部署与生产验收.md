# 稳定部署与生产验收任务

## 任务 1：修复与定向回归

- 输入：候选版本 4.1.6、圆桌停止和远程评估列表代码。
- 输出：REST 停止路径、持久取消状态、终态不可复活保护、审批人列表过滤和回归测试。
- 验收：相关后端用例、前端圆桌测试、Ruff、ESLint、编译与差异检查通过。
- 依赖：无。

## 任务 2：冻结候选并正式发布

- 输入：任务 1 完成的工作树、未修改的 `VERSION=4.1.6`、干净生产部署源路径。
- 输出：单一提交 SHA、通过 SSH/SCP 传输的 Git bundle、生产发布账本回执。
- 验收：生产端检出 SHA 与本地一致，`deploy.sh all --revision <SHA>` 成功；备份、恢复、迁移、前后端构建切换、健康、HTTPS 冒烟均有真实回执。
- 依赖：任务 1。

## 任务 3：生产账号与报告验收

- 输入：已部署 release、现存真实账号与报告数据。
- 输出：按身份记录菜单/列表/详情/导出/用量图的真实可见性与错误证据。
- 验收：不越权、不显示无法读取的报告卡片；报告来源、状态、评分/覆盖和格式与真实执行相符；所有未覆盖项列入 TODO。
- 依赖：任务 2。

## 任务 4：文档和知识治理收尾

- 输入：部署与验收真实结果、预检收据。
- 输出：更新 ACCEPTANCE、FINAL、TODO、发布说明；运行知识库 validate 与 postflight。
- 验收：文档不把本地自动化或健康检查冒充业务验收；主库仅写入经证据确认、可复用的信息。
- 依赖：任务 2、任务 3。
