## 本轮收尾增量验证

在上述候选实现上，继续补了多项边界修复：圆桌停止后 WebSocket 重连时按新连接重发停止请求；报告任务成功但覆盖验证失败时按“验证未通过”显示；渗透任务的覆盖状态检查失败、跳过、未完成及未知状态；重复停止不再用简化兜底报告覆盖已有完整报告，而浏览器黑盒追加新失败证据时仍更新报告。沙箱报告发布遇到数据库异常时最多重试三次，沿用幂等报告任务，避免暂时性断连造成只有测试结果而没有报告卡片。

本轮增量验收：前端相关测试 150 项通过，前端 ESLint、`vue-tsc` 和 Vite 构建通过；后端报告、渗透、停止和权限相关定向组 350 项通过；全部改动 Python 文件 Ruff 检查通过；部署脚本测试与故障注入矩阵通过；`git diff --check` 通过。终态报告写入受沙箱环境行锁保护，ReviewTask、ReviewReport 与既有报告附件查询使用 `SELECT ... FOR UPDATE` 当前读，报告正文及附件内容、字节数和 SHA-256 在同一事务同步。若 AI 报告正文首次无法持久化，系统会把状态改成未完成，改用确定性执行报告并再次写入，避免终态把不可见的 AI 报告标成完成。自动化测试使用 SQLite，不能证明生产 MySQL 隔离级别下的并发竞态；需保留此限制并补做生产环境验证。命令和退出码见 [测试证据](TEST_EVIDENCE_报告生成与小菱停止修复.md)。以上是本次增量回归结果，不替代最终候选 SHA 的全量 CI 与生产验收。

管理员总览的每日 Token 用量日历热力图、用量波形、空值/缺失数据区分和选中日明细已存在于本候选，动效支持 `prefers-reduced-motion`；团队进度用不改变服务端完成比例的阶段流光表达等待。此次增量只记录功能核对，不把这些页面动效误报成生产浏览器验收。

CNVD 与 CNNVD 仍是两个独立官方来源，目前尚未接入官方数据同步或精确匹配；现有来源说明与 OWASP 兜底不等于已查到国内库记录。获取获准使用的数据接口、账号或数据文件并完成字段及来源核验后，才能关闭此项。
