## 已完成的产品修复

- 报告列表、详情与导出统一执行对象归属、通用权限及安全/渗透来源权限；没有访问权限或来源快照/关联无效的报告不形成可见卡片，直接详情/导出明确拒绝。
- 沙箱、渗透评分按可核验证据展示。未知值不伪造成 0；动态评分需要动态用例生成回执与逐项结果数量吻合。
- 报告来源快照、正文缺失和来源关联异常均有明确错误路径；不能把不完整快照包装成完整报告。
- 远程评估报告详情、重试和导出失败有明确状态；失败读取不保留过期内容。
- 管理员小菱入口使用管理页标题栏位置，避免覆盖管理列表操作区域。
- 小菱圆桌增加已鉴权 REST 停止路径、服务端持久取消与迟到事件保护，阻止取消后继续启动后续 Agent 阶段。已发送到模型供应商的在途请求是否停止计算或计费不作推断。
- CNVD/CNNVD 展示按用户指定顺序优先；只有官方编号/链接精确证据才标记官方命中，未知状态不把 OWASP 分类说成官方匹配。
