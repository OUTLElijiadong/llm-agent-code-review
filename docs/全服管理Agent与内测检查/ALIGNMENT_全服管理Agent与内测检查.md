## 不变边界

- 应用容器不得挂载 Docker Socket，也不得直接获得宿主机 Shell；Root 能力只通过本机 Unix Socket 执行器进入。
- 不向模型返回 `.env`、私钥、密码哈希、SSH 密钥、`/etc/shadow` 等敏感内容。
- 不提供任意 Shell、任意 argv、任意 SQL 或自定义脚本执行接口；完全权限由覆盖整机对象的结构化动作组成。
- 不提供任意管理 API 路径、任意 HTTP 方法或任意请求体；只能调用注册表中绑定页面、方法、路径、权限和风险的固定能力。
- 不把密码、Token、私钥或完整敏感文件内容写入数据库审计、SSE、systemd 日志和工具结果。
- 不自动重启、停止或改写 FlyTrap 及其他非本项目服务；只有管理员对精确动作完成 critical 确认后才能执行。
- 不把腾讯云安全组、DNS、备案状态等外部控制面能力伪装成服务器本机能力。
