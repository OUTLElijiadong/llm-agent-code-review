# 任务：外部审查问题核验与修复

## T1 报告逐项核验

- 输入：R2–R10 合订报告、当前候选代码、已有测试和可读生产页面。
- 输出：逐项 evidence matrix，区分生产观察和候选验证。
- 验收：不将报告旧状态直接视为当前漏洞。

## T2 可控代码修复

- 输入：确认且可由仓库修复的问题。
- 输出：最小代码改动、回归用例、相关 CSP/部署合同。
- 约束：保留当前工作树既有改动；本机 Docker 保持关闭；生产容器只读查询，不发布或改配置。

## T3 Agent 长上下文复核

- 输入：对话预算、ReviewAgent、Agent Mesh、Orchestrator 发送和恢复链路。
- 输出：实际输入序列化字节与预算门限回归、规则拆分恢复回归。
- 验收：超过窗口时安全压缩/拆分或显式报告覆盖不足；不可宣称 1M tokens 上下文完整，除非各模型窗口、预算和实际内容均能证明。

## T4 候选质量验证

- 输入：完整候选 diff。
- 输出：前端全测/lint/build、后端全测、部署合同、diff review。
- 验收：失败必须修复或说明阻塞，不隐去失败。

## T5 外部运维边界

- 输入：公开 8888、证书和 SSH 端口只读响应。
- 输出：三次观察及生产控制面待办。
- 验收：不从 TCP banner 推断主机配置，不将不可访问控制面写成已修复。
