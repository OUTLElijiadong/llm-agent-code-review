# 共识：外部审查问题核验与修复

## 需求与验收标准

1. 每条报告发现要标记为：已确认并修复、已确认但保留/部分修复、未复现/报告不适用于当前候选、生产待验证；每个结论写明触发范围与证据。
2. 修改遵循项目现有权限和数据边界；本机 Docker 保持关闭，生产只读验证。不开无痕浏览。
3. 候选前端：全量 Vitest、ESLint、Vue 类型检查与 Vite build 通过；部署脚本静态测试通过。
4. 候选后端：全量 pytest 通过；长上下文预算和 Agent 团队规则压缩缺口有原触发回归，必要时标注部分支持，不能宣称“无限/100 万 token 已完整理解”。
5. CSP 候选改为强制策略，禁用脚本内联与事件属性，WebSocket 来源限制到当前 Host；生产部署后仍需验证实际响应 CSP 与主流程兼容性。
6. 生产端口/证书/SSH 观察至少三次；已核对主机 SSH 配置和系统级 Certbot timer/cron；BT-Panel 续期计划和腾讯云安全组单独列出。

## 技术方案

- 复用既有项目组件、服务层和测试，采取小范围前向修复；独立 Agent 复核长上下文预算与团队分片恢复缺陷。
- 静态站点没有内联脚本块，唯一事件处理器是字体 preload 的 `onload`。移除事件属性并改用同源 defer 脚本；CSP 用 `script-src 'self'` 与 `script-src-attr 'none'` 强制执行，不引入无必要的每响应 nonce 机制。
- Vue 仍使用运行时 style 属性，故 `style-src 'unsafe-inline'` 暂留并明确记录；后续要去除须先逐页验证样式改造。
- CSP 的 WebSocket 限制为 `wss://$host`，仅允许当前站点主机名；外部模型 API 由后端代理，候选探测的浏览器网络用法仍需构建与生产兼容性复测。
- BT-Panel 监听公网 8888，用户已选择暂不修改腾讯云安全组。systemd、cron 和 BT-Panel 任务表均无证书续期任务；所有现存证书 ACME staging dry-run 已通过。OpenCloudOS SSH RPM 安全回补状态仍待核；不通过产品容器 Nginx 推断或修改主机设置。

## 范围与限制

- 本文档不授权删除生产数据、修改腾讯云安全组、升级/重启 SSH 服务或服务器软件。
- 不把算式验证码自动求解难度冒充成验证码答案泄漏，也不在无明确产品决策/供应商授权时接入第三方验证服务。
- 本地/候选通过不能被写作生产发布通过。
