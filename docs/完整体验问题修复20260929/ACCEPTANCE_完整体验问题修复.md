## 候选复现与修复

| ID | 复现 | 修复 | 修复后验证 |
|---|---|---|---|
| ACL-01 报告导出与摘要权限不一致 | 隔离数据库中，具备格式导出权限但无 `report:view` 时，新旧报告导出出口行为不一致；列表/详情对同项目成员暴露沙箱/渗透报告统计与评分，即使 `can_view_report=false` | HTTP/MCP/Agent 导出统一先验 `report:view` 与对应格式权限；沙箱 `review_report` 元数据和下载检查报告权限及 owner/admin 对象范围；沙箱/渗透任务列表与详情以相同能力掩蔽摘要、总数、严重度、评分及评分明细；列表不加载无权查看的沙箱 Markdown。前端受限显示“报告受限”，普通代码审查统计不变 | 隔离 SQLite/JWT HTTP 回归覆盖 sandbox_test 与 pentest、任务列表与详情、报告 owner/审查员成员及两种无权限组合；无权限时敏感聚合字段均为 `null`，有权限 owner 的原值保持；重复成员授予 `report:view` 仍因非 owner/admin 被拒绝。无权视图显示权限提示；有权限但渗透计数为 `null` 时显示“—”，不会伪装成 0。相关后端及前端定向测试通过。Agent `download_report` 缺权时不解析报告、不返回链接；普通测试制品仍按原规则可读。生产未触发导出/下载路径 |
| UX-01 reviewer 显示名分裂 | 生产角色表页面可见“评审员”名称和“审查员”描述 | 前端显示、授权错误和 Agent 提示统一为“审查员”；数据库角色名称、RBAC 编码和权限不改 | 角色格式化/保存保留测试；无权访问授权队列返回规范称谓 |
| UX-02 运维计划难读及前后端校验不一致 | 生产计划有值但无辅助解释；前端先转小写且不校验每字段范围；还拒绝 APScheduler 支持的 `mon` / `jan` 名称 | 已验证格式用中文解释，原始值保留；大小写规则与后端一致，按分/时/日/月/周逐字段校验范围与步进，并支持月份、星期英文缩写 | 原始计划展示与保存回归；非法大小写、越界、倒置范围、步进零及未知名称拒绝；合法数字和名称 Cron 保持可用 |
| UX-03 监控统计误读 | 后端数据聚合粒度不一致，页面没有解释 | 分开说明工具/调度/奖惩累计、审批事项当前状态、当前未关闭告警 | 使用当前生产量级的隔离统计样本断言数字卡片、标题、说明与空态 |
| UX-04 用户列表被角色请求阻塞 | 将角色 API 挂起时，原实现直到角色返回才请求用户列表 | 页面挂载时并行请求用户和角色目录；仅角色编辑对话框等待目录，失败有错误提示 | 延迟角色 API 的回归证明用户列表先显示；角色目录失败时不影响用户列表 |
| UX-05 圆桌分页异步状态 | 旧分页请求 pending 时切换账号，或同账号列表刷新使分页结果过期时，`finally` 可能清不掉 `moreLoading`；账号切换还可能污染新请求状态 | 同账号刷新后，过期分页结果被丢弃但仍释放该账号 loading；切换账号的旧 finally 不可清新账号状态 | 同账号列表变更刷新+迟到分页响应后可再次加载；切换账号的旧/新请求乱序样本通过且不显示旧会话 |
| UX-06 AI 调用日志首载 | 首次 API 请求 pending 时需保证不会将空数组显示成“没有调用记录” | 明确只在请求完成且成功为空时显示空态 | 新增 pending→空成功与失败→重试组件测试 |
| UX-07 审批统计列名与空态 | 统计说明已称“审批事项当前状态分布”，列名仍写“次数”，空态仍称“审批渠道” | 审批状态表使用“状态 / 事项数”，空态改为“暂无审批事项状态记录”；工具执行仍用“结果 / 次数” | 管理台观测页面回归同时检查两个统计口径及审批成功空态 |
| UX-08 管理工作台切换模式时旧请求污染 | 审批列表仍 pending 时切换到其他管理页，旧响应会写回隐藏审批状态，且会提前清除新页共享 loading | 管理页请求使用当前模式与请求代次保护；切换模式立即失效旧代次并重置加载状态；知识页子请求另校验当前 Agent | 先让审批请求 pending，再切换到任务计划页并延迟返回；旧审批不写回、不清新页 loading，新页响应完成后正确解锁 |

- 告警列表 API 当前默认最多返回 100 条；本轮生产总数卡片为 100。新增 105 条样本的本地隔离验证得到计数 105、列表 100，确认超过 100 时列表会截断。是否需要分页取决于生产告警量与业务需求；本提交未修改该接口，也未用合成生产数据验证。

- 未逐个恢复并对照全部历史重复 `session_id` 的消息 owner；跨账号全量历史隔离不因本轮局部权限测试而全部验收。
