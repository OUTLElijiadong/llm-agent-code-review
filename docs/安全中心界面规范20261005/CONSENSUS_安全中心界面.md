# 安全中心界面共识

1. 删除指定的两段长文和对应黄色说明区域。
2. 用“安全概览、事件记录、防御策略”三个页内分区组织现有功能，切换时保留状态和未保存草稿。
3. 默认事件范围以活动记录为主，成功巡检采集单独可查；筛选必须在服务端计数和分页前生效。
4. 详情、固定保护来源和规则解释按需展开，保留完整可读数据。
5. 使用现有颜色、字体和间距令牌；主要控件具有键盘焦点、关联标签和移动端触摸尺寸。
6. 错误、未知、过期和执行未确认各自显示真实状态；不以规则命中代替封禁生效。
7. 先复现后修复，完成单元测试、类型检查、构建、独立代码复核和普通 Safari 真实点击；发布后重复页面场景。
