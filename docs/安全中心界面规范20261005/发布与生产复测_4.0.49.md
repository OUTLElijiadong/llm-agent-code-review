## 真实生产场景

使用普通 Safari，未开启无痕。管理员实际登录后，点击安全中心三个分区、活动/巡检/全部分组、24 小时/7 天/30 天范围、事件详情及活动第二页。权限通过实际三账号登录与读接口检查：管理员 200；匿名 401；审查员与普通用户均 403；非法分组 400。三账号均实际退出验收 API 会话，不保存密码或令牌。

三分组第一页面各重复三轮，核对分类和时间倒序；每个分组第二页实际读取一次，五个样本与对应第一页不重叠。浏览器草稿场景重复三轮；不将所有点击、时间筛选或分页描述为浏览器三轮。计数为实际查询快照，达到单源读取上限的结果显示“至少”，不同分组或不同时刻不能直接相加比较。

4.0.48 原场景中 `collector:145272`，记录时间 `2026-10-05T07:17:39Z`，状态为 `running` 但错误显示采集失败。4.0.49 三轮均找到同一记录，显示“采集进行中，结果尚未返回。”、严重度 info；每轮同时观察到另外两个进行中样本，十二个原失败样本仍保留失败摘要。原场景浏览器截图：[状态修复](证据/18-生产4.0.49采集状态修复.png)。没有修改原执行状态或伪造成功。

自动封禁只读回执采样时 `available=true`、`verified=true`、`outcome_unknown=false`、`enabled=true`、`active_count=0`。这只是该时刻已核验的启用状态，不能替代攻击防御效果测试。
