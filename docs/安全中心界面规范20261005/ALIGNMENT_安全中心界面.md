# 安全中心界面对齐

## 用户原始要求

不在安全中心显示“证据边界”“日志覆盖范围”两段长说明，完全优化安全中心 UI 和 UX，设计规范化。

## 现状与范围

- 当前生产基线为 4.0.47；真实普通 Safari 已登录最高管理员并打开 `/admin/security-center`。
- 两段文字是 `AdminSecurityCenter.vue` 的静态说明，不属于后端业务数据。
- 当前页面把概览、资源、完整封禁表单、长时间线、监控策略和能力说明串成一页。正文和辅助字号过小，成功采集记录淹没活动事件，保护来源重复展示。
- 修改管理员安全中心、自动封禁展示及其所需的兼容事件分组查询；用户侧项目安全标准页面不在范围。
- 保留现有权限、监控阈值限制、封禁回读确认、到期核验和操作审计。未授权的新能力不纳入本次重构。

## 设计选择

用户已明确选择“沿用现有风格并规范化”：采用现有 Prism 紫色、浅色卡片、盾牌源资产与设计令牌。
