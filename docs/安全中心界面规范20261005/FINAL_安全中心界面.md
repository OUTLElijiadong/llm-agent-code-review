# 安全中心界面规范化交付

本轮沿用棱镜现有紫色、浅色卡片与盾牌标识，删除用户指定两段长文，整理信息层级和编辑交互。

## 完成范围

- 概览突出监控、待处理告警、数据源和最近巡检；资源用有标签的进度展示，未知值不伪装成零。
- 事件分为安全活动、巡检采集、全部记录。正常空封禁核验归入巡检；异常回执保留在活动。分类先于计数和分页，达到单源上限明确显示下界。
- 详情、规则和固定保护来源默认折叠；重复保护来源合并展示原因。桌面固定状态/操作列，手机顺序排列。
- 自动封禁和监控策略显示修改状态、恢复与保存反馈；刷新、页签切换保留未保存草稿。
- 保留现有最高管理员鉴权、策略约束、执行回读和未知状态边界，不增加反击能力。
