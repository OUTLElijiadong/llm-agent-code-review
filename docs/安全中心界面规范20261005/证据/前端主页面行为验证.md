## 20 项主页面行为覆盖

1. 默认安全概览、服务端最近活动 5 条与删除两段旧声明。
2. 左右方向键、Home/End、焦点与页签/面板 ARIA 关联。
3. `outcome_unknown=true` 时页头保持待核验。
4. 数据源入口选择巡检分组并将焦点带到事件页签。
5. 页签切换保留自动封禁组件和草稿，不重复获取事件。
6. 服务端记录类型与时间筛选，重置页码、失败清空旧列表与重试。
7. 快速切换筛选只显示最后一次请求，概览查询独立。
8. 全页刷新与筛选重叠时分别隔离事件/概览请求。
9. 服务端总数与分页，数据缩减时回退有效末页。
10. 证据默认折叠，使用原生 `summary.click()` 核验 `details.open`。
11. 布尔字段按启用、截断、例行和核验含义翻译。
12. 告警处理传入说明并刷新统计与活动。
13. 保留失败、降级数据源名称和状态。
14. 概览读取失败以未知展示，策略草稿状态待核验并可重试。
15. 巡检过期、长时间运行、缺少完成时间与停留后的过期刷新。
16. 资源 `null` 不显示未知百分号，合法 `0` 显示进度与 0 分钟。
17. 资源读取失败隐藏旧进度，保留重试。
18. 刷新/切页签保留监控草稿，重置使用最新服务端配置。
19. 监控保存只提交现有四字段，成功/失败反馈与草稿保留。
20. 立即巡检报告数据源异常并重新读取记录。

## 实际浏览器边界

浏览器和多个视口的视觉验收由根代理在普通 Safari 完成。当前预览的只读代理连接旧生产 API 时，新增 `event_group` 参数尚不能证明新分组已在生产生效；服务端分类与总数正确性另由后端测试验证。前端没有对当前分页做筛选以伪装全量分类。

最后一次 320px 观察发现页头副标题越过右内边距，已将移动布局 `hero-main` 约束为 `width:100%`，并给 `hero-copy` 设置可收缩的 flex 与文本换行。最终视觉证据另存于本证据目录。
