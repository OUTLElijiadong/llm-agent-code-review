# 采集状态文案修复验收

日期：2026-10-05。候选目标版本：4.0.49。

## 已复现的问题

父代理在生产 4.0.48 的真实管理员页面点击中，看到记录时间 16:54:36 的 SSH 日志/运行环境采集事件状态为 running、界面显示“进行中”，但摘要却显示“采集失败，相关数据源当前存在监控盲区。”。现场摘录保存在同目录 `生产采集状态文案复现.txt`。这是采集记录读模型的摘要映射错误，不能据此把运行中的采集任务判为执行失败。

## 最小修正

仅修改 `backend/app/services/security_center_service.py` 的 collector 摘要与严重度，未改事件分组、任务状态或执行接口。

| 原记录状态 | 严重度 | 摘要 |
| --- | --- | --- |
| running | info | 采集进行中，结果尚未返回。 |
| success | info | 只读采集器执行回执；未执行封禁或反制。 |
| failed | warning | 采集失败，相关数据源当前存在监控盲区。 |
| 其他状态 | warning | 采集状态待核验，当前回执尚未确认。 |

返回的 status 仍使用原记录值。success/failed 的既有文案与严重度保持不变。
