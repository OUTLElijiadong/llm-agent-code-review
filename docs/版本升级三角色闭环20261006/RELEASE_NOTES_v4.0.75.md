# v4.0.75 发布说明

## 变更

- 首次异步加载的仪表盘与报告分数直接显示最终值，避免读取完成提示出现时数字仍处于滚动动画中间帧。
- 后续统计变化仍沿用平滑数字动画。

## 验证范围

- 新增首次异步值回归测试；验证后续更新仍动画、reduced-motion 更新即时落地、组件卸载会取消动画帧。
- 报告详情回归验证：风险文案和颜色按接口最终分数计算，不依赖动画中间值。
- 候选全前端 Vitest 142 文件、1846 项通过；ESLint、`vue-tsc` 类型检查与 Vite 生产构建通过（3742 模块）。

此版本不修改后端统计 API、统计口径、账号权限或生产业务数据。普通用户此前观察到的仪表盘数字变化尚未取得同一时点的 API 原始响应；UI 动画以外的数据层因素仍未核实。
