# v4.0.74 发布说明

## 修复

- 审批中心根据服务端来源核验状态展示 Responses 会话审批指引。只有来源已核验时才说明关联当前管理员会话并提供返回入口；来源未核验时明确无法确认原会话，不再要求返回未知会话，也不提供跳转按钮。
- 本修复只涉及管理员审批列表和详情文案，不改变审批记录、审批状态、全局模型配置或账号权限。

## 验收范围

- 前端审批详情单元测试同时覆盖已核验与未核验来源。
- Playwright 覆盖 320px、390px 未核验详情布局，以及已核验来源状态和返回入口。
- 生产发布后的版本、服务健康、运行 SHA、审批数量和详情文案需另记于验收证据；仅有本说明不代表已发布。
