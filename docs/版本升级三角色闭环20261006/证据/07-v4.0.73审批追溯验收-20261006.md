## v4.0.73 候选实现

- API 仅在当前管理员 owner、admin surface、运行 ID、资源 ID、请求摘要一致，并且运行状态与检查点处于 waiting_approval 时，才核对检查点内的本条 approval ID、call ID、工具名和规范化参数；参数使用与审批保存相同的规范化器，并以规范化 JSON 保留 bool/int/float 类型差异。

- 独立只读复核确认每条候选重新解析对应审批参数；此前复核发现的未定义变量、跨条目参数串用和 bool/int 宽松比较均已修复。
