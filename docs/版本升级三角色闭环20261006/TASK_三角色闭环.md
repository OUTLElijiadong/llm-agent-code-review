# 三角色闭环任务

1. 只读核新版本、工作树与生产基线，比较4.0.50至4.0.71功能入口/注册/权限。
2. 并行核论坛、反馈、角色导航和权限登记；主代理在普通 Safari 复现管理员入口与当前管理员看到的反馈列表。
3. 修复已证实的管理员社区入口、管理员帖子编辑、异步覆盖/读取失败状态、键盘访问和反馈空回复/状态/已读/刷新链路；渗透入口一并恢复。现有角色和管理权限不扩大。
4. 先红后绿跑论坛/反馈专项、布局/RBAC专项、权限矩阵、前后端类型检查、ESLint和生产构建；独立审阅测试范围与边界。
5. 管理员在正式发布后发布真实版本更新公告；三角色实际读取、刷新并核对论坛权限。反馈用三个现有账号核查本人范围与管理员全局范围；不创建测试反馈，不改动历史反馈。如无适合且获授权的真实反馈，不在生产实弹回复状态变更。
6. 复核安全发布脚本、当前容器标识和备份/恢复门禁；授权发布后按原场景复测和多宽度Safari检查，核知识库validate/postflight及最终待办。

依赖：1→2→3→4→5→6；论坛、反馈、权限矩阵可并行。真实登录和生产写操作由主代理串行完成，子代理不登录、不发布或审批。
