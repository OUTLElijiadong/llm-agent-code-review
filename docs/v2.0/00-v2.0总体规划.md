# 棱镜 Prism v2.0 总体规划

> 版本：v2.0 · 状态：开发中 · 起始日期：2026-05-27

## 一、v2.0 立项动机

v1.0 已交付完整的多 Agent 代码审查闭环（项目/文件/规则/审查/问题/报告/仪表盘 + 11 个 Agent + DeepSeek V4），但用户实际体验中暴露出三类问题：

> 当前状态补充（2026-06-05）：v2.0/v2.1/v3.0 后续能力均已并入主项目,当前运行时注册中心为 14 个 Agent。本文保留 v2.0 立项时的历史数字,实现现状以 README、说明文档和 `/api/agents/runtime` 为准。

1. **态势感知不足**——用户看不到 Agent 在干什么，每次调用都是黑盒。
2. **Agent 中心与实际注册中心数据不一致**——前端只展示 5 个静态画像，后端真正运行 11 个 BaseAgent。
3. **缺少"AI 协作出口"**——审查发现问题后，用户想用其他 AI（Cursor/Copilot/ChatGPT/Claude Code）修复，平台没有提供精准提示词。

v2.0 围绕"**让多 Agent 体系可见、可感、可对话、可协作**"做能力升级。

## 二、v2.0 核心目标

| 编号 | 目标 | 验收口径 |
|---|---|---|
| G1 | Agent 办公室（Marvis 风格） | 每个 Agent 一个独立工位卡，有 SVG 图标 + 状态光环 + 工作动画 |
| G2 | 态势感知面板 | 实时显示当前活跃 Agent 数、任务队列、近 1 小时调用波形、热点 Agent |
| G3 | Agent 调用反馈链 | 每次调用在前端流式展示：调度 → 思考 → 执行 → 完成（含模型、token、耗时） |
| G4 | 主 Agent 编排 | ChatAgent 调用 Orchestrator 操控所有专业 Agent；展示编排路径 |
| G5 | Agent 主动提问 | 关键字段缺失时不再猜测，主动追问用户（例如缺 project_id 就问） |
| G6 | Agent 中心数据同源 | UI 直接来自 AgentRegistry + Profile + Usage，注册数变化自动反映 |
| G7 | AiPromptAgent（新成员） | 把审查问题转为可粘贴给 Cursor/Copilot/ChatGPT 的提示词，含文件路径、行号、修复建议 |
| G8 | 修复 v1.0 图表数据问题 | 维度键值归一化、空数据兜底、字段缺失时显示真实状态而非占位 |

## 三、能力分层

```
┌────────────────────────────────────────────────────────────┐
│  前端（Vue3）                                              │
│  ├─ Agent 办公室视图（AgentOffice.vue）                    │
│  ├─ 态势感知面板（SituationPanel.vue）                     │
│  ├─ 升级版 AgentChatDrawer（带步骤反馈）                   │
│  ├─ AI 提示词生成视图（AiPromptStudio.vue）                │
│  └─ 公共组件：AgentAvatar / AgentStatusRing / StepStream   │
├────────────────────────────────────────────────────────────┤
│  后端（FastAPI）                                           │
│  ├─ /api/agents/runtime         真实注册中心 + 实时状态    │
│  ├─ /api/agents/situation       态势汇总                   │
│  ├─ /api/agents/events  (SSE)   调用事件流                 │
│  ├─ /api/agents/clarify         主动提问回填               │
│  ├─ /api/ai-prompt              AiPromptAgent 出口         │
│  └─ Orchestrator 内嵌 EventBus，发布每次调度事件           │
├────────────────────────────────────────────────────────────┤
│  Agent 层（BaseAgent + Registry 增强）                     │
│  ├─ AgentStatus  enum(idle/thinking/working/blocked/error) │
│  ├─ Agent 元数据：icon、color、category、skills            │
│  ├─ Clarify 协议：missing_fields → questions               │
│  └─ AiPromptAgent  新成员                                  │
└────────────────────────────────────────────────────────────┘
```

## 六、非目标（v2.0 不做）

- 不重写审查逻辑，沿用 v1.0 的 multi_agent 编排
- 不引入新数据库表（事件流是内存广播，不落库）
- 不接入第三方 IM，所有反馈在产品内闭环
- 不做 Agent 的多租户隔离（admin/普通用户的可见范围沿用 v1.0）
