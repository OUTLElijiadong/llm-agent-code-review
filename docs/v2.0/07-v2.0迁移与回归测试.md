# 07 · v2.0 迁移与回归测试

## 一、版本兼容矩阵

| 模块 | v1.0 → v2.0 兼容性 | 说明 |
|---|---|---|
| 数据库 schema | 无变更 | v2.0 不新增表，事件流不落库 |
| `/api/ai/chat` | 响应增字段 | 新增可选 `clarify?: ClarifyOut` |

## 二、上线步骤

```bash
# 后端
cd backend
source .venv/bin/activate
pip install -r requirements.txt           # 无新增依赖
python -c "from app.main import app"      # 冒烟
uvicorn app.main:app --reload --port 8000

# 前端
cd frontend
npm install                                # 若 BaseChart 等无新依赖则跳过
npm run build                              # 确保 vue-tsc 通过
npm run dev
```

无数据库迁移；无破坏性更改；可灰度。

## 五、回滚预案

v2.0 全部新代码集中在：
- 后端：`app/agents/event_bus.py`、`app/agents/events.py`、`app/api/v1/agents.py`（新方法）、`app/api/v1/ai_prompt.py`、`app/agents/ai_prompt_agent.py`、Registry 元数据扩展
- 前端：`views/agent/AgentOffice.vue`、`components/agent/*`、`views/ai-prompt/*`

回滚只需：
1. 前端路由 `/agents` 指回 `AgentCenter.vue`
2. 后端删除新加路由（旧 `/api/agents`、`/api/ai/chat` 不受影响）
3. EventBus 不订阅就静默无影响

无数据迁移、无破坏性回滚成本。
