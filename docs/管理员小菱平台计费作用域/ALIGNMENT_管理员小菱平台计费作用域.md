# 管理员小菱平台计费作用域对齐

## 原始需求

修复管理员端小菱调用失败，提示“Responses transport 调用失败: 平台模型调用未进入可信计费作用域，未计量兼容调用默认关闭”。

## 现有理解

- 生产基线为 4.1.55 / `34f9fb71f9aa0c0d56f4fdbc805471b98959b3`，唯一迁移 head 为 `121_billing_model_evidence`。
- 管理员 Responses 目前没有个人或企业付款归属；默认总调度模型是 `deepseek-v4-pro`，未列入个人商业计费模型目录。
- 报错来自请求前的可信计量门。全局关闭未计量调用是既有安全要求，不能更改成默认放行。
- 用户已确认：不属于任何企业的平台管理员用量要留记录，由平台承担模型成本，不扣用户积分、不计入企业。

## 边界

- 管理员主对话、恢复、压缩、流式 Responses、管理员子 Agent 与管理员 Agent 团队统一走平台成本计量。
- 仅有效平台管理员、平台托管凭据、已核定官方 DeepSeek 价格和官方 HTTPS 端点可进入平台成本作用域。
- 个人用户继续使用个人账本；企业小菱继续使用企业账本；用户自有 Key 不转嫁到平台。
- 未定价模型、工具、未知用量和结果不确定的调用继续拒绝或冻结，不能落到兼容未计量通道。
- 本项修复不打开销售开关、不调整个人积分价格、不改企业计费归属。

## 未决项

无；平台管理员承担官方 DeepSeek 托管凭据产生的实际模型费用已由用户确认。成本采用官方峰时、缓存未命中费率作保守上界记录。
