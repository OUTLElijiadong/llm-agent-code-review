# 生产自然语言临时团队 HTTP 补验准备

## 状态

脚本已准备，语法检查及 10 项离线合同检查通过，没有发送生产登录、模型或建队请求。使用不存在的凭据路径执行默认模式，仍正常输出 `prepared_only`，证明默认模式不会读取凭据。

二〇二六年九月二十三日只读核实：历史九月八日的四个 QA 账号均已停用，当前没有聊天权限。旧凭据不能用于本轮正向验收；没有启用账号、修改权限、签发 JWT 或寻找其他非验收凭据。执行需要用户恢复浏览器已登录会话，或提供另一个已存在、已启用且具备聊天权限的验收账号凭据位置。

## 已复核路径

1. 公网 `/healthz` 与 `/readyz` 同时确认版本为 4.0.1，发布 SHA 等于显式指定的完整提交号。失败时不读取凭据。
2. 从当前系统用户拥有的 0600 普通文件读取既有登录凭据；通过 `/api/auth/login` 正常登录，JWT 仅存内存。账号编号必须与命令参数一致。
3. GET 本人资料和本人有效权限，确认已有 `agent:chat`。没有权限则停止，不补权。
4. 生成唯一新会话，通过 `/api/agent-responses/stream` 发送合成文本自然语言请求。小菱自主创建两个临时分析成员和一个已有报告成员；脚本不直接 POST 团队，不构造工具执行结果。
5. GET 当前会话的团队，确认恰好三成员、三任务；两临时节点互不依赖，报告节点依赖两者，全部真实完成。失败和超时不自动重发，不直接修状态。
6. GET 同一会话，确认报告成员的实际 `task.result` 回投到该会话。另用生产只读核验脚本复查模型用量归属、重叠区间、发现数、终态复用拒绝和跨所有者读取拒绝；永久 Agent/版本数量与执行前快照比较。

原始 SSE 正文、工具参数、回答、密码和令牌均不保存到 HTTP 验收文件；只输出账号编号、运行/团队编号、状态、事件类型和检查结果。遇到审批或追问不自动批准或回答。本轮 HTTP 补验不证明浏览器布局或点击链路。

## 执行接口

脚本在本地 `证据/生产自然语言临时团队HTTP验收.py`。部署和有效账号前置满足后，主代理复制至服务器专用验收目录，先保存生产只读资产快照，再执行：

```bash
python3 /绝对路径/生产自然语言临时团队HTTP验收.py \
  --credentials /用户指定的现有效验收凭据.json \
  --account owner_a \
  --expected-user-id 实际账号编号 \
  --expected-release 本轮生产完整四十位提交号 \
  --output /新建且尚不存在的私有结果路径.json \
  --execute
```

凭据可以是已有清单中的 `accounts.owner_a`，或直接包含 `id`、`username`、`password` 的私有对象。只有主代理在已核实的账号上执行，不能使用目前停用的旧 QA 来凑通过结果。

结果中的 `team_id` 交给生产只读核验脚本。原始结果保留本地，脱敏摘要与实际限制写入最终报告。
