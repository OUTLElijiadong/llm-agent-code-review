# 小菱临时团队与账号隔离：验收共识

1. 支持仅临时成员及临时/既有成员混合团队；无依赖节点并行，汇总依赖全部工作节点。
2. 临时成员冻结职责与提示词在团队记录，定义校验和可审计；仅有效团队租约执行，拒绝跨账号、跨团队、终态复用和伪造快照。
3. 复用账号模型配置与用量记录，不新增永久 Agent，不授予额外权限。读取当前可见资料，不能宣称写入了正式审查结果；需要写操作或正式审查由主小菱既有工具/内置成员完成。
4. 两个普通账号和管理员的私人会话、历史、事件、附件、追问、团队及圆桌不互通；换号旧异步响应不得污染新界面。
5. 图标保持菱形、圆润可爱，保留各状态可辨性、无障碍文字与减少动画偏好。
6. 针对缺陷先复现，再回归；完整构建与必要全套测试通过后，备份、发布并实测生产健康与真实模型团队流程。独立代理复核数据及完成边界。
