# 前端账号隔离与小菱形象验收

首次验收：2026-09-20；最终复核：2026-09-23。阶段：本地实现验收；本页不替代生产部署、真实模型或真实账号验收。

## 对齐需求

按用户明确选择保留小菱的菱形特征，改为圆润可爱小精灵；临时 Agent 只展示本任务身份，不增加永久资产编辑入口。聊天隔离要求同时覆盖账号、登录凭据、会话和异步响应。主控负责后端临时团队及发布，本文只报告前端实施和本地证据。

## 已复现及修复

- 用户端和管理端迟到的 SSE、恢复快照、后台订阅、团队请求与目录请求可能写回切换后的账号。现统一使用账号与会话生命周期检查；账号或 token 变化同步失效旧请求、断开本地旧流订阅、清空消息和项目选项。服务端已有任务继续由后端管理。
- 会话索引命名空间可能重复追加账号，草稿和快照原只按 sessionId 保存。现命名空间幂等，草稿及快照绑定 surface、账号和会话；仅迁移有明确同账号归属的双重目录。不能证明归属的旧裸快照/草稿不自动接管，服务端历史仍可正常恢复。
- 用户资料、登录请求和 RBAC 请求现在检查发起时的认证生命周期，防止退出后旧请求重新登录或覆盖新账号权限。
- 图片下载发送 Cache-Control: no-cache 和 Pragma: no-cache，避免升级前一小时缓存直接被复用；同账号换 token 也撤销旧 blob URL 并丢弃旧图片 promise。
- AI 日志 content_redacted=true 明示“原文按账号隔离”，保留调用与用量元数据，隐藏原文区及复制按钮；账号变化清空详情缓存，旧详情不能写回。
- AgentMemberWorkCard 和紧凑成员徽标按 kind=temporary 展示“本任务临时”，沿用后端成员定义与原权限，不提供永久入库或定义修改入口。

## 小菱形象与交互

沿用 PrismMascot.vue 可复用 SVG，零新图像依赖。提供 idle、thinking、working、waiting、error 五态，兼容旧 running。实例渐变 ID 独立，装饰头像默认对辅助技术隐藏，独立使用时提供中文状态标签；prefers-reduced-motion 禁用动画。

本地浏览器另复现原桌面 120px 装饰图标覆盖欢迎文字，交叠面积 6468 平方像素。现改为 88px 独立文档流，快捷问题允许换行，交叠面积为 0。手机保持原隐藏大图标策略，390px 视口面板边界为 16—374px，整页 scrollWidth=390。
