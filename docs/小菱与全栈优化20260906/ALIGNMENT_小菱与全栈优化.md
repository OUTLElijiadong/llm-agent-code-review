## 执行边界

- 已验收修复与新架构优化分开发布，不把未选动效、未验证依赖或大规模重构夹带进生产修复。
- 生产以精确提交、当次备份、隔离恢复验证、迁移、镜像/环境一致性和公网验收为门禁。
- 不猜接口、不伪造登录、不猜模型密钥、不把测试桩或隔离 SQLite 结果当生产真实业务证据。
- 数据库存储不自动证明数据来源真实；分别验证来源、输入快照、处理状态、报告来源和页面回显。无法证明的历史字段保持未知。
- 不按名称模糊删除项目、不批量补造历史结果、不更换现有模型供应商、不新增未经验证的 Agent 框架。
- 动效仅独立本地预览；先核实来源、许可和技术适配，用户选择后再实现产品版本。
