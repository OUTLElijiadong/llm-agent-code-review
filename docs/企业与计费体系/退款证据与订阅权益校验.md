# 退款证据与订阅权益校验

2026-11-09，本地隔离测试复现：历史退款为 `approved/failed + FAILED`，但发起请求或签名查单的代次证据缺失时，退款已禁止重发，原订阅权益查询却未将该订单视为待核对，可能继续提供付费审查员或企业成员权限。`manual_review + FAILED` 的证据缺失状态也可能误入审核列表。

现在由共享退款证据规则约束退款重发、待审、查单和订阅权益。证据不足的既有退款继续核对，确定失败且创建及查单代次均匹配的退款可恢复原有权益；独立永久审查员权益不受付费订单退款影响。历史积分冻结额保持原值，不推断旧系统是否已释放。

验证：新增会员、企业、跨企业和手工审核边界测试，相关服务/API/回调组合 117 项、退款页面 16 项通过；一次性 MySQL 8.0.45 中 252 组状态/渠道/代次组合的 SQL 与实例判断一致。隔离数据不代表真实商户状态、生产历史订单或多账号浏览器验收；销售开关仍关闭。
