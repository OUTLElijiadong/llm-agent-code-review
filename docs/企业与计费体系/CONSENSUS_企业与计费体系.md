# 共识与验收：企业与计费体系

## 功能
1. 实现账号多企业、小组、席位、邀请与角色，企业范围内全链路隔离。
2. 实现 49 元个人审查员、69 元/企业席位、1000 积分 4 元的暂定商品与积分账本；历史审查员按确认规则保留永久权益。
3. 按输入/输出分别计量，按调用预占、结算、对账；区分企业和个人钱包及企业/小组/成员月度积分限额。2026-11-01 观察的官方价格页列出 `deepseek-v4-pro` 为 `DeepSeek-V4-Pro-0813`，高峰输入/输出价为 US$1.32/US$3.96 每百万 Token；2026-09-10 路由公告称请求临时按 Flash 价路由，同日更新日志又称 9 月 14 日后继续提供 Pro API、计费方式不变，但未明确解除路由，适用范围尚不明确。代码暂按 Pro 高峰成本两倍计积分价，并把真实供应商账单确认列为开售门槛；不得仅凭路由公告下调成本。
4. 实现企业内 Agent、Skill、知识、论坛、公告、远测与群聊。小菱在个人私聊、小组群和公司群中以原发起人身份工作；服务端当前企业角色快照只用于处理指令冲突，较高角色不能把自己的权限转给低权限发起人。当前企业工具包括同企业知识搜索、创建个人私有草稿、提交公告审批，以及按企业账本运行受支持的已发布 Prompt Agent/`llm_transform` Skill；草稿不可执行，公告必须由非发起人的企业 owner/admin 审批精确内容。
8. 企业知识附件按全企业共享：有效成员只读搜索/下载，owner/admin 可上传/删除；暂支持 UTF-8 TXT、Markdown、DOCX 和可提取文字的 PDF。单文件上限 8 MiB，抽取文字 50 万字符，企业活动片段总量 10,000；恶意内容扫描失败关闭，解析在受限子进程执行。企业向量为本地确定性词项/字符哈希，不外传、不计模型费，也不宣称模型语义向量；扫描 PDF/OCR、组/项目级知识范围和付费远端嵌入不在本次范围。删除清除原文件、抽取正文、片段及检索向量；已有企业会话/小菱历史内容依会话留存规则保留，等待中的模型请求会在预占前复核附件状态并失败关闭。
5. 实现支付宝和微信支付产品的订单、签名验证、通知幂等、退款和对账；资质未就绪时保持关闭。本地适配器已实现预下单、响应/回调验签、查单、关单、退款及退款查单；退款自动闭环仅支持未消费、未预占的全额购买积分。订阅退款和部分退款不开放；未消费周期的会员/席位可走平台双人复核的人工全额退款流程，本地流程已实现并以 mock/隔离测试验证，未核验真实渠道资金结果。渠道资金对账未完成；代码级销售锁保持关闭，真实商户沙箱未验。
6. 企业 Agent/Skill 发布与执行分离：作者私有草稿版本可申请企业内或全局发布；企业范围仅覆盖全企业，申请时必须存在另一名有效 owner/admin 审批；全局范围必须由平台唯一最高管理员审批。申请人不能自批；唯一最高管理员不能审批自己的申请，因此禁止其提交全局发布申请，避免生成永远无法审批的队列项。申请固定标题、类型、配置、范围、企业、申请人、源版本和 SHA-256 快照；编辑草稿不会改变已发布版本。待审时不能删除源草稿；申请人可撤回，已离职申请可以拒绝但不能批准。成员变动与审批通过同一企业锁串行，批准时使用当前锁定读。发布者或企业管理员可撤销企业目录项，平台最高管理员可撤销全局目录项。目录只列 approved 状态；拒绝、撤回和撤销均保留审计记录。
7. 企业目录仅对有效企业成员开放，全局目录对登录用户开放；平台审批工作台只允许平台最高管理员访问。目录与普通资产 API 只授予只读可见范围，`execution_available` 仍为 false，表示不能从目录/旧 Agent Profile/Agent Studio 直接启动。小菱可以查询已审批目录元数据，并仅通过专用工具运行受支持的 schema v1 Prompt Agent/`llm_transform` Skill；单个资产按精确 publication ID 解析固定版本，使用企业钱包/额度，无工具、代码、文件或网络能力。用户明确要求多资产协作时，可用 `run_approved_enterprise_asset_team` 专用团队工具按顺序运行 2–3 个不同的已审批资产，每步独立预占、按 usage 结算，未知用量冻结，前序输出作不可信材料；不执行注册运行时 Agent 或任意工作流。不能把目录可见误当作任意执行授权。个人 Agent 团队 `user` surface 的任务模型调用按团队所有者个人钱包逐请求预占/结算，预占前检查任务租约、成员、账户权限和项目执行权，未核清的 `reserved/unknown` 账单阻止重试；`admin` surface 与企业团队没有明确付款主体，商业计量开启时 fail closed。计量关闭时旧个人团队 free-mode 仍可能产生未入账平台费用。企业小菱不得直接复用个人团队队列，须另建企业授权、钱包归属、可见性和审批生命周期。

## 安全与验收
- 所有列表、详情、下载、工具、消息、检索与写操作由服务端验证当前企业和资源权限；平台身份不自动获得企业正文权限。附件成员检查与附件行使用 MySQL 当前锁定读，防止 RR 旧快照在撤员/删除提交后继续放行。
- 企业项目绑定要求原项目所有者明确操作；企业成员移除会停用其显式项目授权，重新加入需重新授予。项目执行受企业活动状态、计费/退款挂起及订阅状态限制；owner/admin 可保留管理和续费，但计费暂停或订阅宽限结束后不能继续执行项目任务。企业报告读取按项目 view 权限共享，报告删除仍受作者/原有管理员权限约束。
- 企业远测审批与执行固定关联同一项目及范围快照；企业空间提供申请、审批和启动入口。企业 owner/admin 可以审批自己提交的企业申请，组长只可审批本组其他成员且不得自批。个人审查员角色不授予企业审批权。提交、批准、启动和执行阶段均复核当前申请人/审批人项目 execute 权限与企业角色。旧的无项目远测申请仅可拒绝或取消。
- 小菱自主讨论与实际业务操作分离，按群共享范围访问资料；受限结果不得向无权群成员公开。
- 企业及全局 Agent/Skill 目录展示经过审批的版本快照和摘要，不向未授权的企业成员泄漏草稿或待审内容；平台管理员只能看到明确提交全局审批的申请正文，不因平台角色获得企业私有草稿或聊天正文。
- 小菱运行采用数据库检查点与租约隔离；支持会话内活动运行列表、补充信息、显式恢复和取消。周期 worker 自动消费未开始、未停止的 queued 任务，并与 HTTP 后台执行共用原子租约认领。运行中租约过期任务仍由用户显式恢复；`reserved/unknown` 费用不得自动重试，以免上游已收费但检查点未落库时重复调用。同一运行排队后，若其他同级或更高权限成员又在当前会话发送 `@小菱`，旧运行在下一次模型/工具授权检查时停止后续调用；如果该指令在模型完成后、答案发布前到达，最终发布事务也会按运行→检查点→企业锁序复核并抑制旧答案，已结算的模型费用仍保留。较低权限成员的新指令不覆盖更高权限发起人的运行。本期对同一冻结上下文内的语义冲突仍依赖 `ask_user`，不宣称具备通用自然语言冲突检测器。
- 生产基线、隔离迁移、真实浏览器多账号、支付沙箱和真实收款分别验证；不能将缺失用量当作零费用。

## 渠道账单阶段补充共识

- 交易账单仅用于人工核对订单/退款，不自动补发权益、改写本地订单、退款、钱包或积分。账单来源区分为手动上传、支付宝 API 和微信 API；相同字节的不同来源保留为不同批次，微信渠道 SHA1 验证结果与来源一同留痕。
- 渠道下载由平台最高管理员显式触发，不运行定时抓取。支付宝只请求 `trade` 日账单，微信只请求最近三个月的 `ALL/SUCCESS/REFUND` 交易账单。服务端固定允许的 HTTPS 主机/路径、拒绝重定向、限速和文件大小；商户密钥只从部署端现有密钥配置读取，不写进批次。微信 `GZIP` 下载须先有界解压，再对解压后的原始账单字节验证 SHA1；压缩响应本身另以内部 SHA-256 标识。支付宝官方文档示例为 HTTP 下载 URL 时必须失败关闭并提示手动导入，不允许明文回退。
- 微信交易账单不等于资金账单；本阶段不自动对账付款账户余额、退款资金和手续费，不自动处理差异，不开放销售。微信下载只做 mock API 合同测试；真实商户密钥、真实账单格式、沙箱和生产支付仍须另行验收。
- 模型计价 API 必须直接展示与账本结算相同的费率来源，覆盖所有可结算模型别名；每笔预占保存精确费率分数和价格版本，结算不能被后续调价重解释。计划生效时点、版本切换审计与供应商价格变更预警仍是后续开售门槛。

## 模型账本人工对账工作台阶段共识
- 平台最高管理员可查询 `reserved/unknown` 模型预占、查看其付款主体、计费快照是否齐全、预占积分与已有 Token/工具用量及审计历史；不得看到关联提示词、对话正文、授权令牌或原始个人支付资料。
- `reserved` 可能仍在上游请求中，只能查看且不可提案；仅已被调用路径明确标为 `unknown` 的终态不确定预占允许进入双人对账。
- 结算提案必须提供供应商请求 ID、外部证据引用、证据 SHA-256、输入/输出 Token 和说明。后端仅用原预占中已有供应商身份、费率版本和精确费率分快照重新计算金额；金额必须不大于原预占，不接受管理员自报金额。正数 Search/Fetch 不能结算；计数缺失时不推断为零，必须有供应商明确报告的 `0/0` 才可结算。
- “从未发送”释放提案必须提供外部核验引用、证据 SHA-256 与说明；只有另一名平台最高管理员批准后才可释放预占与相应额度。已知可能发送但无法证明费用的项继续冻结。
- 每个提案、批准、拒绝，以及可关联至有效预占的业务规则阻断（包括尚无提案的审批请求）均追加审计事件。阻断事件只保存服务端原因、操作者、预占、可选提案关联和已知的动作类别；它不复制 provider request ID、Token、金额、证据引用或哈希，不保存被拒请求正文，不改变账本或待审提案。尚无提案时动作类别为 NULL，不伪造结算/释放意图。认证失败、语法格式错误及无对应预占的请求不写入财务事件表。服务/API 不提供事件更新或删除入口；数据库有写权限者仍可直接改表。提案人不能审批本人提案；同一预占只允许一个未决提案；批准事务必须重新锁定并检查账本状态，避免并发双结算/双释放。已自然终结的过期提案不能再批准，但允许由另一名最高管理员拒绝归档。
- 对账筛选 `reviewed` 显示有审计历史的预占，包括 `settled/released` 历史项；最新业务事件而非后续 `blocked` 事件决定待复核状态。
- 对缺少费率快照或供应商身份的历史项，只能留证与标注不可结算，不能按当下费率补快照。证据原件由运营方按外部留存制度保存；Prism 只保留引用与哈希，不把哈希误称为真实性验证。
- 本阶段不开放销售，不修改支付订单/退款工作台，不调用供应商 API，不部署生产。实商、生产数据恢复与迁移仍须另行验收。

## 2026-11-09 小菱指令澄清扩展共识

- 每个企业小菱运行在首次模型发送前检查冻结的最近 30 条消息中、来源消息之前、由其他当前有效且权限等级不低于发起人的显式 `@小菱` 消息。有候选时不预占、不发供应商请求，等待同房间有权成员逐条允许、拒绝或标记无关。无候选时也保存上下文指纹和冻结作者（包括较低 rank 作者）的权限版本，供每次模型发送前复核。
- `model_send` 与 `tool` 是不同 pending 类型。模型发送恢复清除专用 pending 后调用 Responses `drive_persisted`；不把模型发送包装成伪造工具调用。工具恢复仍重放原始工具调用，并重验动作、目标、参数摘要和当前权限。
- 所有企业小菱工具调用先过统一工具澄清门，再进入原有身份、资源、计费、审批或写入校验；每次决议只针对一次精确工具调用。模型发送许可不替代工具决议，工具决议也不提升发起人的资源权限。停止运行的安全操作始终可用。
- 每个模型预占前的计费 guard 复核同一运行的发送许可、当前冻结内容指纹、相关权限版本、请求版本和完整决定。未决、过期、撤权、消息/参数变化或证据缺失均失败关闭；未知预占不释放、不重发。
- 候选规则只识别显式 `@小菱`，不宣称覆盖没有提及小菱的自然语言矛盾。模型提示和 `ask_user` 是对话行为，不是授权依据；模型不确定时先问人。既有角色、租户、会话和费用边界不变。
