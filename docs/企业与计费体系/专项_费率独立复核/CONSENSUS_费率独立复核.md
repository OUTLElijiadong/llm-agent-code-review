# 费率独立复核：共识

1. 唯一最高管理员作为草稿提交人，另一名现为有效平台管理员、获明确费率复核委任者作独立批准人；任何账号不得批准自己创建的草稿。现存 C4 委任既不作为必要条件，也不产生费率权限。
2. 审批前重新核对人民币与美元官方模型来源、汇率来源、每项成本与 30% 直采毛利、计划生效时间及 30 天时效；任一事实不满足则拒绝。已存在历史账单按旧快照处理。
3. 对已批准且尚未生效的费率，最高管理员或被委任的独立费率复核人可以提出取消申请；由不同、当时仍有效的参与人批准或拒绝。提案和决定均需说明并审计。批准瞬间必须再次确认目录未生效；超时、授权变化、并发批准只产生一个终态，禁止修改历史 reservation。
4. 受委任人读取必要的模型/工具价格快照、核验来源和提案，不读取 Key、prompt、其他用户账单或无关管理员入口。权限由服务端检查，不依赖前端路由或按钮。
5. 接口、数据库和 UI 的失败状态应清晰；普通登录/登出不改变长期委任。源码与 SQLite 测试、真实 MySQL 锁竞争、两账号浏览器、生产验收分别记录。历史目录来源不得臆造，销售门禁保持现状。
