# 费率独立复核：对齐

## 原始目标和已复现问题

依据用户要求完成个人与企业计费体系，支持可审计、可配置的模型与工具费率。真实认证依赖链在本地验证：唯一最高管理员能创建费率草稿，但本人批准返回 409；第二个平台管理员即使获 C4 委任，批准仍 403。取消已批准未生效目录的服务规则要求第三人，而实际 API 又仅允许唯一最高管理员，无法形成合法操作。此结论来自本地隔离测试，不是生产账号验收。

## 边界与既有功能

本专项只增加模型与 Search/Fetch 费率目录的独立复核和两人取消流程；保留现有目录、来源、毛利、计划生效、账本快照、审计和禁止自审规则。C4 委任不得自动成为费率权限，费率委任不得获得 C4、支付、退款或其他平台权限。不更改销售代码锁，不更改历史 reservation 的费率或状态。

已有 105 对历史目录不伪造人民币来源，缺少有效来源时拒绝新模型预占。经实际来源核验并独立审批的新目录生效前，相关新模型调用仍按门禁拒绝。无需因文档再次询问用户授权；具体实现按本任务范围执行。

## 关键决定

- 最高管理员创建草稿并对有效平台管理员逐人授予、撤销专用费率复核权限；历史管理员默认为无授权。
- 获明确授权的独立复核人能查看最小费率证据并批准或拒绝草稿；最高管理员仍能看完整管理视图，创建人不可审批本人草稿。
- 已批准且未生效目录的取消采用一次取消申请和不同账号独立决定，两名符合条件者即可闭环；允许原创建人或原审批人参与，但取消提案人与取消决定人必须不同。已生效目录不得通过该流程追溯取消。
- 授权、账号状态、当前 RBAC、会话代次以及授权撤销、角色降级和禁用的先后由服务端和事务锁校验；用户禁用/降级后重新启用不自动恢复旧委任。
- 产品界面要明确显示费率草稿、审核、计划生效及取消待复核状态；任何超时结果提示先刷新核对，禁止误导为已批准或已取消。
