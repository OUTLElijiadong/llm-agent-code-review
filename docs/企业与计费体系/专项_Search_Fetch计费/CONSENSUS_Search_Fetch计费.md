# Search 与 Fetch 计费共识

## 确认的需求

1. 企业小菱在公司群、小组群和企业私聊中可以调用网页搜索与网页读取。
2. 工具按成功的单次请求计价，调用前预占，实际成功后结算；不能确认结果时冻结预占并交由审计流程处理。
3. 费用归属于当前企业钱包，并计入企业、小组、员工适用额度；不因发起人身份允许个人钱包兜底。
4. 无有效且获双人审批的工具费率目录、无积分、月额度不足、企业/小组授权失效或运行租约失效时，不得向供应商发送请求。
5. 保持内置 Responses `web_search` 关闭，因为其请求次数上限被供应商标为忽略；Pro 的模型价格/路由争议仍然与本专项分离。

## 技术方案

- 使用 DeepSeek 官方 Search/Fetch API，通过企业小菱的本地 function tool 逐个调用；不允许模型直接触发供应商内置服务端工具。
- 新增不可变费率快照字段并沿用当前 30% 模型直采毛利保护线；基准收费按每个成功请求 1,800 毫积分，实际预占/结算精确使用版本快照。
- 中文人民币指南和英文美元价目各保存独立 URL 与核验时间；两者及汇率来源必须覆盖计划生效时间，并在运行时重新核验不超过 30 天。Search 与 Fetch 可分别启用或关闭，未启用工具费率必须为 0。
- 在 `BillingReservation` 增加计费类别、规范工具名、工具成本/售价/目录版本快照、成功次数及 provider attempt 起始时间，继续复用钱包批次、企业额度、唯一请求键、未知冻结、C4 双人审核。模型调用只保留 Token 字段；工具成功次数、成本和客户价分开记录，个人/企业 Token 图只计 `billable_kind=model`。
- 工具 reservation 只允许企业钱包，不允许个人积分兜底；企业、小组、员工月限额沿用当前 wallet→limit→batch 锁序。attempt-started 标记持久化并提交后才允许发 HTTP；同一个 reservation 一旦 attempt 已开始绝不自动重发。确定未发送仅能在 attempt-started 为空时释放；可信非计费供应商响应记录为 `not_billable` 并释放；无法确认状态记 `unknown` 并冻结原金额。
- C4 按账单种类复核：模型继续要求原费率快照与 Token usage；Search/Fetch 使用工具费率快照、证据和 0/1 成功次数，不伪造 Token。双人批准金额必须按原快照复算；证据证明工具未成功/不计费时以成功次数 0、实扣 0 结案，不伪装成“从未发送”。
- 单次小菱 run 最多发出 3 个 Search/Fetch 请求；HTTP 结果成功条件严格符合官方计费规则。所有请求禁自动重试，工具输出限长并标记为不可信网页内容。
- 费率计划只有在中英文价格和汇率来源新鲜、版本完整、官方成本底线与 30% 直采毛利均通过、创建人与审批人不同且生效时间满足现有要求时才能生效；每次外呼前还会重验来源、成本底线和毛利。

## 成本复核

- 中文 Search 指南列 ¥5/1,000 次，英文 Models & Pricing 列 US$0.75/1,000 次；按核价 ¥6.7168/USD，美元价折算为 ¥5.0376/1,000 次。采用两个口径中较高值并向上取整，成本为 5,038 CNY 微元/次。
- 1,000 积分售价 ¥4，收费 1,800 毫积分的收入为 ¥0.0072。以 ¥0.005038 成本计算，精确直采毛利率为 30.0278%，向下取整为 3,002 基点；1,799 毫积分不满足 30% 底线，服务端拒绝。
- 来源：[DeepSeek 官方 Search & Fetch 指南](https://api-docs.deepseek.com/zh-cn/guides/search/)、[Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/)、[中国银行外汇牌价](https://www.boc.cn/sourcedb/whpj/)。本次核价日为 2026-11-07。
- 该价格不覆盖模型 Token、税费、支付通道、服务器、客服、退款与异常损耗。整体产品不得据此宣称盈利；支付销售锁继续关闭。

## 任务边界

- 本期实现范围仅为企业小菱对话运行时，不解锁公开 `/v1/responses`、AdminCopilot、个人助手、注册 Agent 团队以及任意 MCP 外呼。
- Search 返回最多 5 项；Fetch URL 与工具调用输出受长度限制。供应商端负责 Fetch 实际内容抓取，应用只请求官方 DeepSeek API，不自行抓取用户 URL。
- 不实现自动重试、旧 unknown 自动释放、供应商自动抓价或真实交易对账；来源价格变化必须经过新费率目录和双人审核。

## 验收标准

- 计费版本缺少工具费用或无批准版本时，工具不可见且服务端调用返回拒绝，HTTP 外呼为 0。
- 钱包/额度不足、撤权、失租约时，在供应商 HTTP 前拒绝并无残留 reservation。
- 成功、空结果、供应商明确错误、无响应和畸形响应分别进入准确的结算、释放或 unknown 状态；重复 call ID 不会重复外呼。
- provider 实际成本和客户扣费都从预占快照计算；月额度仅增加企业实际收取金额；Token 汇总不混入按次工具调用。
- 所有新迁移、单测、服务测试、API 测试、运行时测试、前端/接口兼容测试和一次性 MySQL 迁移矩阵通过；真实供应商/支付/生产验收另记。
