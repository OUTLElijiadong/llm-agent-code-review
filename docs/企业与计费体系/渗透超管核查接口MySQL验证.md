# 渗透超管核查接口 MySQL 验证

使用独占空 MySQL 8.0.45、REPEATABLE READ 和真实 JWT，在隔离 FastAPI 路由上运行 `backend/tests/test_mysql_pentest_admin_evidence.py`，共 7 项通过。

- JWT 已完成认证、接口当前权限校验前，另一事务先提交令牌版本变更；旧请求被拒绝且没有成功访问审计。
- 核查先获取授权锁时，并发的令牌版本更新、停用账号及移除超管绑定尝试均在 `performance_schema.data_lock_waits` 中观察到等待。放锁后版本更新成功；后两者被迁移 022 的数据库触发器拒绝，不能把这两项表述为实际停用或降权已提交。
- 注入审计插入失败及数据库提交前失败时接口返回错误、不返回核查数据，且没有持久成功审计。该注入不模拟数据库已提交后网络中断的提交结果未知情形。
- 关联执行的账号错配、关联账务的账号错配、关联沙箱的账号错配只返回不可确认，不暴露其他账户的账务、沙箱或执行详情；覆盖的数据是人工构造的隔离记录。

测试未禁用数据库身份保护触发器。核查路由、JWT、服务与数据库为真实实现；不是浏览器、多进程、生产环境、真实支付或真实沙箱的验收。测试容器由独占测试创建并在结束时删除。
