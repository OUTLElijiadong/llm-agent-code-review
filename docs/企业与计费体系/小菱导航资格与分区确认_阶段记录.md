# 小菱导航资格与分区确认

基线为 `38f181c86c3f74f40ce73c43ce73ff23b0f6a292`。本阶段涵盖小菱导航预判、到达确认和登录后站内目标恢复，不修改服务端权限或企业成员关系。

- 个人账号专属入口在企业资格未知、已为企业成员或缓存不属于当前令牌时不展示；只有当前会话的已确认非成员缓存才可继续走既有路由守卫。
- 论坛详情对 URL 路径部分校验规范正整数，允许普通查询与片段，继续拒绝重定向类查询参数（包括编码、大小写及重复键）；后端仍决定资源权限。
- 统一管理中心分区由共享清单和页面实际页签一致性测试约束；历史分区别名保留。未知分区不被小菱识别为可用或报告为已到达，普通管理员敏感分区仍拒绝。
- 敏感分区按解析后的真实统一中心元数据判断，尾斜杠和路径大小写不改变最高管理员要求；到达确认需当前权限来源，缺失或降权时不能声称已到达。
- 旧入口按 Vue Router 重定向规则继承或覆盖查询与锚点，到达确认与真实跳转一致；继承来的敏感分区仍检查当前角色。
- 当前内存中的身份判定同时比较完整令牌；同一账号的 32 位指纹碰撞不会继承已缓存成员资格或运行中请求，完整令牌不写入会话存储和日志。同进程切换时重置空间偏好。

## 证据与未完成

本地三项原始回归、敏感分区大小写/尾斜杠、指纹碰撞及旧入口锚点回归先失败，修复后通过；含导航、空间、统一管理中心与路由守卫的 7 个测试文件共 569 项通过，类型检查、定向 ESLint 和前端生产构建通过。

独立复核报告：9 个源码及测试文件的复核前后哈希一致；150 项单元测试及 6 项本地浏览器测试通过。本地浏览器测试不等同于生产环境真实账号验收。

企业资格缓存是时点结果，其他会话加入或退出企业后可能陈旧。进入个人账号专属论坛时现在重新向服务端确认资格，旧请求不能覆盖新结果，请求失败时不沿用旧资格。停留在其他页面时的入口显示仍可能暂时陈旧；最终服务端鉴权及普通/审查员/管理员真实账号浏览器验收仍需分别验证。当前未部署生产。

登录守卫原先保存访问目标，但登录表单总是进入角色首页。本地新增回归先复现该问题；修复后仅恢复可解析的站内非公开路由，拒绝外部地址、反斜线、控制字符、未知或登录页面，权限仍由正常路由守卫检查；无可用目标时回到角色首页。成功登录后若目标路由抛异常，尝试进入首页；首页也失败时可重试导航，不重复发送密码。登录前链接恢复及权限测试均为本地验证，生产与多账号浏览器验收未执行。

新增登录与成员资格修复后的本地导航相关回归共 8 个文件、223 项通过，定向 ESLint 和生产构建通过。此后补充导航取消提示，登录、成员资格与守卫的最终定向回归共 49 项通过，类型检查和所涉文件 ESLint 通过。首次 8 文件并行回归有 1 项超时、其余 216 项通过；随后将测试并行度限制为 2 重跑全部 8 文件通过，无法据此确定首次超时的原因。

最终源码通过全量前端测试：213 个文件、3,074 项，随后生产构建通过。测试过程中 jsdom 输出不支持完整页面跳转的提示，但最终测试进程退出码为 0。

独立 Chromium 复核在模拟接口下覆盖登录失效后再次登录、目标与首页导航取消后重试、成员目录变更与请求乱序。企业加入和退出仅为模拟数据；论坛页面的模拟响应缺少字段，页面渲染不计入通过，真实后端、多账号及生产尚未验收。

合并小菱入口候选后，独立复核发现等待论坛资格期间重复选择当前页仍可能被旧导航覆盖；真实 Vue Router 回归先复现，现将重复 `push` / `replace` 纳入导航代次。修复后的权限矩阵、登录、工作空间与守卫定向回归 454 项通过，ESLint、类型检查通过；独立真实路由及本地 Chromium 覆盖重复点击、后退、成员变化、离线和账号切换，完整小菱浏览器模拟 11 项通过。较早的并发测试轮出现超时及端口冲突，未计为通过。合并旧版候选的全量前端回归为 3,106 项通过及构建通过，该结果不覆盖此后新增的竞态修复，最终合并树仍需全量验证。

会话存储仍以 32 位指纹保存非授权性的空间偏好；浏览器重载后内存令牌已丢失，无法排除新令牌碰撞而恢复旧空间选择。资格状态在新 store 为未知，企业资源仍须服务端验证，不能将 UI 偏好当作授权。
