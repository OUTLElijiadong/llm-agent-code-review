# 个人 Agent 运行记录恢复

## 范围和契约

个人 Agent 和共享 Agent 的使用者可从服务端找回自己的运行记录，即使清除了浏览器会话存储或共享作品已下架。记录仅用于查看，不会重新调用模型、修改账本或替代原有请求幂等键。

`GET /api/me/agent-runs` 要求登录，参数为 `source=private|public`、`before_id`（可选，上一页末尾运行 ID）和 `limit`（默认 50、最大 100）；按运行 ID 倒序返回本人记录摘要。翻页期间新增的运行不会使旧记录重复；重新打开列表可查看新运行。摘要仅含运行 ID、所属来源 ID、版本、名称、状态、确认费用与创建时间；不包含用户输入、提示词、输出、作者身份和幂等键。未结算费用保持空值，不推断为零。公开记录不暴露作者个人 Agent ID。读取结果时继续使用原有本人运行详情接口，其服务器端校验不因作品下架而放宽。

列表采用普通偏移分页；分页过程中有新运行插入时刷新列表可重新排序。历史列表自身不做过期账单处置；查询运行详情会走既有超时和对账逻辑。

## 交互和验收

两个入口复用折叠式记录组件，用户点击记录才加载结果。切换账号时清空记录与结果，并丢弃旧会话返回；列表与详情失败可重试。自动化覆盖跨账号隔离、公开作品下架、分页、隐私字段、费用待确认和前端异步切换账号；既有运行和发布测试覆盖实际调用、幂等、账本与下架后恢复。真实浏览器多账号、生产环境验证尚未在本专项中完成。
