# 全局共享资产目录分页

全局企业 Agent 和 Skill 原先仅展示最新 100 条，较早的已批准资产无法从目录选择。目录接口继续返回原数组并保留既有 `offset` 参数，新增可选的正整数 `before_id`；前端以当前列表末条 ID 请求下一页，允许用户继续浏览更早的已批准资产。

新增资产不会使翻页重复；下架资产不会出现在之后的服务端查询中。列表已展示的资产在下架后可通过刷新目录移除，执行接口仍独立校验当前发布状态。切换账号时清空原列表并丢弃迟到响应，加载失败保留已有结果和重试入口。分页不是一致性快照，已跨过游标的旧资产若在之后重新上架，需刷新目录。

首屏未成功加载或账号尚未就绪时不显示空目录；失败后可用刷新按钮重试，只有成功返回空列表才显示空态。

本地测试先复现服务端不接受游标和页面缺少加载入口，再验证新资产插入、下架、账号切换、重复操作和失败恢复。相关后端 32 项、前端 21 项通过，Ruff、ESLint 和 TypeScript 检查通过；真实浏览器和生产环境尚未验收。
