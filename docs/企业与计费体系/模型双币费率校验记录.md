# 模型双币费率校验记录

## 2026-11-08 本地实施

生产基线账单及旧费率目录不得改写。迁移 `105_model_cny_cost_sources` 在费率目录添加模型人民币来源 URL、核验时间，在模型费率项添加人民币输入及输出成本；历史行保持空值。新增来源字段和模型费率项由数据库不可变触发器保护。迁移在现有 104 后，后续迁移及实际唯一 head 以执行时 Alembic 状态为准。

新费率目录必须分别记录 DeepSeek 中文及英文官方模型价格页、核验时间、每模型两币成本及中国银行汇率来源。创建、独立审批和新模型预占分别检查来源时效和成本下限；价格及汇率须在审批/生效或预占时处于 30 天窗口内。模型直采毛利按人民币成本与美元成本乘审批汇率的较高者计算，逐项不低于 30%；不能据此声称全产品盈利。

本文记录的是 2026-11-08 实施时的旧价格口径：当时官方 Flash 高峰未命中输入/输出人民币价格为每百万 Token ¥2/¥8，英文价格为 $0.30/$1.20。2026-11-09 一次页面读取曾显示输出 ¥9/$1.32，最新重新打开的官方页面恢复显示 ¥8/$1.20；这些旧实施数字仅解释迁移 105 增加双币来源与成本字段的历史背景，不可当成当前实时采样。现行价格、成本门与毛利计算以[最新模型成本核对](模型成本核对.md)开头的复核为准。供应商可修改价格；固定成本门需要随价格变化及时更新并复核，无法替代真实商户账单、结算币种合同及后续汇率核验。

历史目录缺少人民币来源时仍可查看既有记录，但不得用于新模型预占；需要按实际核验结果创建并由独立管理员审批新目录。已经存在的 reservation 始终按原有快照结算或 C4 复核，不按新目录补价。销售代码锁保持关闭。
