# 企业小菱受控主动讨论：设计与任务

## 范围与边界

- 公司群和小组群由真实人类消息触发受控建议；私聊继续只响应本人 `@小菱`。主动运行不是人类委托，不能执行任何工具或业务写入，也不自动调用网页或其他 Agent。
- 企业 owner/admin 显式启用并设置每月企业积分预算；旧企业默认关闭。企业主动用量归企业钱包，不计入员工个人钱包。商业计量关闭、订阅无效、预算不足或身份失效时禁止模型请求。
- 触发事件与消息同事务持久化，由已有队列调度恢复；一个真实消息最多一次主动运行。限制来源为非 `@` 人类消息，频率与每日触发量均有固定上限；机器人输出不能递归触发。
- 用户可在企业空间关闭；政策变更后的排队运行不可发起请求，在途已发请求继续遵循未知账单与取消规则，不伪造零用量。关闭后不得发布旧建议。
- 自由文本中复杂冲突的形式化仲裁仍未完成；角色提示不是硬保证。本功能不将主动建议的上线视为解决该项需求。

## 契约与依赖

1. 迁移 113 接 112：企业保存开关、预算与政策版本；主动事件绑定真实来源消息且唯一；运行固定 `manual/proactive`，历史默认为 `manual`。
2. 管理员设置需服务端当前权限与企业锁；按上海月份在企业钱包锁内创建/维护现有 `auto` 账本额度，额度不得小于已用及预占。
3. 发送消息仅在公司/小组、人类、非 `@`、策略启用和满足限频时生成事件；保存消息失败不会生成事件，事件失败也不能伪造已保存消息。
4. dispatcher 以事件来源的真实企业成员建立已有运行和角色快照；事件被恢复时不能重复建运行或模型请求。队列、预占和发布均核验政策版本与当前会话身份。
5. 主动运行的检查点工具数组为空，执行器即使收到伪造工具调用也失败关闭；限单模型轮次与上界。费用通过 `enterprise_auto`、企业钱包和当月 `auto` 额度预占结算，未知冻结。
6. 界面仅向有权管理员展示开关和月预算；异步请求绑定登录令牌，切换账号或企业不应用旧响应。
7. 设置保存必须携带读取时的 `expected_version`；冲突时刷新并等待管理员再次决定，不能自动覆盖其他管理员的关闭操作。来源事件超过十分钟时不再新入队、领取运行或发送供应商请求；已发请求仍按账本结算，发布时继续检查当前权限与设置。
8. 通过 HTTP 写入设置和消息时，在企业/用户当前行锁内比对认证时的令牌版本；撤销先提交则拒绝，写入先持锁则撤销等待事务结束。计量、worker 或企业状态不允许执行时禁止启用；已启用状态仍可关闭。

## 验收

- 测试先行：关闭默认、不足预算、私聊/机器人/@ 不触发、消息重放、限频、跨企业/小组、管理员权限与失效；主动运行禁止工具、禁用/撤权先行与队列并发、来源真实性。
- 验证并发预算、未知费用不自动重发、取消与结果抑制；MySQL 空库链和真实锁竞争单独记录。真实多账号浏览器及供应商账单未验证前不得视为生产验收。

## 本地实现与测试记录（2026-11-09）

- 默认关闭、管理员版本化设置、企业月预算、真实消息事件、队列、单次模型调用及禁止主动运行工具已接入本地代码；明确 `@` 与原有人工工具工作流保留。
- SQLite 假供应商测试覆盖正常企业自动计费、恶意 `ask_user`、在途关闭后不发布、用量未知冻结；自动费用归企业和对应小组，不归员工个人。前端设置、账号/企业切换和并发冲突处理有组件测试。
- 独立临时 MySQL 8.0.45 空库执行完整迁移链至唯一 head 113；并发设置只允许一个版本成功、同群并发消息只生成一次受控事件、超过共享预算的两次并发预占只成功一次。另覆盖账号撤销先行和设置/消息持锁先行、管理员降权及企业暂停。费率是测试合成数据，不是真实核价。
- 主动模型请求在预占事务中同时持久化运行及账本发送标记后才进入传输；MySQL 假供应商结果未知时，C4 拒绝把它当成“未发送”释放。即使崩溃发生在真正发送前，已经提交发送标记也会保守冻结。
- 在预占提交之后、流式传输调用之前再次核验来源时效与当前权限；隔离 MySQL 测试模拟预占后过期，供应商未调用且预占保守冻结。该核验不持数据库锁跨网络，核验与实际 I/O 之间仍有不可原子消除的短暂时序窗口。
- 未完成：自然语言冲突全面判定；所有撤权及停止顺序的真实 MySQL 竞争；多账号真实浏览器、真实供应商、真实费用和生产验收。供应商请求一旦已发出，不能承诺关闭立刻阻断上游或退款；关闭后仍抑制结果并按真实账单状态核对。
