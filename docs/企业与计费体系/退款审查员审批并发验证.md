# 退款与审查员审批并发验证

2026-11-09，本地隔离 MySQL 8.0.45 的可重复读事务中复现：审查员已取得事务快照后，退款审核先完成并提交、用户同步降级；旧事务仍可能通过普通权限查询并批准个人渗透测试或个人远测授权。该复现使用合成数据，没有执行远程测试或连接真实渠道。

个人渗透测试审批和个人远测审批现在复用服务端 `check_paid_permission_fenced`：在审批事务内按当前读锁定用户和 RBAC 权限，并持锁到审批提交；对付费审查员以短只读会话核验当前权益，不反向获取退款、订单或钱包锁。退款先提交时审批拒绝；审批先持锁时退款等待后再提交。调用方必须保持此锁序，不能在取得用户锁后再获取订单或钱包锁。

一次性空库从初始化迁移到 `110_ent_public_personal_run` 后，两个审批入口的上述两种时序、永久审查员仍可审批和同秒永久权益授予与退款，共 **7 项通过**；锁等待由 `performance_schema.data_lock_waits` 实际观察。个人与远测审批相关 SQLite 服务及 API 回归 **50 项通过**，目标 Ruff 通过。临时数据库使用合成数据并已清理。

该结果不覆盖 Agent Studio 的创建、更新或提交，也不覆盖其他使用审查员权限的写入口；这些仍需逐项复现、核对锁序并测试。真实浏览器、多账号、商户沙箱、生产迁移与在途业务仍未验证。
