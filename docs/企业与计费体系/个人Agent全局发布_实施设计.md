# 个人 Agent 全局发布：实施合同

状态：实施中，尚未验收或上线。保持现有销售锁。

个人用户和审查员对本人活动 Agent 的指定当前版本申请全局发布。申请保存不可变标题、提示词和绑定摘要，待审批作者可撤回；唯一平台最高管理员可批准、拒绝或下架，不能审核本人申请。最高管理员不提交会导致自审死锁的申请。审批事务重验账号、申请者、个人 Agent、版本及摘要。发布后源作者编辑不改变已批准快照。

登录用户只可查看已批准快照的必要目录元数据，目录不返回提示词、作者私有信息或历史。全局调用仅接受发布 ID、请求标识及文本，不接受模型、凭据、付费主体或提示词。服务端锁定发布状态并使用调用者个人钱包，沿用单次发送、预占、幂等、可信用量结算和不确定冻结。发布撤销先于发送许可则禁止请求；撤销在许可后响应前则可信费用仍结算、迟到结果不展示。已完成本人历史结果保留且只允许本人读取。

实施顺序：108 向前迁移与权限/发布生命周期测试；公共调用及私有/公共幂等冲突测试；API 和目录；MySQL 锁竞争、真实账户浏览器及外部供应商分别验收。公开发布不等于已完成生产验收。
