# 个人基础 Agent 状态与剩余验收

> 状态（2026-11-16）：个人 Agent 的创建、版本、单文本运行、全局发布申请/审核/下架和界面链路已进入生产版本 4.1.49。生产运行态计量与销售门仍关闭，因此当前不能据此承诺线上 Agent 可运行或已经完成真实角色验收。此页保留原需求边界，并记录实现位置和剩余证据；不把代码存在等同于生产功能验收。

## 需求与当前实现

- 个人普通用户与审查员可在个人空间创建、编辑、停用并管理自己的基础 Agent；企业身份不改变个人 Agent 的归属。所有者由当前登录账号推导，不能由请求体指定。
- 企业 Agent/Skill 的企业内或全局发布属于独立企业资产流程，仍按 [ALIGNMENT](ALIGNMENT_企业与计费体系.md#已确认的关键边界) 与 [CONSENSUS](CONSENSUS_企业与计费体系.md#功能) 执行；个人基础 Agent 不替代或缩减该需求。
- 个人 Agent 工作台位于 `/my-agents`，角色入口覆盖普通用户、审查员及管理员。它与旧 Agent Studio 的工坊角色、企业资产草稿和旧 `CustomAgent` 注册表分开。
- 个人 Agent 的服务端接口位于 `backend/app/api/v1/personal_agents.py`；创建、列表、读取、版本、修改和停用由 `personal_agent_service.py` 实现，不提供删除接口。运行接口使用 `/api/me/agents/{agent_id}/runs` 及其按请求键/运行 ID 恢复接口，不采用早期草案中的 `/invocations` 路径。
- 个人 Agent 全局发布由 `backend/app/api/v1/personal_agent_publications.py` 与 `personal_agent_publication_service.py` 实现：作者提交固定版本快照、撤回待审申请；平台最高管理员批准、拒绝或下架；已批准目录对登录用户可见。最高管理员不能提交自己的全局申请，申请人不能审批自己的申请。
- 平台审批入口沿用 `/admin/enterprise-asset-publications`，页面内有“企业/个人”切换；路由元数据、侧栏入口和后端审核 API 均限制平台最高管理员。个人 Agent 的审核组件为 `frontend/src/views/platform/PersonalPublicationReview.vue`。
- 普通用户、审查员及其他合格作者可申请发布；审批通过前不进入公开目录。发布目录只运行批准快照，不能读取作者的私有草稿或任意工具。

## 运行与计费边界

- 个人私有 Agent 及公开 Agent 使用服务端选定的 `deepseek-flash` 受限单文本调用；不接受客户端模型、API Key、Endpoint、工具、Skill、代码执行或网络配置。输入/输出上界和上游 usage 由服务端校验。
- 每次调用从当前用户的钱包按已批准费率快照预占并结算。调用键幂等；响应或 usage 不确定时保持待核对，不自动重发、不记零费用。公开 Agent 的调用者按自己的个人钱包付费。
- 执行可用状态需要商业计量门、平台模型凭据和当前费率目录同时就绪。任一条件不满足时，调用必须在上游请求前失败关闭；界面会显示运行暂不可用。发布申请与目录审批本身不绕过运行门。
- 生产只读观察时间 `2026-11-16T13:46:14Z`：销售代码门、`billing_sales_enabled`、商业计量和权益强制均为 `false`；Alipay/WeChat 有效销售均为 `false`；已配置可计费模型数为 3，但 `model_pricing_ready=false`。这是该时点的有效运行门状态，不代表商户密钥不存在，也未读取任何凭据。该状态意味着个人 Agent 的线上付费运行尚不可用。

## 仍未完成的验收

1. **真实角色浏览器验收**：需使用隔离账号验证普通用户、个人审查员及企业员工创建/运行/停用、用量归属、跨账号隔离、申请全局发布、平台最高管理员审核/下架与刷新后持久性。不能用超级管理员单账号代替完整矩阵，也不在真实客户项目中造测试数据。
2. **生产计量配置**：先核实真实 provider 价格、模型/协议 Token 上界和每个工具调用成本；配置费率及平台托管凭据后，使用隔离账号和受控额度验证预占、结算、未知用量与退款/额度边界。销售门保持关闭，直到结果和真实供应商账单能对上。
3. **完整盈利结论**：模型账单之外还需支付手续费、退款损耗、税费、服务器与存储成本，以及外部服务成本。只证明 Token 单价有毛利不能证明整个平台不亏损。
4. **全局发布真实流程验收**：在隔离账号中验证待审不可见、作者不可自批、普通管理员不能审批、平台最高管理员可审核、批准后目录可见、撤回/拒绝/下架后不可运行；确认每次调用仍归当前运行者个人钱包。
