# 个人渗透发现项幂等独立复核

## 复核范围

独立阅读 `_upsert_finding` 及其 MySQL 和 SQLite 用例，核对旧快照下同一指纹的唯一约束冲突、保存点、外层提交和回滚、调用方待刷新的数据、非目标约束及伪造键名的异常。未修改业务实现。MySQL 使用一次性本地隔离的 8.0.45 tmpfs 实例，测试后已停止；实际供应商和生产环境未验。

## 测试结果

- SQLite 发现项回滚及持久执行暂存相关测试：44 passed。
- 独立 MySQL 发现项幂等、终态竞争、旧快照和锁范围测试：17 passed，2 xfailed。正常发现项跨委托写入测试通过；终态报告与跨委托插入仍有下述不同的锁范围问题。
- 两项已知缺陷使用 `--runxfail` 单独复现。旧 worker 跨进程取消重启后仍可写入；终态报告读取时，无关发现插入等待 `uk_pentest_finding_engagement_fp`、`X,INSERT_INTENTION`、`supremum pseudo-record`。这两项未解决，不代表生产已复现。
- 一次早期 MySQL 容器测试建连报 2013，不计入通过；重试成功。早期测试无异常类型限定时，建连失败曾出现 `XFAIL at setup`，不能作为缺陷已复现的证据。

## 预期失败约束

两个已知缺陷用例分别使用 `OldGenerationWriteAllowed` 和 `UnrelatedFindingLockWait` 作为严格 xfail 的唯一匹配异常。后者仅在观察到上述目标索引、锁类型及 supremum 后触发；其他锁、等待超时、夹具及连接错误正常失败。隔离 MySQL 重跑得到 2 xfailed；再用 `--runxfail` 得到两个对应的专用异常。对两用例分别使用不可连接的本地端口，均实际报 setup error、退出码 1，而非 xfail。

## 边界

旧正式渗透执行路径的跨进程代次 ABA、所有子任务/真实外呼终止证据、终态报告间隙锁容量和完整生产验收仍未完成；不能因上述幂等测试通过而启用持久执行暂存门禁或宣称生产安全。
