活动 CVE 参考集有 41 个唯一编号：38 条来自 CNA 原始 JSON，逐条核对 ID、PUBLISHED 状态、英文说明、完整 affected 结构、发布日期、更新日期、来源 URL 和 SHA；另外 3 条为维护者公告中文摘要，重新读取原始 HTML 核对。

41 条参考中有 20 个 2026 年编号，PHP 官方日志中的 18 个 2026 年编号全部纳入。`known_cves.md` 的 41 个唯一 CVE 条目与活动数据集完全匹配，并说明集合大小。原 CVE-2021-21381 的 CNA 原始记录实际属于 Flatpak，已经从活动 PHP 参考集排除，原始 JSON 保留作纠错证据。Guzzle 的三个 2022 年记录重新核对为重定向/认证头或 Cookie 泄露相关，不能泛化为所有 SSRF。

本复核确认快照、生成器、运行数据和知识文件的一致性。该数据是 PHP 生态的 41 条精选参考，不是完整 CVE/NVD 镜像，不代表项目实际扫描命中。生产向量知识表的只读采集证据由主任务提供，本次没有重新连接生产数据库，因此不将其标为独立数据库重查。
