# 响应式布局与完整测试共识文档

## 明确需求

1. 全局布局在桌面、平板、手机视口下都可用。
2. 主要页面头部操作、筛选条、分页和表格不应发生文本重叠或横向页面溢出。
3. 项目列表与仪表盘作为高频页面，需要补充明确的响应式布局。
4. 完整运行项目现有前后端验证命令。

## 验收标准

- `AppLayout` 在移动端无横向页面滚动，主内容区域可独立滚动。
- `AppHeader` 在 `390px` 手机宽度下按钮不重叠。
- `.filter-bar`、`.page-actions` 在小屏自动换行。
- 项目列表表格在窄屏可横向滚动，卡片网格自动收缩。
- 仪表盘统计卡在手机宽度下不挤压文字，图表卡单列显示。
- 前端 `npm run build` 通过。
- 后端 `pytest` 全量执行并记录结果。

## 技术约束

- 不引入新依赖。
- 优先修改全局样式和布局容器。
- 保持现有 Prism 视觉体系。
