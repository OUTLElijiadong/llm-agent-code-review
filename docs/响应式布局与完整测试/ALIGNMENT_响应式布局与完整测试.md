# 响应式布局与完整测试对齐文档

## 原始需求

- 设计该项目的响应式布局。
- 完整运行测试。

## 项目上下文

- 前端技术栈为 Vue3 + TypeScript + Element Plus + SCSS。
- 应用主壳层为 `AppLayout.vue` + `AppHeader.vue` + `AppSidebar.vue`。
- 已有移动端侧边栏抽屉，但页面级页头、筛选区、表格、分页、部分网格组件缺少统一响应式约束。
- 后端测试位于 `backend/tests`，前端目前仅提供 `npm run build` 与 lint 脚本。

## 需求边界

- 本次聚焦应用级响应式规则与高频页面，不重写业务流程。
- 不改变后端 API 与数据库结构。
- 完整测试以项目现有可执行脚本为准：前端生产构建、后端 pytest 全量测试；如遇环境阻塞则记录原因。

## 响应式范围

| 层级 | 改造目标 |
|------|----------|
| 应用壳层 | 使用动态视口高度、稳定滚动区域和移动端间距 |
| 顶部栏 | 小屏下压缩搜索、Agent、用户信息，避免重叠 |
| 全局页面结构 | 页头、操作区、筛选条、分页在窄屏自动换行 |
| 数据表格 | 在移动端保留信息密度，同时支持横向滚动 |
| 仪表盘/项目列表 | 统计卡、图表卡、项目卡在桌面/平板/手机自适应 |

## 决策

- 保持后台系统的高信息密度，不做营销式重排。
- 使用断点 `1200/1024/768/520/420px` 覆盖桌面、平板、手机。
- 表格不强制转卡片，避免破坏业务字段；窄屏使用横向滚动保证可读。
