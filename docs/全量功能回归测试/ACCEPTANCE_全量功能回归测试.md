## 缺陷与修复

| 缺陷 | 修复结果 |
| --- | --- |
| Axios 统一 JSON 拦截器把 Blob 导出响应误判为失败 | Blob 响应直接放行，下载 helper 返回 `response.data` |
| AI 修复提示词弹窗打开即自动调用外部模型 | 改为显式生成；LLM 润色增加二次确认 |
| AI 提示词可能携带二进制 Base64 或过长文本 | 跳过二进制上下文；脱敏后限制 `4000` 字符 |
| passlib 与 bcrypt 4.1.x 兼容告警 | 固定 `bcrypt>=4.0.0,<4.1.0` |
| 本地核对脚本受代理环境变量影响 | `httpx.Client(trust_env=False)` |
| 编辑器保存后可能保留旧版本内容 | 修复 Monaco 编辑器与当前文件版本同步 |
| 路由切换导致圆桌讨论状态丢失 | 改为不触发重挂载的 URL 清理方式 |
| 审查任务与文件关系未持久化，报告/讨论回查不稳定 | 新增 `review_task_file` 关联表和服务层写入 |
| Word/PDF 报告导出缺少多文件/问题上下文 | 导出器补充任务文件和问题统计 |
| Monaco worker 警告 | 增加 worker 配置 |
| Element Plus tag 类型警告 | 补齐显式 tag type |
| 规则列表大量数据下自定义规则不易定位 | 新增规则页搜索，并兼容下划线/短横线被输入法丢失的场景 |
