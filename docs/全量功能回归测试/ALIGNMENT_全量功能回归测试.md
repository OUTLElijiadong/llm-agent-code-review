# 全量功能回归测试 · 对齐文档

## 原始需求

对当前棱镜 Prism 平台执行全量测试，逐个真实点击页面按钮并监控日志，确认按钮和功能不报错且行为正确。

## 项目理解

- 前端为 Vue 3 + Vite，开发地址为 `http://localhost:5173`。
- 后端为 FastAPI，开发地址为 `http://localhost:8000`。
- 数据库必须使用 Docker MySQL，宿主机端口为 `3307`，禁止切换 SQLite。
- 当前前端含普通页面、管理员页面、Agent 助手、安全扫描、圆桌讨论、Agent 自进化等功能。

## 范围边界

### 本轮执行

- 后端 `pytest`、`ruff`、`compileall`。
- 前端 `npm run build`。
- API 聚合与数据库直查交叉核对。
- Browser 逐页访问、真实点击按钮、检查页面反馈与控制台日志。
- 监控后端运行日志与前端开发服务日志。

### 需单独确认后执行

- 删除数据的最终确认。
- 修改密码、禁用账号、重置密码等会改变账号状态的最终提交。
- 启动 AI 审查、安全扫描、圆桌讨论等会将代码发送到 DeepSeek API 的最终提交。

## 验收标准

- 自动化测试和构建检查通过。
- 页面导航可访问，无未处理控制台错误。
- 每个可见按钮至少完成一次真实点击或验证到风险操作的最终提交前。
- 所有异常均记录、修复并回归，或在 TODO 中明确列出阻塞原因。
