# 全量功能回归测试 · 共识文档

## 需求描述

在真实 Docker MySQL 环境中，对棱镜 Prism 平台执行可复现的全量回归测试。测试同时覆盖自动化验证、API 数据准确性核对、浏览器逐页真实操作和日志监控。

## 技术约束

- 数据库固定使用 `cr_mysql` 容器。
- 页面操作优先使用 Browser 插件，系统界面检查使用 Computer Use 补充。
- 不把已有历史验收结论当成本轮结论，所有结果重新验证。
- 风险操作必须在最终提交前停下并取得用户确认。

## 集成方案

1. 启动 MySQL 和 FastAPI，保留后端日志会话。
2. 运行后端测试、静态检查、编译检查、前端构建和数据核对脚本。
3. 使用 Browser 登录管理员账号，遍历全部导航页面和页面内可见交互。
4. 每次页面变更后读取 Browser 控制台错误，关键流程后检查后端日志。
5. 对发现的问题实施修复并回归。

## 验收标准

- `pytest` 无失败。
- `ruff` 无错误。
- `compileall` 无错误。
- `npm run build` 成功。
- 数据交叉核对无不一致。
- 浏览器控制台无未处理错误。
- 后端日志无未处理异常堆栈。
