# v3.9.4 完整复核与角色授权收敛共识

## 验收标准

1. 代码与数据库只存在三个可分配角色；超级管理员唯一且不可分配。
2. 审计员用户绑定迁移为评审员，审计权限并入评审员；非核心自定义角色停止分配并禁用，不静默删除审计数据。
3. 所有角色设置入口执行覆盖式基础角色替换，降级后不残留附加角色权限。
4. `pentest:authorize` 与 `pentest:start` 分离；申请人与批准人不可为同一人；批准人、时间窗和规则版本落库可审计。
5. 小菱旧裸缓存不迁移到当前账号；账号作用域历史仍由服务端恢复；浮窗显示状态按账号持久化。
6. 新增迁移可在 SQLite/MySQL 路径执行，后端权限与状态机测试、前端会话与页面测试通过。
7. 生产发布前完成数据库备份；发布后核对版本、迁移、角色行、待授权流程、负向 403 和回滚点。

## 本轮不冒充完成

- 标准 CodeQL/CNVD/CNNVD 规则真实入库和扫描执行器集成。
- 安全中心与审查规则的页面级合并、全项目重复功能普查后的批量重构。
- 全输入点注入矩阵和真实 DeepSeek 超长项目回归。
- 公网远程目标的主动渗透探测。
