# 用户功能导航与接口接入 - 共识文档

## 需求共识

管理员是平台超级用户，既可使用 Agent 治理后台，也可进入代码中心、规则、论坛、个人知识库、个性化画像和维修工单等主站页面。管理员放行只影响前端路由和入口可见性，数据范围继续由后端当前用户、管理员检查和服务层权限控制。

## 技术方案

- `canAdminOpenPath` 允许管理员访问所有安全的站内路径，仍拒绝协议相对路径与登录/注册页。
- 路由守卫中的管理员不再受“仅管理页”二次限制，保留对非管理员 `/admin/*` 的拒绝。
- 新增统一导航角色判定函数，主菜单和全局搜索共享；管理员绕过用户/审查员菜单角色过滤。
- 全局搜索补齐代码中心、论坛、知识库、个性化画像和维修工单入口。
- 后端契约测试显式覆盖 `/projects`、`/rules`、`/forum/posts`、`/knowledge/docs`、`/knowledge/stats`、`/me/profile`与 `/maintenance`。

## 约束

- 不改变后端路由前缀、Schema 和数据库结构。
- 不弱化非管理员对后台的隔离。
- 不对六个页面做与导航无关的视觉重构。
