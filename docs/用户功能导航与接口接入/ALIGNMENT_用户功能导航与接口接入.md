# 用户功能导航与接口接入 - 对齐文档

## 原始需求

修复用户代码中心、审查规则、开发者论坛、个人知识库、个性化画像和申请维修无法进入的问题，并确认这些页面的前后端接口完整接入。

## 生产复现与根因

- 当前登录账号为管理员。
- `roleHome.ts` 把管理员限制在少量“管理相关”路径，`/code`、`/rules`、`/knowledge`和 `/profile/personalization` 会被守卫静默重定向到 `/dashboard`。
- `AppSidebar.vue` 声称管理员显示全部主菜单，实际仍按 `roles` 过滤，导致用户功能入口被隐藏。
- `AppHeader.vue` 的全局搜索使用同样的角色过滤，管理员不能通过搜索进入用户功能。
- 开发者论坛与申请维修当前路由可进入，页面数据也正常；需纳入统一回归，防止后续权限修改再次破坏。
- 生产管理员会话对项目、规则、论坛、知识库文档/统计、画像和维修工单的 7 个首屏请求均返回 HTTP 200，后端路由与数据结构已存在。

## 任务边界

- 管理员作为超级用户，可进入全部已认证主站页面和 `/admin/*` 管理页面。
- 普通用户和审查员仍不能进入 `/admin/*`，不放宽后端数据隔离。
- 统一修复路由守卫、主菜单和全局搜索的角色可见性。
- 显式固定六类用户功能的前端 API 与 FastAPI 路由契约。
- 不在生产冒烟中创建帖子、工单、知识文档或规则；写接口由自动化测试验证契约。

## 验收标准

1. 管理员可从主菜单直接进入六个指定页面，不被送回工作台。
2. 全局搜索包含六个页面，管理员可执行跳转。
3. 普通用户/审查员仍被拒绝进入 `/admin/*`。
4. 六类页面所有前端 API 调用均能匹配已注册 FastAPI 路由。
5. 前端测试、ESLint、类型检查和生产构建通过，后端契约回归通过。
6. 生产 Frontend 切换后，六个页面点击、标题、首屏数据和控制台均正常。
