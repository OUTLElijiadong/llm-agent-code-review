# 小菱安全中心运维手册

## 上线与回滚

小菱安全策略保存在 `system_config` 表，配置键为 `copilot_security`。本功能复用现有表结构，不新增数据库迁移。发布前按项目既有流程部署后端，并用管理员账号检查安全中心、策略读取、事件查询、导出和趋势接口；先确认管理入口的权限配置包含 `security:view`。

回滚应用版本不需要回滚数据库结构。策略数据仍保留在 `system_config` 中；回滚后应确认旧版本对该配置的兼容性，并通过管理界面核对当前生效策略。不要为回滚直接删除该配置项。

## 紧急处置三步

1. **拉停机**：由超级管理员立即启用紧急停机开关并记录原因，阻止小菱继续处理会话和工具调用。
2. **看事件**：在事件列表按时间、类型和状态筛查，并结合详情确认发生过程；必要时导出 CSV/JSON 供值班记录和后续分析。
3. **修策略**：确认根因后调整相关策略或白名单，检查态势检查项并复核事件；满足恢复条件后再关闭停机开关。

## 最顶级预设注意事项

启用 `max`（最顶级）预设时，不要清空 `ip_allowlist`。应先确认管理员出口地址与网段均已正确列入，再应用预设并验证访问。切换预设会保留现有白名单，但管理员后续手工编辑仍可能改变它；变更前后都应复核。

## Nginx 反向代理与来源 IP

默认情况下服务只读取 TCP 连接对端地址。只有确认应用仅能通过可信 Nginx 反向代理访问，且代理会覆盖客户端提交的转发头时，才开启策略 `trust_proxy_headers`。

Nginx 应使用自身观察到的客户端地址覆盖 `X-Forwarded-For`，不可把来访请求中原有的同名头直接透传。例如：

```nginx
proxy_set_header X-Forwarded-For $remote_addr;
proxy_set_header X-Real-IP $remote_addr;
```

应用按 `X-Forwarded-For` 的第一个地址识别来源，因此在多层代理场景中必须由最靠近应用且可信的代理按约定重写该字段为已验证的客户端地址。不得用 `$proxy_add_x_forwarded_for` 保留未可信客户端提供的头部作为首项。还应通过网络访问控制确保外部客户端无法绕过代理直连应用；否则客户端可以自行伪造转发头。变更后从受控出口核对审计事件记录的 IP，再启用依赖来源 IP 的限制策略。

若无法保证代理隔离、头部覆盖和地址解析约定，保持 `trust_proxy_headers` 关闭；此时安全中心看到的将是代理对端地址，不是终端客户端地址。

## 命令行配置（推荐给自动化/无界面场景）

策略是**数据不是代码**：迁移到新数据库、重装环境或误改后，用脚本重新落一次即可。
脚本只调用业务服务，不手写 SQL，可重复执行：

```bash
cd backend

# 看当前口径与评分
.venv/bin/python scripts/apply_copilot_security_preset.py --show

# 套用最顶级预设 + 限制来源（生产实际在用的那一份）
# 生产环境请改成你当前的出口 IP/CIDR；下面这份是 2026-11-17 生产落库值
python scripts/apply_copilot_security_preset.py --preset max \
  --allow 127.0.0.1/32 --allow ::1/128 \
  --allow 183.6.24.0/24 --allow 117.141.246.34/32 \
  --allow 113.90.157.113/32 --allow 123.166.61.81/32

# 容器内执行（不依赖宿主 python 环境）
docker exec -w /app cr_backend python scripts/apply_copilot_security_preset.py --show

# 换出口 IP 后只改白名单，不动其它策略
docker exec -w /app cr_backend python -c "import sys; sys.path.insert(0,'/app'); \
from app.core.database import SessionLocal; from app.services import copilot_security_service as s; \
db=SessionLocal(); s.save_policy(db, patch={'ip_allowlist': ['183.6.24.0/24']}, client_ip='ops'); db.close()"

# 只预演不写库
.venv/bin/python scripts/apply_copilot_security_preset.py --preset max --dry-run

# 事故处置：停机 / 解除
.venv/bin/python scripts/apply_copilot_security_preset.py --kill-switch on --reason "疑似注入投毒"
.venv/bin/python scripts/apply_copilot_security_preset.py --kill-switch off
```

注意：

- 切预设**不会**清空手填的 `ip_allowlist` / `tool_allowlist` / `tool_denylist` / 停机开关。
- 该脚本不写操作者身份（审计里 `ip` 记为 `cli`），留痕请配合发布记录。
- 数据库不可用时报 `Can't connect to MySQL ... 3307`：先起容器再执行，脚本不会静默跳过。
