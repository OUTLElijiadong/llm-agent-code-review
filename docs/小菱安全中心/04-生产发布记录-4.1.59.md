## 4. 姿态评分与唯一剩余缺口

发布后生产 `posture.score = 91 / A`。唯一剩余项是 `ip_allowlist`（来源 IP 白名单）。

**没有替管理员填这个白名单**，因为生产审计里超管最近 90 天的成功登录来源分布很散
（`117.141.246.34` 59 次、`37.9.33.104` 23 次、`92.223.71.190` 21 次、`183.6.24.15` 14 次、
`123.166.61.81` 9 次、`45.135.228.155` 8 次 …）。其中 `37.9.33.104`、`92.223.71.190`、`45.135.228.155`
是境外地址，**建议先核实这些登录是否本人**（这属于账号侧风险，不是本次发布能修的）。
在核实前把白名单钉死会直接锁死管理小菱，因此保持为空，改由「注入拦截 + 工具闸门 + 审批 +
会话绑定 + 预算」构成实际防线。

管理员确认常用出口 IP 后在页面上填入即可把评分推到更高，且白名单为空时不会误锁。
