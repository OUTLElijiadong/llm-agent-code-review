# 小菱安全中心使用手册

本手册面向具有管理员权限的运维人员。进入管理台「小菱安全中心」后，可以查看安全态势、调整策略、演练文本检测并查询或导出安全事件。读取页面需要管理员身份及 `security:view` 权限；策略修改、预设切换和停机开关由超级管理员执行。

## 切换策略预设

在「预设」区域选择观察、平衡、严格或最顶级。确认提示会说明预设影响，确认后生效。最顶级预设还要求显式确认。

预设决定基础防护力度。切换预设会保留手动维护的 IP 白名单、工具白名单、工具黑名单和停机开关状态。切换后检查策略表单及态势检查项，确认现场配置符合预期。

## 配置 IP 白名单

在会话防护配置中填写允许访问的 IPv4/IPv6 地址或 CIDR 网段，每项一行。例如：

```text
203.0.113.18
10.20.0.0/16
2001:db8:1234::/48
```

保存前确认列出的网段覆盖实际管理员出口地址。启用白名单后，不在范围内的来源会被拒绝；错误的 CIDR 会被后端校验拒绝。若服务位于反向代理之后，先按运维手册配置代理来源识别，再维护白名单。

## 配置工具白名单

工具白名单填写工具编码。列表非空时，只有列入的工具可通过该层安全策略。平台常用的只读查询工具包括：

| 工具编码 | 用途 |
| --- | --- |
| `list_projects` | 查询当前账号可见项目 |
| `get_project_detail` | 查询项目详情 |
| `list_review_tasks` | 查询审查任务 |
| `list_review_issues` | 查询审查问题 |
| `list_code_files` | 查询项目代码文件 |
| `list_reports` | 查询审查报告 |
| `list_rules` | 查询审查规则 |
| `dashboard_summary` | 查询仪表盘摘要 |

以上编码来自平台固定工具契约。启用前应根据小菱实际工作流选择最小必要集合，并在页面中逐项核对当前版本是否仍提供相应能力；不要把写操作工具放入白名单来替代审批配置。`audit_security_for_file` 与 `audit_security_for_task` 会触发安全审计流程，不属于此处列出的普通只读查询工具；如确有需要，先核对当前策略对这些工具的审批和拒绝规则，再决定是否加入白名单。

## 使用注入检测演练

在「注入演练」文本框输入待评估内容，点击「演练」。结果展示检测分数、命中规则和脱敏文本。演练只返回分析结果，不写入审计事件，也不会拦截或执行输入内容。不要将真实凭据或不必要的个人信息粘贴到演练框。

## 查看、导出事件与趋势

事件列表可按事件类型、状态和天数筛选，并通过分页查看时间、操作者、来源 IP、目标与详情。状态 `failed` 表示失败或被拦截，`info` 表示提示类记录。

点击「导出」可下载当前筛选条件对应的 CSV（适合表格查看）或 JSON（适合后续处理）。导出支持事件类型、状态和时间窗筛选；天数表示从当前时刻向前滚动的时间范围。趋势页只按所选天数按自然日展示全部事件类型，日期轴中的无事件日期以 0 显示；按类型汇总包含总数、失败数及最近发生时间。趋势的日期范围按自然日计算，与导出的滚动时间窗边界不同。

## 何时启用紧急停机

确认小菱正在发生异常工具调用、疑似越权或持续触发危险操作，且需要立即阻止其继续工作时，由超级管理员启用「停机开关」，并填写简明原因。随后按运维手册查看事件、调查原因并修正策略。处置完成且验证恢复条件后，再由超级管理员关闭停机开关；不要把停机当作常规策略切换手段。
