# 全 AI 上下文压缩与完整性：交付说明

## 问题与结果

小菱、正式审查、审计、已发布与临时 Agent、沙箱辅助 Agent、报告和知识调用中，原有多个固定前缀、尾部或条数裁剪会把部分内容当作完整输入或输出。候选实现把长输入改为可核对来源 ID、哈希和顺序的分片压缩；把长输出改为有界重试、拆批或明确失败。服务端保存同账号会话原始记录，浏览器仅提交新消息并可分页回看。

单个模型无法在数学上保证理解每一句上文；来源覆盖和原始账本保证可以检查哪些材料参与处理，并在材料不全时停止产生“完成”的结论。正式审查仍以原文分片检查为准；临时 Agent 的摘要不能替代正式审查证据。
