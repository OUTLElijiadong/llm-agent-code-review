# 全 AI 上下文压缩与完整性：执行契约

## 范围

覆盖所有实际调用模型的聊天、编排、审查、审计和已发布 Agent 生产入口；纯规则/确定性步骤不伪装为模型压缩范围。每条链路记录现有分批、压缩、工具结果、输出预算及终态，优先复用已有组件，保持现有授权与审计。

## 验收标准

1. 超阈值内容进入模型前可按来源分批/压缩，较晚用户约束和长内容尾部仍能在可检索证据中定位；结果注明文件行、发言序号或消息来源。
2. 所有分片均有完成/失败记录；缺失覆盖、摘要无法完成或输出 `length/incomplete` 时不得形成“已完整审查、未发现问题”的成功报告。
3. 并行 Agent 的每个结论可追踪到其输入覆盖；总控合并不能把子 Agent 失败隐藏为成功。
4. 会话原文与工具账本不使用 UI 预览的字符/数量裁剪；长历史恢复有游标或服务端连续上下文契约，保持账号隔离和顺序。
5. 单元/集成覆盖长消息尾部、第十三条及之后的修正、超长工具结果、模型长度耗尽、失败分片及多 Agent 部分失败；发布后真实模型和浏览器多样本验收。

## 状态边界

此文是用户已明确范围和可测试的工程契约，不表示上述每条链路已经实现。完整入口盘点与实测结果另记于验收文档。
