# 日志数据追溯验证总结

## 变更摘要

本轮补齐了日志与业务数据在真实网页上的追溯能力。AI 调用日志现在可以从列表和详情直接看到项目、任务、文件、用户、分片、Token、Prompt、Response，并跳转到任务或代码文件。审查任务详情现在返回完整关联文件列表，页面可从任务跳转到项目、报告和代码文件。系统审计页新增日志 ID、操作者 ID 和对象追溯入口。
