# 棱镜 4.0.1 更新说明

小菱可以复用已有 Agent，也可现场生成具有独立职责和提示词的临时 Agent，并组成混合并行团队。临时定义仅当前账号的当前团队任务可执行，终态后保留审计记录，不加入永久 Agent 库。

- 临时专项分析读取当前账号有权查看的资料，最多 5 个文件、每文件 12000 字符、结构化用户上下文总上限 60000 字符，明确披露覆盖及局限。正式全项目审查和安全审计继续使用完整内置工作流；业务写操作由主小菱的现有工具和审批链执行。
- 聊天历史、事件、图片、追问、圆桌、团队、私人知识、审批和相关日志按账号隔离；管理员及超级管理员的业务权限不开放他人聊天原文。
- 换号时清理旧界面状态，丢弃旧账号迟到的网络响应；草稿与快照按账号和入口保存。聊天保存的笔记进入本账号个人知识库，历史聊天知识按原运行归属过滤。
- 小菱图标重绘为圆润菱形小精灵，保留工作、思考、等待和错误状态，支持减少动画。
- 修复安全扫描成员绕过主小菱 security:scan 权限包装的路径，创建和执行均检查当前权限。
- 修补生产依赖 AnyIO 的三项已知漏洞，锁定 4.14.2 及官方制品哈希；前后端生产依赖审计通过。

发布按精确提交构建，经过备份、隔离恢复、回归与生产验收后交付。验收的样本范围和未完成项以本次验收文档为准。
