# Agent 项目选择模糊匹配与自定义输入 - 对齐文档

## 原始需求

Agent 聊天追问项目时不能只提供一个固定选项。项目较多时需要支持按名称模糊查询，并提供“其他”入口允许用户自定义输入。

## 现状理解

- 后端 `ChatAssistantAgent._resolve_project` 已支持从用户原话或 `project_query` 中模糊匹配项目，并最多返回 8 个推荐候选。
- 前端 `AgentChatDrawer` 在后端已提供候选时不会再加载完整项目列表，因此一个推荐候选会变成唯一可选项。
- 当前 `el-select` 虽然启用了 `allow-create`，但提示为“输入项目 ID”，没有显式“其他”入口，也没有把自定义项目名称转换为后端可解析的 `project_query`。

## 范围

- 项目选择器合并后端推荐候选和项目 API 查询结果。
- 输入关键词时调用项目列表 API 做名称包含查询。
- 增加“其他（自定义输入）”，支持输入项目名称或项目 ID。
- 保持后端当前用户项目可见性、危险操作确认和 Clarify 多轮协议不变。

## 已决问题

- 自定义数字按项目 ID 提交。
- 自定义名称按 `project_query` 提交，由后端模糊解析后再次确认，不直接猜测执行。
- 本次不新增数据库字段、不改变项目 CRUD 和 RBAC。
