# Agent 项目选择模糊匹配与自定义输入 - 共识文档

## 需求描述

Agent 追问 `project_id` 时，项目选择控件必须展示可搜索的项目候选。后端推荐项不能覆盖完整项目列表；用户还可以通过“其他”输入未显示的项目名称或 ID。

## 验收标准

- 后端只返回一个推荐候选时，前端仍会加载并合并项目 API 结果。
- 输入项目名称关键字会调用 `/api/projects?keyword=...`，最多返回 100 条当前用户可见项目。
- 推荐候选、搜索结果按项目 ID 去重，推荐候选保持在前。
- “其他（自定义输入）”始终位于选项末尾。
- 自定义数字转换为 `project_id`；自定义名称转换为 `project_query` 并触发后端模糊确认。
- 自定义输入为空时禁止提交并给出明确提示。

## 安全边界

项目 API 和后端 Orchestrator 继续按当前用户过滤可见项目；前端搜索结果不构成授权依据，最终操作仍由服务层校验。
