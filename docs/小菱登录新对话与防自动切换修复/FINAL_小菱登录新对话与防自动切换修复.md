# 总结：小菱登录新对话与防自动切换修复

## 已完成

- 每次成功凭据登录后，普通端和管理端小菱在各自首次打开时创建一个全新的空白对话。
- 同一次登录中关闭再打开，继续最后一次由用户明确选择的会话。
- 创建新对话后，服务端目录轮询、Agent Mesh 心跳、后台任务完成、历史恢复响应均不能自动切换当前会话。
- 后台任务、审计执行、服务端检查点、团队卡片、会话恢复和历史列表均保留。
- 默认对话和既有历史未删除，用户仍可在会话菜单中显式选择。
- 普通端与管理端共用的会话选择契约已由自动化测试覆盖。
- 普通用户与超级管理员两个公网入口均已完成真实登录、时间窗、关闭重开、历史保留和显式切换验收。

## 实现要点

- 成功登录与 Token 恢复分离，只有真实凭据登录产生本次登录的新对话标记。
- 移除打开面板时按忙碌状态选中历史会话的逻辑。
- 移除服务端发现按最近心跳自动聚焦会话的逻辑。
- 移除普通端、管理端后台 Mesh 消息完成时主动聚焦目标会话的逻辑。
- 新创建或当前会话在首次心跳落库前进入保留集合，防止服务端目录短暂未发现时被剔除。
