## 故障复现

在修复前的 `www.lijiadong.cn` 普通用户会话中复现到：

1. 打开小菱时显示旧会话“请组建一个只读子 Agent 团队核…”，不是新对话。
2. 点击“新建对话”后立即显示“新对话”。
3. 等待约 11.5 秒后，当前标题自动变为“帮我全面审计皮卡丘漏洞平台…”。

根因是前端把 Agent Mesh 的后台心跳、服务端目录发现和后台任务完成误当成“应切换当前会话”的信号。后端只按明确的 `surface + session_id` 恢复会话，不负责默认选中，因此无需修改数据库或后端契约。
