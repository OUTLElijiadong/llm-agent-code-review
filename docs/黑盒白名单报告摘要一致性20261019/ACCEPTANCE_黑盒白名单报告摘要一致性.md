## 问题复现

生产任务 `sbx_7d1ffc7ba9cb40c1bca743d3` 的下载报告在详细证据中列出三条 HTTP 200 请求，却在覆盖摘要写“执行器未提供可核验的逐项范围”“执行器未报告未扫描项”“无已记录跳过项”。`evidence.blackbox_execution.requests` 与 `evidence.agent_test_generation.status=skipped` 已在实际报告对应的持久执行结果中证明该摘要错误。

## 候选实现

- 确定性报告从精确白名单请求回执派生逐条已测试范围，并写明白名单外路由发现未执行。
- AI 动态测试明确 skipped 时，摘要写出未执行状态和证据中可用的原因。
- 请求结果未知时不写成通过或失败；无请求回执时明确没有可确认的已测路径。
- 已保存的精确白名单报告只有在回执非空且摘要含旧版矛盾短语时，才可由创建者通过现有终态 stop 操作触发重建。重建只读持久化执行结果，不启动 Worker、不发送 HTTP、不调用模型，并刷新报告正文与对应导出制品。
- 白名单任务仍标为部分覆盖；HTTP 状态断言通过不解释为漏洞验证通过。
