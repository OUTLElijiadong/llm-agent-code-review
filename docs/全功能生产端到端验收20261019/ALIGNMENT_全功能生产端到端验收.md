# 全功能生产端到端验收：对齐文档

## 原始需求

用户要求完成 Prism 正式部署后的全功能验收：代码审查、审查报告、沙箱白盒/黑盒测试、远程网站评估均可正常生成和读取报告；报告必须属于当前账号可见范围，无权查看的报告不得显示卡片；报告内容、状态、格式、排版准确清楚；逐页点击并滚动检查前端显示；普通用户、审查员、管理员账号边界正确；管理员页面重点展示每日 Token 用量；圆桌任务能够由小菱调度、接收插话、停止后不自行重启；漏洞来源优先级以 CNVD 与 CNNVD 为主，分别标明，二者明确无匹配时才显示标注清楚的 OWASP 参考。

用户明确要求：GitHub 上传失败不作为部署阻断；避免反复改版本；产品行为仅用真实生产网站验收，不以本机页面或本地测试替代；不要删除业务数据。审查员账号已由用户在 Safari 登录；超级管理员此前已由用户确认验证过。

## 现有项目理解

Prism 使用 Vue 3/Vite/Element Plus/Pinia 前端，FastAPI/SQLAlchemy/Alembic 后端，MySQL 持久化，Docker Compose 与精确 SHA 发布事务。页面路由由 Vue Router 守卫控制；报告列表、详情和导出共用后端来源权限和对象归属判断。黑白盒与远程评估是领域报告，需复用其已持久化原始报告，不得把失败、未知或未覆盖误写成通过。

## 范围与边界

- 使用生产 Safari 检查页面、交互、滚动、状态、权限和报告导出；生产验收不在本机运行。用户另明确授权对 `https://lijiadong.cn/` 根地址发起一次受限只读远程评估，平台要求由另一具备“渗透测试授权”权限的账号独立批准；批准前不进行任何探测。
- 当前生产基线为 `4.1.10`，本次候选版本为 `4.1.11`；只进行一次正式部署，不追加额外版本号。版本号保持三段式；GitHub 上传失败不阻断部署。
- 优先复用生产已有数据与报告；不为重复验证发起新的 LLM 审查/扫描。仅执行已获用户明确授权、且经平台独立审批的这一次根地址远程评估。
- 不删除报告、项目、用户、备份或其他业务数据，不修改账号角色/权限、安全策略、模型供应商凭据。
- 所有报告事实须来自可读报告、执行记录或原始领域快照；未知和未覆盖内容须明确呈现。
- CNVD/CNNVD 权威数据接入不能在没有官方授权接口/数据的情况下伪造或绕过登录；当前只允许诚实标明接入状态。
