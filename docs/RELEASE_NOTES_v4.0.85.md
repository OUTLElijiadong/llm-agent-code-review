# Prism v4.0.85

2026-10-08 00:21 UTC 已部署生产，发布 SHA：`727d636c22e5ff7e8d7fe887f934867ce591e1f3`。Backend、Frontend 和独立 Sandbox Worker 与生产发布账本一致。

此版本修复沙箱 Worker 的提交与周期回收器竞态。任务处于提交中的 `validating` 或 `preparing` 阶段时，同进程 janitor 会识别进行中/待处理提交预约，不再把任务误判为 Worker 重启遗留任务并提前终止。真正 Worker 重启后，进程内预约消失，遗留任务仍按失败关闭策略回收。

v4.0.84 已修正黑盒、白盒和组合测试的阶段事件及前端标签。本次生产 Worker 复测中，黑盒有效路由、白盒、组合各 3/3 成功；无可识别路由在扫描阶段拒绝，以及已识别路由实际返回 HTTP 404，这两类负例各 3/3 按预期失败。Safari 普通窗口确认页面版本为 4.0.85。该复测通过 Worker UDS 执行，不覆盖真实账号从 UI 提交任务的完整业务闭环。

无数据库结构或 Alembic 迁移变更。详细范围和未覆盖项见 [沙箱修复验收记录](沙箱测试阶段标识修复20261008/ACCEPTANCE_沙箱测试阶段标识.md)。
