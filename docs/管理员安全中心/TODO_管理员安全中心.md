## 已知功能边界与后续决策

- 自动封禁/反击没有实现或启用。若要增加，需另行确定授权范围、白名单、误报回滚、审批和审计流程；当前工作不执行这类操作。
- 时间线不覆盖每个成功只读管理 API 请求，也不呈现完整 SSH/Nginx 原始日志。需要完整取证时，应先扩展带权限和保留策略的日志接入，并避免把“无记录”解释为“未发生”。
- 外部报告没有随任务提供可复核的原始服务器日志；报告指称的攻击结果、攻击来源归属和用户身份仍未在本次生产核实。
- 本地测试使用 SQLite；MySQL 方言已通过 SQLAlchemy 编译检查。生产 MySQL 的真实请求执行情况需在部署后通过安全中心/旧告警只读接口确认，不写入人工构造的生产记录。
