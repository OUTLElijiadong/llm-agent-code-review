# 管理员安全中心交付总结

## 已完成实现

- 增加仅最高管理员可用的独立安全中心页面与 API，使用盾牌主题展示运行资源、采集状态、事件时间线和监控策略。
- 时间线展示平台实际持久化的安全告警、巡检、运维采集及相关审计摘要，并明确记录时间、数据覆盖与归因边界。
- 增加可审计的监控灵敏度调整，后端只允许保持或增强检测能力。
- 旧安全告警不再从普通治理告警路径泄漏；保留告警原始证据，处理备注以结构化记录追加。
- 增加完整样本的 Nginx HTTP 错误阈值告警，采集截断时不把下界说成总量。
- 修复 `source` 缺失及空白字段导致的 SQL 列表过滤与对象级权限判定不一致。

## 明确边界

本次交付是被动监控与可审计告警策略，不实现自动封禁、反击、进攻式追踪、生产密钥轮换或安全组调整。安全中心展示已接入的 SSH/Nginx 规则告警与采集回执，不等价于完整原始服务器日志；未审计的成功只读 API 不会自动进入时间线。报告内容没有原始服务器证据支撑时只作为报告主张展示。
