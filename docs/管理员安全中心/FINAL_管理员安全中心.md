# 管理员安全中心交付总结

## 发布结果

管理员安全中心及两项运维修复已发布到生产，当前版本为 v4.0.43，完整提交 SHA 为 `7529fcd3a7d42236faf2f786e629f989f233635d`。

v4.0.42 修复了 Nginx 安全监控采集器参数缺失造成的采集失败。v4.0.43 修复了部署 dotenv 中的 `BACKUP_DIR` 未被定时巡检、备份校验和部署容量检查读取的问题。后者在 v4.0.42 生产上先复现出误报，再以未导出该变量的方式在候选与生产重复验证。

## 已完成实现

- 增加仅最高管理员可访问的独立安全中心页面和 API，用盾牌视觉展示运行资源、监控来源、事件时间线与监控策略。
- 时间线展示平台实际持久化的安全告警、巡检、运维采集及相关审计摘要，并说明时间范围、数据覆盖和归因限制。
- 监控灵敏度变更只允许维持或增强检测能力，并保留审计记录。
- 旧安全告警从普通治理告警路径隔离；处置备注以结构化记录追加，保留原始告警证据。
- 增加 Nginx HTTP 异常阈值告警；采集到上限时标明统计下界。
- 统一 SQL 列表过滤与 Python 对象级检查对来源、类型、分类及空白字段的识别。
- 运维脚本统一从环境变量、部署 dotenv 或默认目录解析持久备份路径，避免 systemd 未导出 `.env` 值时误报或使用错误目录。

## 明确边界

本次交付是被动监控与可审计告警策略，不实现自动封禁、反击、进攻式追踪、生产密钥轮换或安全组调整。安全中心展示已接入的 SSH/Nginx 规则告警和采集回执，不等价于完整原始服务器日志；没有证据的报告主张不表述为生产事实。最高管理员会话读取成功，不代表本次已完成未登录 401、普通管理角色 403 的生产矩阵。因而本交付不是全站渗透测试通过声明。
