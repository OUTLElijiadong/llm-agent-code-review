# 管理员安全中心对齐

## 原始需求

根据用户提供的管理员提权链报告、Prism 渗透报告、安全评估交付书和 exploit 脚本，核查报告后完善 Prism 管理员安全体验：新增独立安全中心，用盾牌视觉展示服务器安全/小菱监控记录，并提供可调整的防御配置；优化页面交互。

## 范围

- 为唯一超级管理员增加独立 `/admin/security-center` 页面和后端安全中心 API。
- 页面分别呈现服务器运行环境资源、监控最近运行状态、已落库告警、只读采集动作回执、安全监控策略变更记录。
- 新增可分页、受 super_admin 保护、限字段且脱敏的时间线；展示时间代表系统记录/采集时间，不冒充原始攻击发生时间。
- 提供受限安全监控策略配置，只允许增强告警灵敏度；继续保持仅监控与告警，禁止自动封禁、反击和服务隔离。
- 修复告警关闭时覆盖原始证据的逻辑。
- 纳入 Nginx 重复 HTTP 400/403/444 被动告警修复与验证。
- 页面适配桌面和移动尺寸，并提供加载、失败、过期、无记录状态。

## 边界

- 静态阅读附件，绝不运行 `exploit-admin.sh`、复制或展示报告里的令牌/密钥/密码。
- 报告陈述与当前生产独立证据分开；不因报告文本自动认定第三方入侵或服务端 RBAC 被绕过。
- 不在本任务自动轮换 JWT/数据库/API 密钥，不删 SSH 私钥，不更改防火墙/安全组，不封禁或反击来源 IP。
- 不把只读巡检调用描述成已采取防御动作；没有原始日志时间戳时只展示审计时间。
- 运行期可调阈值存入受限配置，不允许安全中心直接写任意 `.env` 或主机策略。

## 已知项目约束

- 后端已有 `AgentAlert`、`AgentJobRun`、`OpsExecution`、`AuditLog`、`SystemConfig`，安全监控目前为被动采集和告警。
- `/admin/observability/security/status` 与手动巡检要求超级管理员；普通告警列表权限更宽。
- 安全规则阈值原先来自 Settings，没有专属数据库读写 API。
- 现有 `/security` 属于代码安全/规则页面，不能复用为服务器安全中心。

## 验收关注点

- 报告矛盾与证据级别清楚，页面不会把扫描尝试写成成功入侵或拦截。
- 普通用户、审查员和普通管理员不能读取主机安全中心接口；super_admin 可读取和在约束内更新策略。
- 普通管理员也不得通过旧通用告警列表/分页/未读/已读/处置接口访问 `security_monitor` 来源记录；其余治理告警维持原有管理员行为。
- Admin Copilot 对普通管理员隐藏并拒绝执行超管专属安全能力。
- 策略更改写前后安全字段与操作者审计记录；未授权或削弱监控的更新拒绝。
- 告警处置后原始 `detail_json` 仍可查，处置说明单独保留。
- 重复 HTTP 错误阈值内外、去重、采集截断、数据缺失均有回归验证。
- 桌面 1280px、手机 375/390px 版式不横向溢出，键盘和屏幕阅读器可识别关键操作。
