# 管理员安全中心任务拆分

## T01：被动 Nginx HTTP 异常告警

- 输入：当前 `nginx_attack_events` 安全采集格式、已配置窗口及阈值。
- 输出：按 IP 聚合 400/403/444 告警，阈值以下不告警，截断时标记下界。
- 验收：阈值边界、状态组合、allowlist 独立性、去重与 30,000 行截断测试通过。

## T02：安全事件聚合 API

- 输入：AgentAlert、AgentJobRun、OpsExecution、AuditLog 实际字段。
- 输出：super_admin-only 摘要状态和分页事件 feed，包含登录与高影响用户/权限/模型配置审计，字段白名单、统一记录时间、准确的持久化计划、数据源状态及可追溯操作者/来源；旧告警路径不得泄漏 security_monitor 记录。
- 验收：API 与 Admin Copilot 角色边界、旧通用告警接口隔离、分页稳定性、类型语义、敏感字段断言通过；明确未审计只读 API 请求不会自动出现。

## T03：可审计且只增强监控策略

- 输入：Settings 默认基线、SystemConfig 持久化表、AuditLog；Nginx 窗口独立于退役 FlyTrap 设置。
- 输出：查询/更新有限安全阈值配置；更新与审计在同一事务内。
- 验收：边界合法、放宽拒绝、非最高管理员拒绝、审计前后值匹配、并发重读验证。

## T04：告警证据保留

- 输入：现有 AgentAlert `detail_json` 和处理备注。
- 输出：追加结构化 resolution 元数据，不覆盖原始事件证据。
- 验收：历史有效 JSON、无效旧内容、空备注、重复处置回归通过。

## T05：安全中心前端

- 输入：新后端契约、既有管理设计令牌和响应式壳。
- 输出：独立桌面/移动安全中心，具备盾牌视觉、概览、时间线、策略编辑与错误/空状态。
- 验收：页面/API授权一致、无横向溢出、键盘状态、无数据时不绿显、前端构建测试通过。

## T06：发布与真实验收

- 输入：候选完整 SHA、受支持的生产发布流程、生产前置状态。
- 输出：发布记录与 HTTPS/运行版本/权限证据。
- 验收：生产发布门全部满足。任何备份、包哈希、迁移或版本对不上则停止。
