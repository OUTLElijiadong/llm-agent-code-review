## 验收范围

- 新增仅最高管理员可访问的独立安全中心、盾牌视觉、运行资源、被动安全事件时间线、告警处置和监控灵敏度设置。
- 审计报告中可由当前平台记录验证的内容与报告主张分开显示；未把报告文本当成已发生的生产事件。
- 安全能力只读取、汇总、调高/维持监控灵敏度；不执行攻击重放、自动封禁、反击、凭据轮换或安全组变更。
- 旧安全告警在通用治理告警列表、分页、未读、读取与处置接口隔离；SQL 查询和对象检查共享来源/类型/类别识别规则。
- 被动 Nginx HTTP 异常请求按完整采集结果聚合；采集上限时标明结果为下界，并保留来源白名单与 HTTP 判定独立。

## 复现与修复证据

1. 历史迁移记录的 `source` 可为空。修复前回归复现显示，`source=NULL` 的旧安全告警能出现在普通管理员通用告警列表，读取端点也曾接受该行；这不是生产账号越权测试结果。
2. 独立复核发现带制表符/换行的旧告警字段在 SQL 列表过滤与 Python 读取判断间存在不一致。新增测试先失败，证明普通管理员列表可见该类安全告警；统一两边对 ASCII 空白的规范化后，测试通过。
3. 最终回归覆盖空来源、NULL 来源、空格、制表符/换行、普通无来源治理告警可见/可读，以及安全告警读取/处置返回 404 且不改写记录。
4. 外部报告之间对是否从公网 Web 层取得管理员权限的描述不一致；报告未随本次任务提供可独立复核的原始服务器日志。因此本记录不认定第三方入侵生产，也不认定 Web RBAC 已被绕过。
