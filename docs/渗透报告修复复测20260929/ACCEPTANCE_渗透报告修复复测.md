## 未验证风险与明确边界

- 历史 33 个相同 `session_id` 只证明标识重复，不能据此认定跨账号消息泄漏；本轮未用两组真实账号逐个恢复这些会话并核对消息 owner，因此全局会话隔离仍未验收。
- 外部重定向 SSRF、CSP 强制策略、每天 Token 预算、BT-Panel 端口安全均未由本次复测闭环。
- 管理员浏览器控制台曾出现 Agent Mesh heartbeat HTTP 409 和一次 inbox 请求中断；其业务语义未拿到响应正文并复现确认，故记录为未分类现象，不将其写成漏洞或“控制台零错误”。
- 未完成生产端逐页移动端目测、全角色逐按钮权限矩阵、所有 UX 审计点慢网验收。本轮自动化视口通过不能替代这些未做的生产场景。生产 Safari 截图和脱敏 HAR/原始响应未归档；当前文档记录的是现场观察摘要，仓库读者无法只凭文件重放这些生产操作。
- 已验证的 40432 是业务资源不存在；本结论不承诺系统任何路径都不会返回 404。
