# 前端失败恢复风险与可测矩阵

本轮在当前源码中执行原 SFC 函数并注入本地拒绝、延迟和浏览器异常，复现 10 项失败路径；随后挂载真实 Vue 页面与 Element Plus 组件，新增 24 项回归。独立复核又补 4 项反例并修复，与既有权限、报告、Agent 口径测试合计 88 项通过。所有 API、角色与项目数据均为测试替身。没有生产 HTTP 请求、模型请求、实际下载或新增生产点击记录。

主代理的本轮 preflight 收据 `20260908-043653-5695123a36` 为 ready 后才开始写入项目。本页描述已授权的有界修复，不把仓库所有失败路径或所有按钮声明为验收完成。

## 下一阶段可测矩阵

| 维度 | 应执行的场景 | 通过标准 |
| --- | --- | --- |
| 首次读取 | 无快照时 500/503/断网，手动恢复 | 显示明确失败原因，不能以“暂无数据”假装成功，恢复后能继续操作 |
| 同条件刷新 | 有成功快照后临时失败 | 保留快照并标明未刷新，不给出同步成功提示 |
| 筛选与分页 | A 慢/B 快、B 失败、组件卸载后响应 | 最新条件归属清楚，旧响应不能覆盖新结果，卸载后不能恢复轮询 |
| 认证与资源 | 未登录、权限撤销、资源 404 | 隐藏/清除受保护旧内容，失败后不沿用写授权；不自动放行403 |
| 非幂等写入 | 创建/上传/生成请求慢、超时、部分完成 | 在途禁止重复操作；保留输入和已完成结果；结果未知先核对，不自动重放 |
| 分析与辅助读取 | 分析、技能、画像失败 | 保留用户输入或可用数据，明确哪部分未完成，可手动恢复 |
| 本地浏览器失败 | 弹窗/Blob/anchor 失败 | 持续反馈、释放 loading 与资源；不把模拟动作当真实下载成功 |
| 五角色页面控件 | 管理员、项目 A owner、A reviewer、B owner、无权限 | 每个控件独立保留 passed/failed/blocked/untested，显隐观测与点击分开 |

本轮尚未对以下候选完成挂载或生产故障注入，不标为确认缺陷：ReportList 初始读取/快速筛选；ReviewTaskList 遇 403 后是否继续 GET 轮询；Agent SSE 认证失败后的 GET 重连边界；ProjectDetail 成员列表读取错误的独立恢复提示。它们应按真实契约追加验证，再分配修复，不能按关键词批量改 catch。

现有正确恢复机制保留：ReviewTaskList 已有请求序号、快照与 GET 退避；ReviewStart 对完整文件读取失败保持执行门禁，批量创建失败不自动重放；远程导入携带已持久化幂等键。不能为了“失败后能继续”放宽认证、授权、完整性或重复写入约束。
