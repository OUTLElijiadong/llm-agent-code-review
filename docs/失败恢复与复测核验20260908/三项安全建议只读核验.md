# 三项安全建议只读核验

本文件核对实际合同与最小后续建议，不将安全建议混写为已实施修复。准入收据 `20260908-043653-5695123a36`。没有读取生产凭据、登录生产账号或执行生产写入。

## CSP 仍是只报告模式

2026-09-08 04:48:47 UTC，对公开 `/login` 的一次匿名 HEAD 返回 200；白名单响应头在 `证据/公开登录页安全响应头只读.json`。实际没有 Content-Security-Policy，存在 Content-Security-Policy-Report-Only；策略包含 script-src 的 unsafe-inline。没有 Reporting-Endpoints、Report-To，策略内也没有 report-to/report-uri。故当前策略不阻止违规资源，且不能称“已集中收集到零违规”。已有 HSTS、X-Frame-Options、nosniff 等响应头不能替代 CSP 执行。

源码位于 `frontend/nginx.conf.template`，server、index 与静态资源 location 都有对应 header；`frontend/nginx.conf` 引用该模板。生产只读 HEAD 支持当前已部署入口结论，尚未对所有路由和动态来源做浏览器 CSP 兼容采集。

最小后续方案是先收集实际脚本、字体、Worker、WebSocket 等需求和违规，再同步三个配置位置施加可执行策略，移除不必要的脚本 unsafe-inline；必要内联脚本使用明确 nonce/hash。仅改头名称但保留宽松脚本策略不能称已解决 XSS。当前没有证据证明已有可利用 XSS，也没有实施 CSP 迁移。[MDN 对 Report-Only 与报告端点的定义](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy-Report-Only)。

## JWT 确实保存在 localStorage

`frontend/src/utils/token.ts` 使用 key `review_token` 并直接调用 localStorage get/set/remove；用户 store 登录保存 access_token，`frontend/src/api/http.ts` 与 Responses 客户端读取后发 Authorization Bearer。后端检查签名、有效期、用户状态和 token_version，登录/退出/改密/禁用可使旧版本失效。配置文件默认有效期七天，但没有读取生产实际配置，不能把默认值声称为本轮核实的生产有效期。

同源脚本可读 localStorage，所以一旦同源 XSS 成立就可能盗取令牌。服务端撤销能力降低后续使用范围，不能消除脚本读取风险。HttpOnly、Secure、SameSite cookie 需要连同 CSRF、HTTP/流式接口的凭据传递、跨域策略一起设计；单行改 storage 或改成 sessionStorage 不是等价修复。本轮不改变认证架构。[OWASP 对客户端存储与会话标识的建议](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html)。

## 123456 通过的是前后端共同的现有长度合同

“只有前端校验 6–32”不准确。Register.vue 规则是 6–32，强度条只是提示；后端 RegisterIn.password 与 ChangePasswordIn 新密码也各自以 Pydantic Field 强制 6–32。auth_service.register 没有常见弱密码列表或字符构成拒绝，直接 bcrypt 哈希保存。

隔离真实 schema、service、SQLite 测试确认：5 与 33 字符被服务端 schema 拒绝，123456 则注册成功且存储 bcrypt 哈希，非明文。为隔离密码规则，测试仅关闭本地 beta 邀请开关，不能据此声称生产邀请码或验证码被绕过。具体输入/结果见 `证据/登录限流与安全建议修复前场景.json`，未使用生产账号。

最小后续修复应在服务端统一注册和改密的常见/泄露密码拒绝，再同步前端提示与直接服务调用入口，不能只加前端大小写正则。当前 OWASP 建议依有无 MFA 区分最低长度、支持至少 64 字符上限和 Unicode/空格、拒绝常见/泄露密码，并不要求机械的字符构成组合；平台还要处理既有 bcrypt 的 72 字节约束。长度、历史账号兼容及可能的哈希迁移属于独立密码政策决定，本轮未自行实施。[OWASP 认证密码规则](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。
