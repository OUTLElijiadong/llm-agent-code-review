# CNVD 与 CNNVD 生产只读核验

## 初始化与新增配置

**本次新增环境变量 key 清单为空，无需新增 .env 配置、账号或个人 API Key。** 两个来源的 adapter 在代码加载后可用，无需数据迁移、种子导入或后台同步任务。HTTPX 为项目已有依赖，没有修改依赖和锁文件。

| 项目 | 默认值 | 初始化要求 |
|---|---|---|
| CNVD 官方 origin | https://www.cnvd.org.cn | 固定在服务中，不接受请求参数提供 origin |
| CNVD 行业回退 origin | https://ai.cnvd.org.cn | 默认仅主库真实HTTP521触发，只读首页，不翻页；非全库 |
| CNNVD 官方 origin | https://www.cnnvd.org.cn | 固定在服务中，不接受请求参数提供 origin |
| CNNVD 公开游客 appId | 6i8417579268034679HXvp0Kb6r1C2A9 | 来自官网公开 JS，是公开应用标识，不是个人 Key；每次游客签名在内存临时取得 |
| 连接 / 读超时 | 5 秒 / 10 秒 | 无新增环境变量 |
| 单响应上限 | 1 MiB | 超限返回 invalid_response |
| 成功及有效空结果缓存 TTL | 300 秒 | 每进程、按来源 / 查询词 / limit 缓存 |
| 失败退避 | 至少 60 秒 | 按来源，尊重上游 Retry-After，最多 3600 秒 |
| 缓存容量 | 128 项 | 有界进程缓存，重启清空 |
| 刷新策略 | 请求触发，无后台轮询 | 缓存或退避到期后的下一请求重新访问官方源 |

当前实现没有正式授权 XML API 配置项。已核验官方 XML 文档要求单位实名认证和 AppID/AppSecret，且内部路径与签名算法不一致；没有凭据时未推测实现。游客搜索已凭正常页面初始化成功取数，旧 4030 不能再被当作未配置个人 Key 的证据。CNVD 主库521仍真实受阻，AI行业首页已正常取数；只代表该行业首页。生产域名与已有登录令牌是下文核验命令的输入，不是本次新增的应用配置。

每个 worker 独立维护状态；目录首次读取为 not_checked。重启后通过来源 API 或检索 API 触发首次核验；CNNVD 自动执行 sign → POST vulTypeList（无 body）→ sign → POST searchVul，HTTPX 在单次客户端内保留服务器正常 Cookie。多 worker 下，另一次目录请求可能落到尚未核验的 worker；前端应优先展示主动查询 API 返回的逐来源状态。当前实现不宣称持久化同步或全量漏洞库导入。

## 对外 API 与身份要求

以下均位于已有 `/api/security` 路由，需要现有 Bearer 登录令牌及 `security:view` 权限，不是匿名接口。

| 方法与路径 | 参数与默认值 | Resp.data |
|---|---|---|
| GET /api/security/vulnerability-sources | 无 | 来源状态数组，真实查询两库最新页，遵守缓存和退避 |
| GET /api/security/vulnerability-records | q=""（最多 200 字符）、source=all（all / cnvd / cnnvd）、limit=10（1–20，每来源） | {query, sources, records} |
| GET /api/security/rule-catalog | 既有参数 | 原目录；sources 内国内源增加最近观察，不隐式联网 |

`source=all&limit=20` 最多 40 条记录。CNVD 正常主库的精确编号查询读取详情；其他关键词仅筛选最新列表页（query_scope=latest_page_filter）。主库HTTP521时默认回退AI行业首页（query_scope=ai_sector_latest_page、coverage_scope=ai_sector），精确编号也只匹配该页链接。空结果不能解释为全库无匹配。CNNVD 检索官方搜索第一页（query_scope=official_search_first_page）。

认证或权限拒绝分别 HTTP 401 / 403，参数非法遵循项目统一处理 HTTP 400、code=40002；这些情况不请求官方源。平台完成上游查询处理时 HTTP 200、Resp.code=0、message=ok；这不意味着两库都成功，必须检查 `data.sources`。

## 状态与前端显示契约

来源字段定义见 `backend/app/schemas/vulnerability_source.py`。

| 字段 | 含义 |
|---|---|
| integration=implemented | 适配器代码已实现，不能单凭此字段显示官方取数已接通 |
| status=not_checked / connected=false | 当前进程还没有核验 |
| status=available / connected=true | 实际取得至少一条漏洞记录且数据结构、业务码及字段校验通过 |
| status=empty / connected=false | 官方结构完整的零命中，未取得记录；不按源站失败退避，不显示已接通 |
| blocked / rate_limited / timeout / unavailable / invalid_response | 真实拒绝、限流、超时、连接失败或响应无效，connected=false |
| stale / connected=false | 最近成功观察已过 300 秒，当前可用性需重核验 |
| checked_at / last_success_at | UTC ISO 时间；最后一次观察与最后一次验证成功必须分开 |
| cached | true 表示缓存、退避或被动目录读取的历史观察；false 才是该 API 响应的本次网络查询 |
| http_status / upstream_code | HTTP 与业务码分别保留；HTTP 200 与业务码 4030 可同时存在 |
| record_count | 该来源本次返回的记录数；不能以 0 独立判定全库无漏洞 |
| retry_after_seconds | 该次上游观察的 Retry-After 值，经 0–3600 秒约束；不是动态倒计时 |
| evidence | 每个实际请求的官方 URL、method、UTC 时间、HTTP / 业务码、响应 SHA-256、字节数；evidence.cached=true表复用原主库失败证据 |
| coverage_scope / coverage_label | ai_sector及“人工智能行业子库首页（最多20条），非CNVD全库”；前端必须保留范围 |
| primary_status / primary_http_status | 行业回退时保留主库blocked/521，不能被行业200覆盖 |
| record.source_date | 行业列表“时间”的原文日期；不推断发布日期，published_at保持null |

共享目录与失败退避状态的 last_query 清空，防止其他账号读到上一请求的私人检索词。参考源 OWASP / CodeQL 的 status、connected 可以为空；国内来源不能以这些参考源替代。HTTP 200、游客签名成功、应用页面可达均不能显示“国内官方数据已接通”。

## 发布后可直接运行的取数核验

本文件给主线程发布后执行；本子任务已完成生产出口只读协议与最终服务验证，未执行生产应用部署或生产应用 API 调用。把 `PRISM_BASE_URL` 设置为已部署实例的 HTTPS 根地址，`PRISM_TOKEN` 设置为具有 security:view 的现有登录令牌。不要把令牌放入证据文件。

以下只调用查询接口，将响应保存在执行机器临时目录；不写生产业务数据。命令使用默认空关键词，要求每个来源都能返回真实最新记录；不会以合成编号请求官方源。

```bash
set -o pipefail
: "${PRISM_BASE_URL:?请设置已部署实例的 HTTPS 根地址}"
: "${PRISM_TOKEN:?请设置现有 security:view 登录令牌}"
audit_path="${TMPDIR:-/tmp}/cnvd-cnnvd-prod-$(date +%Y%m%d-%H%M%S).json"
curl --fail-with-body --silent --show-error \
  --connect-timeout 5 --max-time 60 \
  --header "Authorization: Bearer ${PRISM_TOKEN}" \
  --get "${PRISM_BASE_URL%/}/api/security/vulnerability-records" \
  --data-urlencode 'source=all' --data-urlencode 'limit=3' > "$audit_path"
python3 - "$audit_path" <<'PY'
import json
import sys
from pathlib import Path

payload = json.loads(Path(sys.argv[1]).read_text())
if payload.get("code") != 0 or not isinstance(payload.get("data"), dict):
    raise SystemExit("平台调用未成功，请检查 HTTP 响应、登录与权限。")
data = payload["data"]
sources = data.get("sources", [])
records = data.get("records", [])
if len(sources) != 2 or {s.get("code") for s in sources} != {"cnvd", "cnnvd"}:
    raise SystemExit("未取得完整的两来源状态，取数验收未通过。")
for source in sources:
    print(json.dumps({key: source.get(key) for key in (
        "code", "status", "connected", "cached", "checked_at", "http_status",
        "upstream_code", "record_count", "retry_after_seconds", "coverage_scope",
        "coverage_label", "primary_status", "primary_http_status", "evidence"
    )}, ensure_ascii=False))
passed = all(
    source.get("status") == "available"
    and source.get("connected") is True
    and source.get("cached") is False
    and source.get("record_count", 0) > 0
    and source.get("evidence")
    and any(record.get("source") == source["code"] for record in records)
    for source in sources
)
for source in sources:
    matched = [r for r in records if r.get("source") == source["code"]]
    evidence = source.get("evidence", [])
    passed = passed and all(
        any(r.get("evidence_url") == e.get("url")
            and r.get("evidence_sha256") == e.get("response_sha256")
            and e.get("http_status") == 200 and not e.get("cached", False)
            for e in evidence)
        for r in matched
    )
    if source.get("coverage_scope") == "ai_sector":
        passed = passed and (
            source["code"] == "cnvd"
            and source.get("query_scope") == "ai_sector_latest_page"
            and source.get("primary_status") == "blocked"
            and source.get("primary_http_status") == 521
            and "非CNVD全库" in source.get("coverage_label", "")
            and any(e.get("http_status") == 521 and e.get("url", "").startswith(
                "https://www.cnvd.org.cn/") for e in evidence)
            and any(e.get("url") == "https://ai.cnvd.org.cn/"
                and e.get("http_status") == 200 for e in evidence)
            and all(r.get("coverage_scope") == "ai_sector"
                and r.get("source_date") and r.get("published_at") is None
                for r in matched)
        )
        print("CNVD覆盖：人工智能行业首页，主库521仍受限，非全库。")
print("响应证据文件：", sys.argv[1])
print("真实最新记录取数验收：", "通过" if passed else "未通过，按逐源状态处理")
raise SystemExit(0 if passed else 2)
PY
```

此脚本的通过标准比结构完整的零命中响应更严格：必须两来源都新请求成功且有真实记录及证据绑定。CNVD若为行业回退，还必须确认范围、来源日期及原始主库521证据；通过不代表CNVD全库已接通。退出码 2 表示本次真实取数验收未通过，不能改成成功提示；后端隔离测试中的成功夹具不满足这个验收。

如果 cached=true，保留已有证据，等待缓存 / 退避期限结束后重试。成功缓存为 300 秒，普通失败至少 60 秒；有 Retry-After 时按该次 checked_at 与等待时长判断。没有强制跳过退避参数，也不要通过反复重启或更换关键词刷官方源。多 worker 环境逐个观察响应证据，只有 cached=false 且带新时间戳的结果才能证明该次服务端实际访问。

也可分别请求上述检索路径的 source=cnvd / source=cnnvd 分离诊断；不要单凭 rule-catalog 认定已主动核验。
