# CNVD 与 CNNVD 后端需求对齐

## 原始需求与写集

国内两库必须走真实官方源；前端不能无证据声称未接入，也不能把失败包装成成功。当前子任务只交付后端漏洞来源 service、API、schema、测试及本主题文档。直接编辑共享工作树，不 commit、不部署、不操作生产数据。前端与发布由主线程负责。

## 已核实的项目能力

已有 `httpx`、`/api/security` 路由、`security:view` 权限、`Resp` 包装和统一安全规则目录。原目录仅有两库门户引用，没有查询客户端。现有配置文件未发现两库专用配置项，不读取或输出其他凭据。

## 门禁与澄清

主线程收据 `20261021-141119-9c75d53bc4` 已确认 `hard_gate=ready`。当前授权足够实施限定写集；发布、模型提示词、团队和讨论功能不在本次写集。公开端点拒绝的根本原因没有官方解释，不能从业务码猜测“必须登录”或伪造 API 权限。

## 限定扩展与收口

用户明确允许评估 ai.cnvd.org.cn/ics.cnvd.org.cn 官方公开行业通道并保留范围。最终只纳入已取得真实记录的 AI 首页作为主站521的回退，主库诊断保留；ICS无token业务拒绝后停止。只读生产出口低频验证已完成，2026-10-22冻结，不再扩展调查。
