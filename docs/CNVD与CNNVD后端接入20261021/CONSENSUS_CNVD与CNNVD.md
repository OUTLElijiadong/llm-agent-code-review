# CNVD 与 CNNVD 实施约束与验收标准

1. 仅请求固定官方 HTTPS origin，复用公开页面实际使用的协议；不以 OWASP、第三方镜像或合成记录替代。
2. `integration=implemented` 表示适配器已实现；仅实际取得并验证通过的漏洞记录能使 `connected=true`；结构完整的零命中返回 `empty/connected=false`。HTTP 200、签名成功、页面可达均不充分。
3. HTTP 拒绝、业务拒绝、限流、超时、应用壳和错误结构必须保真返回；每次网络观察含时间、URL、状态码、响应 SHA-256 和字节数。
4. CNVD 优先主库公开最新页与精确编号详情；主库真实 HTTP521 时仅回退固定人工智能行业首页，标明 coverage_scope=ai_sector 和主库失败；关键字只筛选该页，不能宣称全库无匹配。CNNVD 查询官方搜索第一页；不宣称全量同步。
5. 成功和有效空结果缓存 300 秒；失败至少退避 60 秒，尊重上游 `Retry-After`，最长 3600 秒。过期成功不能继续标为当前接通。
6. 两条 API 均须真实认证和 `security:view`；无权限和参数非法请求不得联网。共享来源状态不得公开其他请求的检索词。
7. 验收分为本地实现回归、真实官方查询、主线程生产验收。只有第一层已完成不能推导后两层成功。
