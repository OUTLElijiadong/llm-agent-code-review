## 批准范围

- 批准执行本分支代码、沙箱 Java 镜像和固定 JADX CLI 的生产发布。
- 批准仅在隔离 `runsc` worker 中处理用户上传的 APK/AAB/DEX；不执行用户提供的 Windows GUI 工具。
- JAR/未知二进制保持不支持状态，不生成“反编译通过”。
- 生产失败只允许应用层回滚；不自动执行数据库 downgrade 或恢复。

## 暂停条件

- 服务器无法通过发布前备份和 `verify-backup.sh`。
- 生产沙箱缺少 `runsc`、Java 镜像或固定 JADX 校验和不匹配。
- 部署后容器、`/healthz`、登录、源码白盒或报告导出任一关键链路失败。
- 发现真实 Android 制品需要 Android SDK/模拟器才能完成动态运行；此时报告必须明确“仅反编译静态审计，动态部署未验证”。
