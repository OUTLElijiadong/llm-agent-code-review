## 本版新增的硬约束（实现时遵守的设计红线）

1. 诱捕容器**不发布任何端口**，只在 `code_review_net` 内可达；公网无法直连。
2. 诱捕路由 `/__prism_decoy` 只接受来自内网/回环的转发（`geo $prism_decoy_internal` 判定），
   公网直接访问该路径一律 308 跳转，不暴露诱捕层的存在。
3. 诱捕内容全部由固定种子伪随机生成，**没有任何真实密钥**；服务不读环境变量中的真实配置。
4. 引流只加公网地址，保护来源（管理员连接/本机地址/白名单/已建立公网对端）一律跳过。
5. **链序不合法时拒绝写入任何规则**（fail-closed）：引流链必须排在 DROP 链之前，
   否则流量会在 DROP 处终止、根本到不了诱捕层。
