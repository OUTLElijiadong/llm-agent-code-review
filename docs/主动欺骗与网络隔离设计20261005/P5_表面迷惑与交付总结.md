# P5 表面迷惑上线 + 诱捕层阶段总结（v4.0.71）

## 1. P5 改动（已上线 v4.0.70 / v4.0.71）

| 改动 | 版本 | 生产实测 |
| --- | --- | --- |
| 统一错误页：400/401/403/404/405/408/429/5xx 一律回落到站点自身页面 | 4.0.70 | `/assets/does-not-exist.js` 从 **146 字节的 nginx 默认页** 变为 200 + 1617 字节站点页面（nginx 版本指纹泄漏已消除） |
| 扫描器 UA 软 404（http 级 `map $http_user_agent`） | 4.0.70 | `sqlmap/1.7`、`Nikto/2.5`、Nmap Scripting Engine 命中诱饵路径均返回 **200 / 1617 字节**，与首页完全一致 |

## 4. 仍未完成的边界（如实列出）

1. **没有观察到真实攻击者被引流**：DNAT 只在 `nat` 表 `PREROUTING` 生效、回环流量不经过该链，
   宿主无法伪造集合成员源地址，端到端必须等真实来源进入 `prism-decoy-*`。
2. 诱捕容器 `access_log off`，观察依赖内核集合与执行器状态。
3. P4 需要云侧第二个弹性公网地址；P6 需单独窗口改云安全组。
4. 诱捕层目前**只服务 IPv4 与 IPv6 的 80/443**，其它端口按设计直接 DROP，不改写。
