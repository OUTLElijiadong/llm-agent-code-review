# Prism 测试报告完整修复：共识文档

## 目标

建立一条对标准审查、多 Agent 和圆桌讨论一致生效的确定性结果管线，同时修复平台安全、远程导入可靠性和报告页面交互缺陷。

## 验收契约

1. 同文件同一调用点的多来源发现只写入一个规范问题，并保留全部确认来源；相邻独立调用不能误合并。
2. Python `os.system`、危险 `subprocess.*` 和动态 `shell=True` 稳定产生 CWE-78；安全 argv 列表不误报。
3. 有效 CVSS v3.1 向量由后端确定性重算；向量与分数不可拆分；未知值保持为空。
4. 所有审查模式在归并后评分，输出公式版本和扣分明细；前端与导出报告使用同一风险口径。
5. 首页、静态资源、API 和错误响应均有目标安全头；CSP 不破坏现有 SSE、WebSocket、报告预览和资源加载。
6. 登录失败第 6 次触发 429；共享 Redis 计数，不信任外部伪造的转发地址，返回可恢复时间。
7. 干净 Shell/PHP 源码仍可审查；恶意内容和二进制仍被拒绝或隔离；宿主机无执行路径。
8. 远程导入快速返回持久化任务，支持进度、幂等、租约、失败原因和重启恢复；失败不留下可见半成品项目。
9. HTML 预览在弹窗允许、弹窗阻止和请求失败三条路径均有真实反馈，不再虚假提示成功。
10. 点击修复方案后，详情区进入实际滚动容器视口并获得可访问焦点；减少动画设置得到尊重。
11. 空白邮箱按未填写处理，非法非空邮箱继续拒绝。
12. 修改密码校验、项目视图切换不回归；目标 Radio 页面不再出现弃用警告。
13. 后端全量测试、Ruff、前端测试、Lint、构建全部通过；生产健康检查和三角色非破坏性真实点击通过。

## 技术约束

- 复用现有 SQLAlchemy/Alembic、SlowAPI/Redis、Agent 租约与恢复模式、Element Plus 和 Playwright。
- 新接口保持旧调用者兼容，第一方调用者迁移后再考虑移除旧同步语义。
- 高风险操作继续受 RBAC 和审批约束；本任务不扩大权限边界。
- 生产部署使用不可变提交哈希镜像，迁移前备份，部署失败可回滚旧镜像。
