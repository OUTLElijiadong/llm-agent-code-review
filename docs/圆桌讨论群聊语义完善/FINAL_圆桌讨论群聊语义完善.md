# 圆桌讨论群聊语义完善 - 最终总结

## 本地交付结果

- 圆桌固定邀请通用质量、安全、可靠性、性能、可维护性五个审查子 Agent。
- 每个 Agent 基于共享聊天记录自主选择发言或静音，并输出结构化立场和回应对象。
- 用户插话进入后续 Agent、主持总结和报告抽取的完整上下文。
- 静音可见、可回放，但不会生成虚假审查问题。
- 主持 Agent 最终总结共识、分歧、用户关注点和优先级。
- 前端显示参会者决策状态、立场标签、回应对象和静音原因。
