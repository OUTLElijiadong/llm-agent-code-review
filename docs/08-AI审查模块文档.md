# 08 · AI 审查模块文档

> 本文是项目的核心。详细描述 DeepSeek 智能体如何被设计、调用、约束输出、解析、入库、容错。读完应能照着实现 `app/ai/` 整个包。

## 1. 模块职责

`app/ai/` 是一个独立子模块,负责把 **代码 + 规则 + 审查代理画像** 转成 **结构化问题**。它对外主要暴露四类能力:

1. `DeepSeekAgent.chat(...)`:调用大模型,返回原始 JSON 文本
2. `multi_agent.get_agent_profiles(...)`:根据审查类型选择代理组合
3. `prompt_builder.build_prompt(...)`:构造带代理画像的 Prompt
4. `result_parser.parse(text)`:解析为标准化 `ReviewResult`

这一层不做业务权限判断,问题是否落库、写哪些表、归到哪个 task,都由 `ReviewService` 决定。`DeepSeekAgent` 仅负责把每次 LLM 调用审计写入 `ai_call_log`。

## 3. Prompt 工程

### 3.1 设计原则

- **角色明确**:让模型扮演"资深代码审查工程师"
- **维度清晰**:八条规则结构化列出,可启用/禁用
- **代理分工**:不同审查类型注入不同 Agent 画像,降低单个 Prompt 过宽导致的遗漏
- **输出强约束**:固定 JSON Schema,禁止额外解释
- **示例**(few-shot):给一个 mini 示例,模型更稳定
- **位置精确**:必须给 `line_number`,便于前端高亮
- **可分片**:长文件分块时附带 `line_offset`,模型用相对行号

## 字段约束
- `score`: 0-100 的整数,综合质量评分
- `issue_type` 取值范围: 代码规范 / 潜在Bug / 安全漏洞 / 性能问题 / 异常处理 / 命名规范 / 可维护性 / 注释完整性 / 其他
- `severity` 取值范围: 严重 / 高 / 中 / 低
- `line_number`: 问题起始行号(整数),若是文件级问题填 0
- `end_line`: 问题结束行号,可与 line_number 相同
- `title`: 不超过 30 字
- `description`: 中文描述,30-200 字
- `suggestion`: 中文修改建议,30-200 字
- `fixed_code`: 必须是可直接替换原代码的片段,包含必要的上下文

- 如果代码完全没有问题,issues 返回 []
- 不要捏造问题;不确定时倾向不报
- 不要输出 markdown 围栏、不要解释、不要寒暄,只输出 JSON

{code_content}
```

## 4. `prompt_builder.py`

```python
# app/ai/prompt_builder.py
from pathlib import Path
from typing import List, Tuple

PROMPT_PATH = Path(__file__).parent / "prompts" / "review.zh.md"


_SYSTEM = (
    "你是一名严谨的代码审查工程师。"
    "你必须严格按照用户消息中要求的 JSON 格式回答,只输出 JSON,不输出任何额外文字。"
)


def _load_template() -> str:
    return PROMPT_PATH.read_text(encoding="utf-8")


def _format_rules(rules) -> str:
    if not rules:
        return "(用户未启用任何规则,请按通用最佳实践审查)"
    lines = []
    for idx, r in enumerate(rules, 1):
        lines.append(f"{idx}. **{r.rule_name}**({r.rule_code}): {r.rule_content}")
    return "\n".join(lines)


def build_prompt(*, language: str, file_name: str, code: str,
                 rules: list, line_offset: int = 0, agent_section: str = "") -> Tuple[str, str]:
    """
    返回 (system_prompt, user_prompt)
    """
    template = _load_template()
    user_prompt = (
        template
        .replace("{rules_section}", _format_rules(rules))
        .replace("{agent_section}", agent_section)
        .replace("{language}", language or "plaintext")
        .replace("{file_name}", file_name)
        .replace("{line_offset}", str(line_offset))
        .replace("{code_content}", code)
    )
    return _SYSTEM, user_prompt
```

## 5. `multi_agent.py`

### 5.1 代理组合

| review_type | 代理组合 | 说明 |
| --- | --- | --- |
| `quick` | 通用质量代理 | 低成本快速检查 |
| `standard` | 通用质量代理 | 默认标准审查 |
| `security` | 安全审查代理 + 可靠性代理 | 聚焦漏洞、异常和边界条件 |
| `performance` | 性能审查代理 + 可维护性代理 | 聚焦性能瓶颈和维护成本 |
| `full` | 安全 + 可靠性 + 性能 + 可维护性 | 多 Agent 全面审查 |

### 5.2 设计约束

- 多 Agent 不新增数据库表,调用日志仍进入 `ai_call_log`。
- 多 Agent 结果在 `ReviewService` 中按文件、行号、类型、标题和描述做轻量去重。
- `standard` 保持单代理,避免默认审查成本突然升高。

## 6. `deepseek_agent.py`

### 6.1 设计要点

- 使用 `httpx` 同步客户端(简单,适合一期);后续切异步只换客户端
- 强制 `response_format={"type": "json_object"}`,DeepSeek 会保证输出为合法 JSON
- 单次调用失败重试 2 次,指数退避(2 秒、4 秒)
- 每次调用记入 `ai_call_log`(包括失败的重试)
- 超时 60 秒

### 6.2 实现

```python
# app/ai/deepseek_agent.py
import time
from typing import Optional, Tuple

import httpx
from loguru import logger
from sqlalchemy.orm import Session

from app.core.config import settings
from app.models.ai_call_log import AiCallLog
from app.ai.exceptions import AiServiceError


class DeepSeekAgent:
    def __init__(
        self,
        base_url: Optional[str] = None,
        api_key: Optional[str] = None,
        model: Optional[str] = None,
        timeout: Optional[int] = None,
        max_retries: Optional[int] = None,
    ):
        self.base_url = (base_url or settings.deepseek_base_url).rstrip("/")
        self.api_key = api_key or settings.deepseek_api_key
        self.model = model or settings.deepseek_model
        self.timeout = timeout or settings.deepseek_timeout
        self.max_retries = max_retries if max_retries is not None else settings.deepseek_max_retries

    def chat(
        self,
        *,
        system_prompt: str,
        user_prompt: str,
        db: Session,
        task_id: Optional[int] = None,
        user_id: Optional[int] = None,
        file_id: Optional[int] = None,
        chunk_index: Optional[int] = None,
    ) -> Tuple[str, dict]:
        """
        返回 (raw_text, meta)
        meta 含 prompt_tokens / completion_tokens / total_tokens / duration_ms
        """
        url = f"{self.base_url}/chat/completions"
        headers = {
            "Authorization": f"Bearer {self.api_key}",
            "Content-Type": "application/json",
        }
        payload = {
            "model": self.model,
            "messages": [
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_prompt},
            ],
            "temperature": 0.2,
            "max_tokens": 4096,
            "response_format": {"type": "json_object"},
        }

        attempt = 0
        last_err: Optional[Exception] = None
        while attempt <= self.max_retries:
            t0 = time.time()
            try:
                with httpx.Client(timeout=self.timeout) as c:
                    resp = c.post(url, headers=headers, json=payload)
                duration_ms = int((time.time() - t0) * 1000)

                if resp.status_code == 429:
                    raise AiServiceError("DeepSeek 限流", code=42900)
                if resp.status_code >= 500:
                    raise AiServiceError(f"DeepSeek 服务异常 {resp.status_code}", code=50201)
                if resp.status_code != 200:
                    raise AiServiceError(
                        f"DeepSeek 返回 {resp.status_code}: {resp.text[:200]}",
                        code=50201,
                    )

                body = resp.json()
                content = body["choices"][0]["message"]["content"]
                usage = body.get("usage", {})
                meta = {
                    "prompt_tokens": usage.get("prompt_tokens"),
                    "completion_tokens": usage.get("completion_tokens"),
                    "total_tokens": usage.get("total_tokens"),
                    "duration_ms": duration_ms,
                }
                self._log(
                    db, task_id=task_id, user_id=user_id, file_id=file_id,
                    chunk_index=chunk_index, prompt=user_prompt, response=content,
                    status="success", error=None, meta=meta,
                )
                return content, meta
            except Exception as e:
                last_err = e
                duration_ms = int((time.time() - t0) * 1000)
                self._log(
                    db, task_id=task_id, user_id=user_id, file_id=file_id,
                    chunk_index=chunk_index, prompt=user_prompt, response=None,
                    status="retry" if attempt < self.max_retries else "failed",
                    error=str(e)[:500],
                    meta={"duration_ms": duration_ms},
                )
                if attempt < self.max_retries:
                    sleep = 2 ** (attempt + 1)
                    logger.warning(f"DeepSeek 调用失败({e}), 第 {attempt+1} 次重试, sleep {sleep}s")
                    time.sleep(sleep)
                attempt += 1

        raise AiServiceError(f"DeepSeek 调用失败: {last_err}", code=50201) from last_err

    @staticmethod
    def _log(
        db: Session, *, task_id, user_id, file_id, chunk_index,
        prompt, response, status, error, meta,
    ):
        rec = AiCallLog(
            task_id=task_id, user_id=user_id, file_id=file_id,
            chunk_index=chunk_index,
            model_name=settings.deepseek_model,
            prompt=prompt[:200_000] if prompt else None,
            response=response[:200_000] if response else None,
            status=status,
            error_message=error,
            prompt_tokens=meta.get("prompt_tokens"),
            completion_tokens=meta.get("completion_tokens"),
            total_tokens=meta.get("total_tokens"),
            duration_ms=meta.get("duration_ms"),
        )
        db.add(rec)
        try:
            db.commit()
        except Exception:
            db.rollback()
```

## 7. `result_parser.py`

### 6.1 设计要点

- DeepSeek 在 `json_object` 模式下输出合法 JSON;但偶尔会带 markdown 围栏,需清洗
- 字段缺失给默认值;字段超出枚举降级为"其他"
- 行号越界(>文件行数)截断到合法范围(由 Service 层处理)
- 二次失败抛 `ResultParseError`,Service 跳过该 chunk

### 6.2 数据类

```python
# app/ai/result_parser.py
from dataclasses import dataclass, field
from typing import List, Optional
import json
import re
from loguru import logger

from app.ai.exceptions import ResultParseError


ALLOWED_TYPES = {
    "代码规范", "潜在Bug", "安全漏洞", "性能问题",
    "异常处理", "命名规范", "可维护性", "注释完整性", "其他",
}
ALLOWED_SEVERITY = {"严重", "高", "中", "低"}


@dataclass
class Issue:
    line_number: int = 0
    end_line: Optional[int] = None
    issue_type: str = "其他"
    severity: str = "中"
    title: Optional[str] = None
    description: str = ""
    suggestion: Optional[str] = None
    fixed_code: Optional[str] = None


@dataclass
class ReviewResult:
    summary: str = ""
    score: int = 0
    issues: List[Issue] = field(default_factory=list)


_FENCE_RE = re.compile(r"```(?:json)?\s*([\s\S]*?)```", re.IGNORECASE)
```

### 6.3 解析

```python
def _strip_fence(text: str) -> str:
    text = text.strip()
    m = _FENCE_RE.search(text)
    if m:
        return m.group(1).strip()
    return text


def _coerce_int(v, default=0) -> int:
    try:
        return int(v)
    except (TypeError, ValueError):
        return default


def _normalize_issue(raw: dict) -> Issue:
    issue_type = raw.get("issue_type") or "其他"
    if issue_type not in ALLOWED_TYPES:
        issue_type = "其他"
    severity = raw.get("severity") or "中"
    if severity not in ALLOWED_SEVERITY:
        severity = "中"
    return Issue(
        line_number=_coerce_int(raw.get("line_number"), 0),
        end_line=_coerce_int(raw.get("end_line"), 0) or None,
        issue_type=issue_type,
        severity=severity,
        title=(raw.get("title") or "")[:200] or None,
        description=str(raw.get("description") or ""),
        suggestion=str(raw.get("suggestion") or "") or None,
        fixed_code=str(raw.get("fixed_code") or "") or None,
    )


def parse(text: str) -> ReviewResult:
    if not text or not text.strip():
        raise ResultParseError("AI 返回为空")

    cleaned = _strip_fence(text)
    try:
        data = json.loads(cleaned)
    except json.JSONDecodeError as e:
        logger.warning(f"JSON 解析失败: {e}, 原始片段: {cleaned[:200]}")
        raise ResultParseError(f"AI 返回非合法 JSON: {e}")

    if not isinstance(data, dict):
        raise ResultParseError("AI 返回不是 JSON 对象")

    issues_raw = data.get("issues") or []
    if not isinstance(issues_raw, list):
        issues_raw = []

    return ReviewResult(
        summary=str(data.get("summary") or "")[:2000],
        score=max(0, min(100, _coerce_int(data.get("score"), 0))),
        issues=[_normalize_issue(it) for it in issues_raw if isinstance(it, dict)],
    )
```

## 8. `code_chunker.py`(分片策略)

### 7.1 策略

- 文件 ≤ 6000 字符:不分片,整体送入
- 文件 > 6000 字符:按 **函数/类边界** 切分;无法识别时按 **行数** 兜底每 200 行一片
- 每片携带 `start_line`(原文件中的起始行,1-based),Service 累加到 issue 行号

### 7.2 实现(语言无关的简化版)

```python
# app/ai/code_chunker.py
from dataclasses import dataclass
from typing import List
import re


@dataclass
class CodeChunk:
    text: str
    start_line: int       # 1-based,原文件中的起始行
    end_line: int


_FUNC_PATTERNS = {
    "python":    re.compile(r"^\s*(def|class)\s+\w+", re.MULTILINE),
    "java":      re.compile(r"^\s*(public|private|protected|static|final|class)\s.+\(.*\)\s*\{?", re.MULTILINE),
    "javascript":re.compile(r"^\s*(function\s+\w+|const\s+\w+\s*=\s*\(|class\s+\w+)", re.MULTILINE),
    "typescript":re.compile(r"^\s*(function\s+\w+|const\s+\w+\s*=\s*\(|class\s+\w+)", re.MULTILINE),
    "go":        re.compile(r"^\s*func\s+\w+", re.MULTILINE),
    "cpp":       re.compile(r"^\s*\w[\w\s\*&]*\s+\w+\s*\(.*\)\s*\{?", re.MULTILINE),
}


def chunk_code(content: str, language: str, threshold: int = 6000) -> List[CodeChunk]:
    if len(content) <= threshold:
        return [CodeChunk(text=content, start_line=0, end_line=content.count("\n"))]

    lines = content.splitlines(keepends=True)
    pattern = _FUNC_PATTERNS.get(language)
    if pattern:
        boundaries = _find_function_boundaries(content, pattern)
        if boundaries:
            return _split_by_boundaries(lines, boundaries, threshold)

    return _split_by_lines(lines, lines_per_chunk=200)


def _find_function_boundaries(content: str, pattern: re.Pattern) -> List[int]:
    """返回每个函数起始的行号(0-based)"""
    positions = []
    for m in pattern.finditer(content):
        line_no = content.count("\n", 0, m.start())
        positions.append(line_no)
    return positions


def _split_by_boundaries(lines, boundaries, threshold) -> List[CodeChunk]:
    chunks: List[CodeChunk] = []
    starts = boundaries + [len(lines)]
    cursor = 0
    while cursor < len(starts) - 1:
        # 尽可能合并多个函数到一片,直到 threshold
        start_line = starts[cursor]
        end_line = starts[cursor + 1]
        text = "".join(lines[start_line:end_line])
        # 合并后续函数,直到超过阈值
        while cursor + 2 < len(starts):
            next_text = "".join(lines[end_line:starts[cursor + 2]])
            if len(text) + len(next_text) > threshold:
                break
            text += next_text
            cursor += 1
            end_line = starts[cursor + 1]
        chunks.append(CodeChunk(text=text, start_line=start_line, end_line=end_line))
        cursor += 1
    # 文件头部(第一个函数之前)
    if boundaries and boundaries[0] > 0:
        head_text = "".join(lines[0:boundaries[0]])
        if head_text.strip():
            chunks.insert(0, CodeChunk(text=head_text, start_line=0, end_line=boundaries[0]))
    return chunks


def _split_by_lines(lines, lines_per_chunk: int) -> List[CodeChunk]:
    out: List[CodeChunk] = []
    for i in range(0, len(lines), lines_per_chunk):
        text = "".join(lines[i: i + lines_per_chunk])
        out.append(CodeChunk(text=text, start_line=i, end_line=i + len(lines[i: i + lines_per_chunk])))
    return out
```

> 此处实现简化、可工作即可。语言精准切分(如 Python 缩进解析、Java AST)超出毕设工作量。

## 10. `scoring.py`(综合评分)

```python
# app/ai/scoring.py
DEDUCT = {"严重": 15, "高": 8, "中": 3, "低": 1}


def compute_score(severity_count: dict) -> int:
    deduct = sum(DEDUCT.get(k, 0) * v for k, v in severity_count.items())
    score = 100 - deduct
    return max(0, min(100, score))
```

> 该计算覆盖 `review_task.score`,优先于 LLM 自评的 `score`(LLM 评分仅作为参考写入 task.summary 中)。

## 11. 完整调用示例

```python
from sqlalchemy.orm import Session
from app.ai.deepseek_agent import DeepSeekAgent
from app.ai.multi_agent import format_agent_section, get_agent_profiles
from app.ai.prompt_builder import build_prompt
from app.ai.result_parser import parse
from app.ai.code_chunker import chunk_code


def review_one_file(db: Session, file, rules, user, task):
    agent = DeepSeekAgent()
    profiles = get_agent_profiles(task.review_type)
    chunks = chunk_code(file.content, file.language, threshold=6000)
    all_issues = []
    for idx, ck in enumerate(chunks):
        for agent_idx, profile in enumerate(profiles):
            system, user_prompt = build_prompt(
                language=file.language,
                file_name=file.file_name,
                code=ck.text,
                rules=rules,
                line_offset=ck.start_line,
                agent_section=format_agent_section(profile),
            )
            raw, meta = agent.chat(
                system_prompt=system, user_prompt=user_prompt,
                db=db, task_id=task.id, user_id=user.id,
                file_id=file.id, chunk_index=idx * 100 + agent_idx,
            )
            result = parse(raw)
            # 调整行号:LLM 给的分片内相对行号 + 偏移;0 表示文件级问题
            for it in result.issues:
                it.line_number = 0 if not it.line_number else it.line_number + ck.start_line
                if it.end_line:
                    it.end_line += ck.start_line
            all_issues.extend(result.issues)
    return all_issues
```

## 13. 与数据库的交互边界

```
┌──────────────────────────────────────┐
│   ReviewService                       │ 业务编排
│   - 加载 project/file/rules           │
│   - 创建 review_task                  │
│   - 循环 file → chunk                 │
│   - 调用 DeepSeekAgent + parse        │
│   - 写入 review_issue 批量            │
│   - 计算 score 收尾                    │
└──────────────────────────────────────┘
            │ 调用            │ 调用
            ▼                ▼
┌──────────────────┐  ┌──────────────────┐
│ DeepSeekAgent     │  │ result_parser     │
│ - chat()           │  │ - parse()          │
│ - 写 ai_call_log   │  │ - 容错             │
└──────────────────┘  └──────────────────┘
```

**关键边界:** `ai/` 包仅写 `ai_call_log`,不写 `review_task` / `review_issue`。这样测试 AI 层时只需 mock `ai_call_log`,不污染业务表。

## 14. Token 与成本估算

| 单文件大小 | 估算 prompt tokens | 估算 completion tokens | 单次成本(DeepSeek-Chat 估) |
| --- | --- | --- | --- |
| 1 KB(~50 行) | ~600 | ~400 | ~¥0.003 |
| 5 KB(~250 行) | ~2,000 | ~800 | ~¥0.008 |
| 10 KB(~500 行,分 2 片) | ~4,200 | ~1,500 | ~¥0.020 |
| 20 KB(~1000 行,分 4 片) | ~8,500 | ~3,000 | ~¥0.040 |

> 多 Agent 模式会按代理数量放大调用次数:`security/performance` 约 2 倍,`full` 约 4 倍。答辩演示建议选择小文件或使用 `standard` 控制耗时。

> 实际以 DeepSeek 计费为准。本地测试期间充值 ¥50 应可覆盖整个毕设迭代。

## 15. 失败场景与降级

| 场景 | 处理 |
| --- | --- |
| API 401 | 立刻终止任务,标记 `failed`,提示"DeepSeek 鉴权失败,请检查 API Key" |
| API 429 | 重试 2 次,失败则跳过该 chunk |
| API 5xx / 网络抖动 | 同上,重试 2 次 |
| 返回非 JSON | `result_parser` 做围栏剥离;仍失败跳过该 chunk |
| 返回 JSON 但 issues 字段缺失 | `parse()` 把 issues 当作空数组,继续 |
| 模型超长截断 | 通过 `max_tokens=4096` 与分片避免 |

## 19. 圆桌讨论编排器 `discussion_orchestrator.py` (v2.3)

实时对话式审查的 AI 编排,与并行审查(`multi_agent` + `review_service`)并列。完整功能与协议见 [`docs/圆桌讨论/圆桌讨论功能文档.md`](../圆桌讨论/圆桌讨论功能文档.md)。

### 19.1 与既有 AI 模块的关系

- 复用 `multi_agent.get_agent_profiles(review_type)` 决定参会 Agent 组合;
- 复用 `deepseek_agent.DeepSeekAgent.call_raw(...)` 调用 LLM,**但必须传 `json_mode=False`**:讨论发言与共识小结是自然语言文本,不能走 `response_format=json_object`(否则返回 JSON、气泡为空)。这是与并行审查(强制 JSON)的关键差异。

### 19.2 编排流程

1. **开场**:主持人(`orchestrator`)发布欢迎语;
2. **逐轮逐人**:`max_rounds`(默认 2)轮,每轮按 `profiles` 顺序让每个 Agent 发言;
3. **历史可见**:`_build_history()` 把**之前全部发言**(含其他 Agent 与用户)拼入 prompt,实现「后发言者可见前者」;
4. **用户指示**:`_user_inputs` 在每轮结束清空,作为「用户最新指示」对下一位发言者强提示一次;
5. **汇总**:全部结束(或被终止)后,主持人在线程池中调用 LLM 生成自然语言共识小结,失败时回退为按 Agent 分组统计;
6. **收尾**:`finally` 发布 `done` 控制帧并 `close_session`。

### 19.3 调用链上的 LLM 标签

| `agent_label` | 用途 |
| --- | --- |
| `discuss_{code}` | 每个 Agent 的单轮发言 |
| `discuss_consensus` | 主持人共识汇总 |

> 这些标签同样写入 `ai_call_log`,可在管理员「AI 调用日志」中追溯讨论过程的每次 LLM 调用。
