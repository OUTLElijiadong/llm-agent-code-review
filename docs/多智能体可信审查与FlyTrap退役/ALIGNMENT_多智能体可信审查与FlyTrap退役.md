# Align：多智能体可信审查与 FlyTrap 退役

## 原始需求

1. 修复安全、质量、可靠性等智能体输出格式、严重度和置信度不一致，建立统一评分映射和冲突消解机制。
2. 降低同一代码在不同上下文和提示词下的误报、漏报与数据流理解波动。
3. 修复长文件分片后变量定义、函数调用、类继承和跨函数污点传播上下文丢失。
4. FlyTrap 项目已经关停，Prism 不得继续把它视为在役依赖或持续产生恢复告警。
5. 单点错误不得堵死整次审查；不确定结论必须可交给人复核。

## 项目现状

- 审查主链：`review_service -> code_chunker -> 多 Agent -> result_parser -> issue_merger -> review_issue`。
- 多 Agent 当前先独立调用，再让两个额外 LLM 分别执行交叉复审和共识统合；最终结论仍受模型随机性影响。
- `result_parser` 会把非数组 `issues` 静默转换为空数组，可能把格式错误误报为“零问题”。
- `issue_merger` 分别取最高严重度和最高置信度，可能组合出没有任何来源真正主张过的结论。
- 现有 `confirmation_count` 可由模型声明并补造来源，不能证明独立确认。
- `code_chunker` 仅输出代码、起止行，分片请求不包含全文件符号表、调用边、继承关系和邻接上下文。
- 安全哨兵对超过 60000 字符的文件直接跳过单文件 LLM 审查。
- 生产主机上的 `flytrap-agent.service`、`flytrap-sync.service` 和 `flytrap-agent-cert-renew.timer` 仍为 `active/enabled`，Prism 每轮安全巡检仍调用 `flytrap_attack_events`，因此持续重试并产生上游降级告警。

## 标准依据

- OASIS SARIF 2.1.0 区分逻辑相同结果、稳定指纹、严重度、优先级和 `review` 人工复核状态，并明确指出不同工具的 rank 通常不可直接比较。
- OWASP 风险评级将风险拆为发生可能性和影响，避免把模型把握度直接当作漏洞影响等级。
- NIST SAMATE/SARD 强调使用已知真值样本评估静态分析工具，不能用单次模型自评替代误报、漏报回归。

## 边界

### 本次包含

- 统一发现主张协议、严重度映射、置信度校准、证据等级、冲突状态和输入守恒。
- 真实来源计数；禁止根据模型给出的数字补造来源。
- 可恢复解析：坏条目隔离、好条目继续；全部不可解析时不得伪装成零发现。
- 跨分片符号索引和有界上下文；Python AST 优先，其他语言使用保守词法索引并明确降级。
- 稳定提示词版本与上下文指纹；高危但证据不足或结论冲突自动进入人工复核。
- 审查详情展示置信度、来源、证据等级和冲突，并支持独立的人审结论。
- FlyTrap 代码、调度、告警和生产服务的非破坏性退役。

### 本次不包含

- 不承诺概率模型永远零误报或零漏报；验收目标是错误可见、可回退、可复验，不再静默伪装为成功。
- 不删除 FlyTrap 历史日志、数据库记录、部署备份或兼容读取接口。
- 不把 CVSS 与非安全质量问题混用，不根据严重度反推 CVSS。
- 不更换 LLM 供应商，不引入新的外部运行依赖。

## 已确认决策

- FlyTrap “关停”按非破坏性退役执行：停止采集、同步、自启、巡检和新告警；历史证据只读保留，可按回滚文档恢复。
- 现有中文四级严重度与 `severity-deduction-v1` 历史评分保持兼容；新聚合风险分使用独立版本，不改写旧算法含义。
- 置信度表示结论可信程度，严重度表示问题影响，两者分开计算并绑定具体来源主张。
- 冲突不静默覆盖：跨两档严重度、CWE 冲突、证据缺失、来源不守恒均进入 `pending_review`。
- 前端和 API 只增字段，不删除既有字段。

## 可测试验收线

- 非数组 `issues` 触发结构错误，不再返回“空问题成功”。
- 混合好坏条目保留有效项，并返回逐项诊断。
- 每个输入 claim 必须映射到一个输出 claim 或带理由的 discarded claim。
- 聚合严重度、置信度、证据和来源可追溯，不能生成无人主张过的组合。
- 相同输入任意排列的聚合结果字节级稳定。
- 同一真实来源不能重复增加确认数，模型声明的计数不能制造新来源。
- Python 嵌套函数、类继承和跨分片调用测试能在每个相关分片上下文中看到必要符号。
- 分片或单 Agent 失败时其他结果继续；全部模型失败时静态结果保留且任务明确带警告。
- FlyTrap 禁用时不执行宿主机日志/服务查询，不生成降级或恢复人工动作，历史状态接口明确返回 `retired`。
