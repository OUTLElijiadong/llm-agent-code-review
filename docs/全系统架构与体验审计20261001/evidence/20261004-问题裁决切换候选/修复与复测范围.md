# 问题裁决响应绑定修复范围

仅修复候选工作树中的 `IssueDetailDrawer.vue` 与专属测试，不改后端请求、人工裁决规则、共用路由或业务数据。

## 原问题与复现

真实 Vue 组件中，问题 A 接受请求待返回，切到问题 B 并输入新依据，A 晚到成功后旧组件会清空 B 新依据、发送旧 A `reviewed` 事件并显示旧成功提示。独立受控 API 边界桩原场景三轮均失败，未切换正向对照通过。请求始终指向 A，没有证明 API 越权、后端写错问题或跨账号数据访问。

扩大原实现样本24项中16失败、8通过，无未处理错误。首次扩展有关闭 stub 未命名与 mock once 队列残留的测试桩问题；修正测试桩后重新运行有效红，首次日志仅保留为测试设置记录，不当作产品证据。修复后另外扩展6项账号迟到错误与认证未就绪入口样本，最终组件30项。

## 最小修复

发起请求冻结问题/任务与账号 token/ID、当前显示世代；问题或账号变化同步失效，关闭后同目标草稿仍保留，卸载后拒迟到结果。成功、错误、finally 均检查当前目标；旧 finally 不能解除新问题请求的 loading。A→B→A 与 token/profile A→B→A 使用同步世代，不能因标识回到原值而复活旧响应。当前正常成功仍发结果并清已提交依据；当前真实失败仍提示、保留草稿并允许重试。

## 验证

原场景在最终三轮关联组内每轮重复3次，共9个通过样本。三轮关联测试文件 `IssueDetailDrawer.test.ts`、`SecurityCenter.test.ts`、`ReviewTaskDetail.test.ts` 每轮108通过；最终 verbose 原日志确认 Drawer30项、SecurityCenter12项、ReviewTaskDetail66项。目标ESLint、限定diff检查、完整 vue-tsc 和 Vite build 都退出0。首轮与完整构建并行耗时92.79秒，第二轮27.27秒，第三轮14.66秒；构建 Vite 为2分14秒，保留实际耗时。

## 未验边界

本组不调用生产、真实 HTTP、供应商、CUA 或手机，也没有创建业务裁决。取消后端已经发出的请求或撤销已提交 A 的裁决不在本 UI 修复范围；只抑制不再属于当前显示生命周期的结果事件、提示与本地状态更新。保留此前证据分级/历史CVSS语义改动，不声称全站无错误、权限全部通过或所有模型无幻觉。
