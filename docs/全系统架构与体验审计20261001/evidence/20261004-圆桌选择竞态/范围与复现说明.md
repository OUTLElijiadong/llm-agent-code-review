# 圆桌同账号会话选择竞态

## 已确认范围

实际 Vue 宿主组件接收 API 延迟桩：同账号先选择 A、再选择 B，B 的详情先成功并显示 B；A 随后成功，旧实现将面板覆盖为 A。原场景三轮均失败，15 项中 3 失败、12 通过；日志保留原始失败断言，不以源码推断替代复现。

扩大样本后旧实现 22 项中 8 失败、14 通过：旧详情错误污染新选择、最后选择失败被旧成功覆盖、显式关闭面板后迟到成功重新打开或迟到错误出现、关闭选择器后迟到详情打开。账号切换和卸载样本在旧实现本来通过，只作保留回归，不记作新增缺陷。

## 最小修复

仅修改 `GlobalDiscussionHost.vue` 和专属测试。详情请求使用独立选择代际，成功和错误均校验账号代际、当前账号及详情代际；显式关闭面板或选择器、切换账号、卸载会使待处理详情过期。保持跨页面全局面板、后台列表对账、服务端鉴权、历史分页、五分钟追问的既有契约。

补充同账号 A→B→A 的历史快照样本，以及账号 A→B→A 的迟到成功/错误样本。关闭后可正常重开，旧错误不得污染最新选择；未增加路由权限或改动侧边栏及渗透入口。
