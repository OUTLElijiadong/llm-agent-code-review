# 全域 AI 上下文压缩：需求对齐

用户要求：所有涉及 AI 与 Agent 的聊天、代码审查和安全审计，在内容超过模型预算时压缩上下文而非静默截断；模型仍需理解此前目标、约束、证据和对话顺序。移动端需要能看见处理进度和完整回复。

现状以 v4.0.12 仓库为准：小菱新版 Responses 运行时、圆桌、临时 Agent、正式源码分片已有预算或来源覆盖；但旧 `/ai/chat` 对话仍按固定字符摘录，公开 `/v1/responses` 回放历史无预算，安全哨兵部分二轮推理固定取前 30 项或前 12 条高危证据，正式协同审查的非源码画像过大时直接失败。全链审计会拒绝图谱截断，但仍有超窗即失败的可用性缺口。

本阶段只修改已确认的模型输入路径及必要的移动端表格布局；保持现有账号权限、完整原始账本、审查报告与发布接口。首轮修复后进一步审计出论坛助手、渗透多个阶段、团队依赖、已发布 Agent 只读 Skill、正式审查聚合与沙箱报告知识引用的遗漏，纳入后续 T9–T16；未能真实模型验收的路径继续列为待办。模型语义摘要无法由来源 ID 校验证明绝对无损，因此完整性验收以来源覆盖、关键约束与证据测试、失败显式化和真实调用共同判断。
