# 全域 AI 上下文压缩：交付报告

本任务在 v4.0.12 生产版上复现并修复多处固定裁剪、无预算回放及审计覆盖误判。候选保持账号聊天账本、源码和审查规则原文，先计算模型输入与输出预算，再对允许压缩的历史和补充知识按来源分片；来源不完整、模型输出截断或剩余预算不足时显式报错，不能把部分结果标成完整。

圆桌的正式讨论进度、后台追问与五分钟期限已在 v4.0.12 用真实项目 `test_auth.py` 验收；本轮补手机长表格阅读问题，并把预算检查扩展到旧聊天、公开 Responses、正式审查、安全哨兵和全链审计。全链审计的“模型推理确认”与“沙箱实际复现”分别统计。

v4.0.13 生产真调暴露公开 Responses 压缩模型仍会在两次输出预算内截断；系统当时正确拒绝使用不完整摘要。v4.0.14 候选据此加入更高但有界的输出预算与多来源拆批，同一真实圆桌历史的隔离进程复跑已返回完整答案；上线后仍须独立复测。版本、提交、完整测试数、生产核验与截图证据以验收记录为准；其他模型入口和未完成项见待办。
