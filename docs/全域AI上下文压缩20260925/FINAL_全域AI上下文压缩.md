# 全域 AI 上下文压缩：交付报告

本任务在 v4.0.12 生产版上复现并修复多处固定裁剪、无预算回放及审计覆盖误判。v4.0.15 已发布：实现保持账号聊天账本、源码和审查规则原文，先计算模型输入与输出预算，再对允许压缩的历史和补充知识按来源分片；来源不完整、模型输出截断或剩余预算不足时显式报错，不能把部分结果标成完整。

圆桌的正式讨论进度、后台追问与五分钟期限已在 v4.0.12 用真实项目 `test_auth.py` 验收；本轮补手机长表格阅读问题，并把预算检查扩展到旧聊天、公开 Responses、正式审查、安全哨兵和全链审计。全链审计的“模型推理确认”与“沙箱实际复现”分别统计。

v4.0.13 生产真调暴露公开 Responses 压缩模型仍会在两次输出预算内截断；系统当时正确拒绝使用不完整摘要。v4.0.14 据此加入更高但有界的输出预算与多来源拆批，正式生产镜像用真实圆桌历史触发压缩后已返回完整答案。第二组主动压低最终输出预算的实测返回上游 `incomplete`；取消显式上限时又遇到上游 HTTP 402，因此不能声称所有预算都能完成。v4.0.15 已将 402 从误导性的 502 分类改为明确的上游支付或额度状态，并修复论坛助手长草稿、渗透证据摘要及团队私有依赖的来源/覆盖缺口。v4.0.16 继续处理渗透其余阶段、已发布 Agent 的只读 Skill 结果、沙箱报告知识引用及正式审查聚合降级口径，按实际 HTTP 尝试限制知识压缩请求；后端全量 4849 项通过并已发布生产。发布后审计又发现正式审查依赖固定前 100 条、自动重试策略固定前 12000 字，v4.0.17 候选已删除两处静默裁剪并新增覆盖测试；团队定向 95 项、后端全量 4851 项通过。真实模型仍受上游 HTTP 402 阻挡，相关边界保留在待办中。
