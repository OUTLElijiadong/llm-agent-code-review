# 主机治理与执行器边界交付结论

生产已部署 `4.0.47`（`efd620d3b1cd1e989996385085b197fa888a84fb`）。后端和前端均健康，生产备份通过独立恢复校验，Alembic 与 `062_audit_log_action_length` head 一致。真实后端 socket 探针合法身份返回 200，错误 UID 返回 403；root 执行器 dotenv 隔离、socket 权限和容器 capability 边界均按目标生效。独立复核未发现旧的通用高权操作入口残留。

除 Prism 和必需主机基础服务外，已核查的非项目 systemd 服务均 inactive；公网 TCP 监听为 SSH 22、Prism 80/443。containerd 35913、后端 8000、MySQL 3307 仅绑定回环。没有本机 8888 监听；腾讯云安全组按用户此前选择保持不变。生产数据、已有备份和两次发布新增备份均保留。

测试通过不等于完成攻击验证。本次没有执行真实利用或入侵模拟。仍需治理的核心边界是：被攻陷的后端进程虽不能执行任意 shell，仍可绕过应用用户审批直接调用 root 执行器中保留的固定高权限动作；详见 TODO。
