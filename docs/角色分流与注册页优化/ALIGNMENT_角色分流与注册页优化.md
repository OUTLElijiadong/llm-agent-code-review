# 角色分流与注册页优化对齐文档

## 原始需求

- 不同角色登录后应该进入不同页面，不能都共用同一个默认界面。
- 注册界面需要更美观，并且看起来像同一个项目。

## 项目上下文

- 前端为 Vue3 + TypeScript + Element Plus + Pinia + Vue Router。
- 当前角色字段来自 `user.profile.role`，后端支持 `admin`、`reviewer`、`user`。
- 现有路由已有管理员专属页面：`/admin/users`、`/admin/ai-logs`、`/admin/audit`、`/admin/evolution`。
- 登录页已经采用 Prism 棱镜品牌视觉，注册页仍是旧式渐变卡片，与项目主视觉不一致。

## 边界确认

- 本次只修改前端登录分流、路由守卫、导航入口和注册页视觉。
- 不改后端权限模型，不新增数据库字段，不改变已有 API。
- 管理员仍可通过路由访问原有业务数据能力，但默认入口与侧栏优先展示管理界面。

## 决策

| 角色 | 默认进入页面 | 界面侧重 |
|------|--------------|----------|
| 管理员 `admin` | `/admin/users` | 用户、日志、审计、自进化等平台管理 |
| 审查员 `reviewer` | `/reviews` | 审查任务、问题追踪、报告、安全中心 |
| 普通用户 `user` | `/projects` | 项目、代码、审查、报告等业务操作 |

## 疑问处理

无必须中断确认的问题；角色值和页面边界可由现有代码直接判断。
