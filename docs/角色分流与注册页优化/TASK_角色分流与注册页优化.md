## 原子任务

| 编号 | 输入契约 | 输出契约 | 验收标准 |
|------|----------|----------|----------|
| T1 | 已知角色值 `admin/reviewer/user` | `roleHome.ts` | 角色首页映射集中管理 |
| T2 | 登录页与路由守卫 | 登录后、根路径、已登录访问认证页均分流 | 不再固定跳 `/dashboard` |
| T3 | 侧栏与搜索入口 | 角色化菜单和搜索结果 | 普通用户不显示管理员入口 |
| T4 | 现有登录页视觉 | 新注册页 | 注册页与项目 Prism 风格一致 |
| T5 | 前端工程 | 构建结果与文档 | `npm run build` 通过 |
