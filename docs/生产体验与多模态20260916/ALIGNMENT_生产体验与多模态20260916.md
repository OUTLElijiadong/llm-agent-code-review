# 生产体验与多模态 2026-09-16 对齐

## 原始需求

核验最新生产代码和真实界面，完成严重度分布、工作台评分、普通用户个性化与头像、Agent 工坊权限、小菱引导与形象、首页进度反馈、卡片化交互、DeepSeek 多模态模型配置及图片上传自动切换；检查失败回退和反馈；回填知识库；通过完整 Git bundle 发布生产。

## 范围与边界

- 代码范围：`backend/`、`frontend/`、`deploy/`，前后端必须同一完整提交发布。
- 验收范围：管理员与普通账号的关键页面、路由权限、仪表盘统计、模型注册/分配、图片历史恢复、失败反馈。
- 数据范围：只读核对生产现有数据；不自动改写历史任务、组织归属或个人偏好。模型同步和个人头像仅在明确点击后写入。
- 生产动作：沿用用户确认的完整 Git bundle 发布流程，发布前备份、迁移、健康检查、冒烟及必要时应用回滚。

## 需求理解

现有 3.9.2 已包含大部分体验改造。本轮重点补齐跨接口失败时的前端归一化、Responses 请求/响应审计脱敏、图片失败重试续跑，以及评分趋势的非法历史分数过滤。DeepSeek 官方 2026-09-10 已将 `deepseek-flash` 作为具备原生视觉理解的最新 Flash 入口，旧名称仅作兼容路由。

## 待确认与验收假设

- 生产环境当前仍可能指向旧的 3.9.2 提交；必须以 `/readyz` 的完整 release SHA 为准。
- 生产模型凭据不可用时，界面应明确显示回退到系统默认，不因同步失败清空既有注册表。
- “个人画像隐藏”解释为不在主导航单独暴露画像页，偏好通过个人中心/小菱按需询问；账户基本信息仍保留。
