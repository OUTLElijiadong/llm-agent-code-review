# 生产体验与多模态 2026-09-16 共识

## 验收标准

1. 仪表盘严重度分布有可见数值兜底；图表失败显示重绘入口；平均代码评分只统计有效代码审查并过滤空值/越界值。
2. 后台进行中面板展示项目/Agent 状态和进度，轮询失败可重试且不阻塞其余卡片。
3. Agent 工坊仅 `reviewer`/`admin` 可进入；普通用户访问得到标准 403 页面。
4. 普通用户可选择内置头像、上传受限图片，偏好弹窗可保存/跳过/不再提醒；小菱注册后引导不重复打扰。
5. 管理员可查看模型注册表、视觉能力标记、角色分配和同步失败反馈；图片消息自动使用 `chat_vision`，同一会话后续纯文本恢复默认模型。
6. 多模态输入/输出写入用量账本时保留协议、模型、请求结构和响应摘要，图片只保留资产 SHA/引用，不保存 base64。
7. 生产发布使用完整 Git bundle/精确 SHA；发布前备份和 Alembic head 检查通过，发布后 `/healthz`、`/readyz`、关键页面和权限冒烟通过。

## 技术约束

- 复用现有 FastAPI、SQLAlchemy、Alembic、Vue 3、Element Plus、Responses runtime 和部署脚本。
- 不修改历史任务状态；不把模型列表拉取成功当作模型调用能力验证。
- 所有异步接口失败必须保留局部结果并给出可见反馈；认证、授权、数据完整性和发布门禁继续 fail-closed。
