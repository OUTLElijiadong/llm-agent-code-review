# 逻辑漏洞与修复

本轮依据代码、独立复现与回归测试，不代表全代码库不存在其他问题。具体测试结果见验收记录。

|问题|影响|修复|
|---|---|---|
|项目成员移除或项目隔离后，历史报告仍能读取/导出|越过当前项目访问边界|报告原作者/管理员合同叠加当前项目可见性|
|报告使用当前文件名和语言|历史报告随文件修改漂移或删除后缺失|优先使用审查时冻结的文件快照|
|非空问题列表把 ORM 对象当字典|小菱查询已发现问题时失败|按真实服务返回结构读取并回归|
|默认选入二进制与空文本|正常项目审查失败，排除范围不可见|统一选择可审文本，记录每个排除文件和原因|
|团队中直接传 project_id 给仅支持代码片段的 Agent|团队看似工作，未走正式任务/报告链路|既有审查调度 Agent 新增受信 run_review，复用正式任务与快照|
|安全成员未传递 scan_mode、失败证据丢失|全量/部分覆盖边界混淆|按参数执行，部分失败保留证据且不报成功|
|旧 Worker 吞掉取消/租约失效后继续写进度|覆盖新 Worker 状态，取消后恢复写入|执行与提交前校验有效租约，失败写入同样校验 token|
|已停用账户的排队审查继续执行|失效授权仍产生模型调用|队列执行前和等待中复核账户、权限与项目范围|
|共享审查 Agent 的系统提示词被并发修改|不同规则请求互相串扰|请求级提示词，无共享对象写入|
|团队汇总只包装依赖结果、未验证内部状态|部分失败可能被升级为完成|同时检查外层节点终态与内部结果，失败闭环|
|嵌套公开结果丢失审计覆盖指标|小菱无法确认实际已完成的语义覆盖|从数据库提取白名单覆盖标量，顶层公开摘要保留文件/分片/字符/失败计数，未知不推断|
|团队无时区后缀的 UTC 时间按浏览器本地解析|刚开始运行显示已工作 8 小时，日志时钟错位|复用 Day.js UTC 解析，统一团队组件时钟与计时|
|报告页脚硬编码 v1.0|与实际发布版本不符|复用全站现有版本常量|
|嵌套事件脱敏截断问题明细|真实有问题却汇总为零|从数据库结果提取有界标量字段并逐项脱敏，保留范围提示|
|侧栏按钮负偏移遇到 overflow 裁切|收起后按钮不完整|按钮置于有效容器布局范围|
|操作列跟随标题、权限变化后网格错位|“详情”“查看任务”左右漂移|操作列独立，权限决定网格结构，中文底边对齐|
|上传限制中间件先读取非 HTTP 消息的 headers，Uvicorn 自动模式忽略生命周期异常|网页健康但小菱团队永久排队，调度器未启动|非 HTTP scope 原样透传；生产强制 lifespan on，生命周期异常立即启动失败，并增加真实应用中间件链回归|
|页面项目加载失败阻止问题加载、错误详情被默认插槽遮住|失败变空态或无法理解原因|独立加载、明确错误与可点击重试，并用真实 Vue 浏览器验证|

## 能力与证据边界

- 只复用当前存在的 Agent 定义；团队成员、工作图是执行记录，不创建新的 Agent 定义。
- 正式审查支持 full/security，单任务沿用 1–500 个文件边界；等待上限来自 agent_full_validation_wait_seconds（生产默认 600 秒）。超时保留证据并取消关联任务，不能声称所有大项目均已验证。
- 正式任务问题摘要最多返回 100 条；团队依赖摘要最多 200 条，保留总数或截断标记。汇总数量只针对已返回条目的精确去重，任务与报告保留正式完整结果。
- 汇总成员进行确定性证据核对与精确去重；相同漏洞的不同措辞不会被强行语义合并，自动结果也不等于漏洞已动态复现。
- 本地浏览器页面测试使用明确 API 桩；与真实模型、生产浏览器验收分别记账。
- 本机模型域名解析到保留地址，被现有 SSRF 防护拒绝。此失败保留；在服务器隔离环境复验，不关闭防护。
