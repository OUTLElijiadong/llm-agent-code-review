# 棱镜第四版执行共识

1. 小菱以当前用户/会话为总控，只选择现有可执行成员；代码审查通过正式 ReviewTask 执行，安全审计使用现有安全哨兵。独立工作可并行，汇总依赖工作结果。
2. 创建任务、排队和运行中不能称为审查完成；成功、部分结果、失败、取消、超时和失效租约必须可区分。正式任务、问题、报告、模型调用和团队证据相互可追踪。
3. 部分失败保留已产出的证据，但不能报全覆盖成功。重试不能重复创建正式任务；取消和停用账号不得继续无约束执行。
4. 展开/收起侧栏按钮完整可见且可点击；代码中心标题与搜索按底边对齐；问题卡片操作独立稳定列，不随标题字数或是否有勾选框漂移；窄屏合理换行。
5. 明确偏好写入主知识库，区分用户原话、工程实现和推断。用户本次已授权记录所表达偏好，不新增人格/兴趣推断。
6. 通过适用自动化测试、生产构建、真实模型审查/审计团队、浏览器交互及独立证据复核后，执行备份/隔离恢复、精确 SHA 发布、健康/迁移/业务复验；用户已授权上线，无须重复申请同一权限。
