设计方案 · v1.0 · 2026

让代码穿过 棱镜，
折射出 8 个维度的真相。

「棱镜 Prism」是为基于大模型智能体的代码质量审查管理系统定制的视觉语言。它把"AI 智能体审查代码"这件抽象的事，转译成一个所有人都能瞬间理解的隐喻：代码像一束白光穿过棱镜，被 AI 折射成 8 道彩色的维度光谱——每一道颜色，都对应一类被发现的问题。

One beam in, eight truths out. — 一束代码进，八重洞察出。

CONCEPT
在 SonarQube 像"扫描仪"、GitHub 像"批注板"的时候，
我们做一台会说话的棱镜。
DeepSeek 大模型让审查从"模式匹配"升级为"语义理解"——它会用自然语言告诉你为什么这段代码有问题，并给出该怎么改。视觉语言必须把这种"智能感"和"折射感"传递出去。

1  设计理念

01 / 07 — Philosophy
关键词
棱镜 · 光谱 · 折射

三个词共同构造一个核心隐喻：AI 智能体 = 棱镜；8 维度审查 = 光谱；自然语言反馈 = 折射出的可见光。隐喻自带答辩记忆点，不依赖"AI 蓝"、"赛博绿"这类被用滥的视觉。

为什么契合本品

SonarQube/ESLint 是"过滤器"——它们只筛出已知模式。我们是"折射器"——大模型把一段难以名状的代码气味，折射为 8 道清晰的、可命名的维度。这恰好把产品的差异化（语义理解、自然语言反馈）变成了视觉差异化。

推荐风格方向

采用你倾向的 A 暗色侧栏 + C 高饱和图表。理由：① 侧栏暗化让品牌色更"发光"，强化 AI 工作站气质；② 主内容区保持浅色高密度，照顾教师/学生长时间阅读代码的视疲劳；③ 8 维度天然就是一组数据可视化色板，与 C 的诉求完全一致。

import { ref, onUnmounted } from 'vue';
export function useStreamText(target) {
  const text = ref('');
  let i = 0, timer;
  const start = () => {
    timer = setInterval(() => {
      if (i >= target.length) return clearInterval(timer);
      text.value += target[i++];
    }, 22);
  };
  onUnmounted(() => clearInterval(timer));
  return { text, start };
}

// 用于 Dashboard / Report 评分大数字
export function useCountUp(target, duration = 1200) {
  const value = ref(0);
  const start = performance.now();
  const ease = t => 1 - Math.pow(1 - t, 3); // easeOutCubic
  const tick = (now) => {
    const t = Math.min((now - start) / duration, 1);
    value.value = Math.round(target * ease(t));
    if (t < 1) requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick);
  return value;
}
